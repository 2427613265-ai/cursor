# 交底摘录（清洗稿，供独权对照）

原件：专利技术交底书《冷轧IGBT功率单元快速检测工具应用》。  
联系人等信息已省略。附图见 `figures/`。

## 声称要解决的问题

IGBT 损坏导致轧线中断；更换前须判断元件好坏。万用表常规检测不能满足该抽屉式变频器；需要快速检测 IGBT 及驱动板，并检测备件。

## 背景与现有做法

冷轧五机架连轧，日立 HIVECTOL-DC 3.3 kV 水冷 IGBT 单元多组并联，直流母线 3300 V。

现有：在线或备件均须解体抽屉，拆成单管后用万用表辨 G/C/E，再用电阻从 C 向 G 提供触发，看表针是否保持。一台轧机约 18 个抽屉、64 只 IGBT，拆装检测约 20 小时，且易静电击穿栅极。

上桥由两只 IGBT 串联；不解体时柜内空间不允许用万用表检测。核心是：如何在不解体条件下构成两组栅极触发和一条检测回路。

## 工具结构（优选实施例）

- 电源：AC 220 V 输入，DC 48 V 输出（适配器或电池）。
- 指示回路：V+ → 常开开关 S1 → LED → 被测串联支路 C 极；E 极经可调电阻（正文 R3，图中 R1，约 20 kΩ）回 V−。
- 栅极回路一：驱动板 HMD890 的栅极输出经常开开关 S2 接到第一管 G1；E 与驱动板 −DC 共地。
- 栅极回路二：经 S3 接到第二管 G2。
- 公共端：电源 GND 接 IGBT E 极。
- 光纤信号发生器向 HMD890 提供触发脉冲。
- 附件：绝缘夹及绝缘电缆，用于不解体接线。

## 判据（交底原文层次）

1. 只按 S1：灯亮 → 两管损坏；灯不亮 → 至少一管正常。
2. 先给光纤信号，S1 按下后再按 S2、S3。只按 S2 灯亮 → 第一管能开通且第二管已坏；S2 不亮再按 S3 后灯亮 → 两管均能开通；仍不亮 → 栅极失效。
3. 松开 S2：灯常亮 → C-E 击穿（交底写「IGBT2 关断」，与 G1/G2 编号可能不一致，见第1步推定）。
4. 松开 S3：灯常亮 → C-E 击穿（交底写「IGBT3」，疑笔误）。

## 欲保护点（交底）

1. IGBT 检测工具整个硬件配置方案。
2. 利用 IGBT 特性的检测手段与判断标准。

## 声称效果

不拆装功率单元；单抽屉约 30 秒，18 个抽屉约 15 分钟。
