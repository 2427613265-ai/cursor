# 【第3步-a / 共9步】独权部件命名对照表（第一版）

**闸门：** `部件命名优化总控` → 分型后已读 `交底口语名改写为自明结构名规范`、`部件命名具体优化`、`自定义名词就地定义`、`权利要求指代与参照清晰性规范`、`结构类权利要求撰写`（母子件）、`功能性限定使用边界规范`。名称中无左/右、上下游等观察方位钉死语，第 2 闸 `方位与场景限定上位规范` 未改名（「上桥」不入独权名）。

**硬性：** 用户确认或改选采用名之前，**不写第一版独权全文**。最小集里的物不变，只定怎么叫。

**本案口径：** 电学案。名称用电路元件/电极/接线端，不用夹子、灯、工装等机械口语。

## 3. 推荐采用名清单（确认后第 3 步-b 只准用这些词）

**主题：** 检测装置（前序可写用于检测具有串联功率开关支路的功率单元）

**接线对象（不列入「包括」）：** 功率单元；串联功率开关支路；功率开关器件

**装置同级元件：** 直流电源；指示元件；控制极激励源；接线端

**前置引入、不与上列并列：** 检测回路（直流电源与指示元件串联构成）；控制极激励支路（由控制极激励源引出、与各功率开关器件对应）

**电极（前置一句说清）：** 功率开关器件具有控制极、第一主电极和第二主电极。串联功率开关支路的第一主电极端、第二主电极端。该功率开关器件的控制极、该功率开关器件的第二主电极。

**接线端消歧（归属前缀，不用第一/第二钉数量）：** 第一主电极接线端、第二主电极接线端、各控制极接线端（各管第二主电极可经对应控制极激励支路接通，不必再单列一种夹子名）

**就地定义（前置白话，不用「其中」堆砌）：**

- 先写「直流电源与指示元件串联构成检测回路」，再用所述检测回路。
- 先写「控制极激励源引出与各功率开关器件对应的控制极激励支路，各控制极激励支路分别可通断」，再用所述控制极激励支路。
