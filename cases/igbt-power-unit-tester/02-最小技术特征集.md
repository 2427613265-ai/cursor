# 【第2步 / 共9步】最小技术特征集

**本步依据：** `最小技术特征集与第一版独权`  
**本案口径：** 电学案（电路拓扑）。组集问的是元件角色与电极节点，不问机械安装面。  
**禁止：** 本文件不写独权全文；不调用必要特征检查；不预先锚定技术问题。

## 0. 电学案与结构案组集的差别（本案必须守）

结构案 skill 里的「位置 / 固定 / 作用面」在本案改写为电学对应物；第 3 步连缀时同样不套机械总列习惯。

| | 机械结构案 | 本案（电学 / 检测装置） |
|--|------------|------------------------|
| 入集对象 | 壳体、杆、面、安装位置 | 电源、指示元件、激励源、支路、连接端 |
| 关系 | 位于、固定于、抵接 | **串联、电连接、跨接、接到某电极** |
| 作用面 | 进风侧、抵接面 | **电极节点**：串联支路集电极端 / 发射极端；各管自身的栅极与发射极 |
| 被测件 | 常是装置自身的一部分 | **功率单元不是检测装置的组成件**，只作接线对象（否则权1变成「柜子+工装」组合） |
| 禁止入集 | 使用时先拧后推 | **按下 S1、灯亮则…** 四步判据；改成电路上的「分别可通断」 |
| 上下位 | 母件与内部零件不可并列 | **检测回路**由直流电源与指示元件串联而成，不是与二者并列的第三只元件；通断手段是各栅极激励支路的内部构成 |
| 动词 | 连接 / 固定连接 | 独权用 **电连接**；绝缘夹、光纤插接下放 |

第 3 步仍是产品权：先列同级电路元件，再按电连接展开。不把「不拆开」「先按 S2 再按 S3」写进权 1。

## 1. 已确认的一句话与机制三栏

**一句话：** 在不拆开功率单元的前提下，用外接直流指示回路跨接串联功率开关支路的集电极—发射极端，并对该支路中各开关器件分别设置可独立接通的栅极激励支路。

| 技术问题 | 物理机制 | 技术效果 |
|----------|----------|----------|
| 串联支路未解体时无法对单管做栅极触发测量；解体耗时且易损伤。两端子电流分不出是哪一管坏。 | 外接直流电源与指示元件跨接串联支路两端，仅在该 C-E 通路导通时回路有电流。各管栅极激励分别可通断，形成不同激励组合；指示元件随组合改变通断状态，从而分解短路、能开通、不能关断。 | 功率单元保持装配即可判断各管开通、关断与击穿。 |

用户追加口径：按**电学案**组集与连缀，不套机械结构铺陈。

## 2. 一句话抽出的特征（含清楚化）

| 原词 | 入集用名 | 清楚化说明 |
|------|----------|------------|
| 功率单元 | 功率单元 | 被测对象；不列入检测装置「包括」清单 |
| 不拆开 | （不入集为工序）→ 由「外接」+「连接端接到保持装配状态的电极」承担 | 产品集不写拆装步骤 |
| 外接直流指示回路 | **检测回路**；由 **直流电源** 与 **指示元件** 串联构成 | 「指示回路」是交底口语；回路本身不是第三只元器件 |
| 跨接集电极—发射极端 | 检测回路两端分别电连接 **串联功率开关支路的集电极端** 与 **串联功率开关支路的发射极端** | 节点关系；两端是支路的高端 / 低端，不是某一管的任意电极 |
| 串联功率开关支路 / 各开关器件 | **串联功率开关支路**；其中至少两个 **功率开关器件** | 「各」不钉死两只；不钉 IGBT 型号 |
| 可独立接通的栅极激励支路 | **栅极激励支路**（与各功率开关器件对应）；**各支路分别可通断** | 不钉 S2/S3 微动开关；接通手段可以是开关或等效可通断连接 |
| 栅极激励（字面未写「源」） | **栅极激励源** | 一句话的「激励」要有电压来源，否则支路只是导线 |

同名须拆开的一对（否则不清楚）：

- **串联支路的发射极端** ≠ **功率开关器件的发射极**。前者是检测回路跨接的低端节点；后者是该管自己的发射极，栅极激励必须加在该管栅极与**该管发射极**之间。上管发射极是串联中点，不是支路低端。交底把两路都写成「E 极端子」接 HMD890 −DC，组集按电学原理取「各管 G–E」，不把「两路激励共地到支路底端」写入最小集（见推定）。

## 3. 完整方案支撑特征（一句话字面上没有）

| 特征 | 为何必不可少 |
|------|----------------|
| 检测装置（客体） | 一句话的外接工具；与功率单元不是同一物 |
| 连接端（集电极连接端、发射极连接端、以及与各管对应的栅极连接端） | 没有接线端口，检测回路和激励落不到未解体单元的电极上，「外接」说不圆 |
| 各栅极激励支路电连接在对应功率开关器件的**栅极与该器件发射极之间** | 没有管自身的发射极回线，Vge 无参考，激励机制不成立 |
| 功率开关器件具有栅极、集电极、发射极 | 电极名称的出处；否则「接到栅极」无所指 |
| 栅极激励源 | 见上；与直流电源角色不同（见同名检查） |

指示回路上的试灯开关 S1、限流电阻、光纤、HMD890、绝缘夹形状：不是机制成立所必需，见第 6 节。

## 4. 入集表与删一法

删一法只问：去掉后方案还能否实施，**以及**三栏效果（不解体即可用指示状态分解各管通断/击穿）是否还在。不问交底「20 小时 / 冷轧」声称问题。

### 4.1 入集

| 特征 | 来源 | 入集理由 | 若不入如何下放 |
|------|------|----------|----------------|
| 检测装置 | 支撑（客体） | 无此则没有外接工具这一技术方案 | — |
| 功率单元 | 抽出（接线对象） | 无被测对象则「外接」「不解体」无处落地；**不作为装置组成件** | 场景「冷轧抽屉」下放 |
| 串联功率开关支路 | 抽出 | 无串联支路则跨接 C-E 与分路激励无对象 | 钉死「上桥两管」下放 |
| 至少两个功率开关器件 | 清楚化「各」 | 一只管子不需要「分别」激励，分路组合机制不成立 | 钉死「两只」下放 |
| 功率开关器件的栅极、集电极、发射极 | 支撑 | 电极无出处则电连接句无所指 | — |
| 串联支路的集电极端、发射极端 | 抽出 | 检测回路跨接的两个节点；去掉则「跨接」落空 | — |
| 直流电源 | 抽出/清楚化 | 无电源则检测回路无电流 | 48 V / 电池 / 适配器下放 |
| 指示元件 | 抽出/清楚化 | 无指示则看不见通路是否导通，分解故障的效果没有 | LED / 灯泡 / 电流表形态下放 |
| 直流电源与指示元件串联构成检测回路 | 支撑（拓扑） | 指示元件若不串在该回路里，亮灭与串联 C-E 是否导通无对应 | — |
| 检测回路两端分别电连接串联支路的集电极端与发射极端 | 抽出（关系） | 关系当背景删掉则电源和灯与被测支路不相干，机制不成立 | — |
| 栅极激励源 | 清楚化/支撑 | 无激励电压则完好器件不能被开通，区分不了「能开通」与「栅极失效」 | 光驱板、脉冲发生器、隔离电源形态下放 |
| 与各功率开关器件对应的栅极激励支路 | 抽出 | 一句话的分路激励载体 | 钉死「两路」下放 |
| 各栅极激励支路分别可通断 | 抽出「可独立接通」 | 不能分路投切则形不成「均不激励 / 只激励部分 / 全部激励」组合，分解单管故障的效果没有 | S2/S3 微动开关型号下放 |
| 各栅极激励支路电连接于对应器件的栅极与该器件发射极之间 | 支撑（节点） | 电学作用部位；去掉则 Vge 不定 | 共地到支路底端的实施例接法不入集 |
| 连接端，用于接到保持装配状态的功率单元之集电极端、发射极端及各栅极 | 支撑 | 把「不拆开」改成产品上的接线关系；去掉则易被读成装置内部已焊死被测管 | 绝缘夹、电缆、插头形态下放 |

### 4.2 机制｜载体｜电路构成｜电连接节点｜下放

| 机制 | 载体 | 必须电路构成 | 必须电连接（节点） | 可下放的具体化 |
|------|------|--------------|---------------------|----------------|
| 串联 C-E 导通才有检测电流 | 检测回路 | 直流电源与指示元件串联 | 两端 → 串联支路集电极端与发射极端 | LED、48 V、可调电阻、S1 |
| 分路组合分解各管状态 | 栅极激励支路 | 与各管对应且分别可通断；有栅极激励源 | 各支路 → 该管栅极与**该管发射极**之间 | HMD890、光纤、微动开关 |
| 不解体即可接到电极 | 连接端 | 设于检测装置、相对功率单元外接 | 接到装配状态下的 C / 支路 E / 各 G（及各管 E，可经激励电缆） | 绝缘夹、线盘 |

## 5. 同名检查

| 名称 | 指什么 | 不得混用 |
|------|--------|----------|
| 检测装置 | 外接工具（权要客体） | ≠ 功率单元 |
| 功率单元 | 被测成套模块 | ≠ 串联功率开关支路 |
| 串联功率开关支路 | 单元内至少两管串联的那条 C-E 通路 | ≠ 检测回路 |
| 功率开关器件 | 支路中的单管 | ≠ 功率单元 |
| 检测回路 | 直流电源与指示元件串联而成的电流环 | 不要与电源、指示元件并列成三只元件 |
| 直流电源 | 检测回路的电源 | ≠ 栅极激励源（角色不同；实施例可用同一 48 V 给驱动板供电，最小集不要求两只独立电源箱） |
| 指示元件 | 串在检测回路里、随回路电流改变通断状态的元件 | ≠ LED |
| 栅极激励源 | 提供栅极驱动电压的来源 | ≠ 直流电源；≠ HMD890 |
| 栅极激励支路 | 从激励源到某一管 G–E 的、可通断的通路 | ≠ 检测回路 |
| 串联支路的集电极端 / 发射极端 | 检测回路跨接的两个节点 | 发射极端 ≠ 上管自己的发射极 |
| 功率开关器件的栅极 / 发射极 | 该管控制极与该管发射极 | 激励加在这两者之间 |
| 连接端 | 检测装置上用来接到上述电极的端口 | ≠ 绝缘夹 |

## 6. 未入集下放候选

**第 1 步已标宜下放、本步确认不入集：**

- 四步操作顺序与亮灭判词 → 方法次要组 / 说明书工作过程  
- 光信号发生器 + 光电转换驱动板（HMD890）→ 从权（一种栅极激励源形态，并可带测驱动板）  
- 绝缘夹形态 → 从权  

**本步删一法新下放：**

- S1、可调电阻、LED 具体、48 V、微动开关、两路钉死、冷轧 / 日立抽屉场景  
- 与效果无关、连从权可不占：线盘、AC 220 V 输入、红色、电缆长度、放电安全规程（说明书注意事项）

## 7. `[推定]`（组集用到的）

1. `[推定]` 各栅极激励加在**该管**栅极与**该管**发射极之间；不把交底「两路 −DC 共接到支路底端 E」当作必要拓扑。  
2. `[推定]` 栅极激励源与直流电源可以为同一物理电源经驱动电路变换，最小集只保留两个**角色**名。  
3. 第 1 步其余推定（R1/R3、HMD980、判据编号）仍只影响说明书与从权，不改变本最小集。
