# 【第3步 / 共7步】发明内容（技术问题陈述 + 有益效果）

## 技术问题陈述

本发明的目的在于提供一种一体化排泥井，以解决现有技术中排泥阀井与排泥湿井分建占地较大，以及放空水依赖就地溢流、在环境敏感区或周边未建市政污水管时出路不足的问题。

独权对应：竖向叠合同一井室 → 占地；泵水组件连通下游输水管 → 出路。地面涌水由权9解决，不写入本句。

## 有益效果

与现有技术相比，本发明的有益效果在于：排泥阀井与排泥湿井在同一井室内上下叠合设置，相较平面分建能够节省占地和开挖面；泵水组件将湿井内放空水排入下游输水管，使放空水以压力流进入仍在运行的管段，不依赖向附近水体或市政污水管溢流。

进一步地，在优选实施方式中，通过应急泵水组件和应急排水井，可将地面涌入排泥湿井的水排出（对应权9，不作为独权效果）。
