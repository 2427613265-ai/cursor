## 一、旧口径哪里错了

| 旧理解（已废） | 发明人实际逻辑 |
|----------------|----------------|
| 一根输水管；放空水压入**同一根管上隔离段以外的下游段** | **两根并行输水管**；一根检修时，把该管余水抽到**另一根仍在运行的管** |
| 「下游输水管」= 本管下游 | 「下游正常运行的管道」= **并行的那根在运管**（交底原词保留，含义按当面澄清） |
| 应急泵水组件 / 应急排水井 = 排地面涌入湿井的水 | **应急出水阀** = 控制泵出的放空水**排入哪一根输水管**（排入当时在运的那根） |
| 输水管上第一/第三阀门写入独权 | 发明人侧：**输水管上的阀门非必要**（代理人推测：用于选择排空该管上游侧还是下游侧余水） |
| 黄框当「地面涌水应急井」 | 黄框 = **应急出水阀井 / 应急排水阀井**：泵出水管在此用阀接到两根干管 |

附图对应（发明人平面）：**大方框 = 本案井室**（阀井叠湿井）；**黄框 = 应急出水阀井**；井室内泵出的水经灰管进黄框，黄框内阀门分别接入两根并行干管（图中蓝线与白线，箭头为干管流向）。

## 二、代理人优化口径（本轮独权按此写）

发明人图面是「井室 + 另建应急出水阀井」。代理人认为另建黄框井偏冗余。

**独权采用的优化方案：** 把应急出水阀井的选管功能**集成进井室**——应急出水阀设在井室内，泵水组件经该阀可选择地连通两根并行输水管中未检修、仍在运行的一根。

**从权再写：** 发明人原布置，即井室外另设应急出水阀井，应急出水阀设于该阀井内。

其余仍忠实交底：**排泥阀井在上、排泥湿井在下，同一井室竖向叠合**；检修时总闸关闭，管内余水经泄水管进湿井，再由泵加压送出。

## 三、交底书界定的技术问题（本步固定，不作重新界定）

**来源：** 交底书「现有技术的缺点及本方案要解决的技术问题」+ 发明人当面澄清「下游正常运行的管道」所指。

**交底主写问题（第一版锚点）：**  
在放空水出路存在明显问题的区域（如环境敏感区或周边未建设市政排水管道），如何设置排泥井，使排泥阀井与排泥湿井能够以上下结构建于同一井室，并将放空水以压力流方式排入下游正常运行的管道。

**发明人澄清（问题仍用交底原词，对象钉死）：**  
所述「下游正常运行的管道」= 与待检修输水管**并行的另一根、当时仍在运行的输水管**，不是同一根管上的下游管段。

交底将问题与手段写在同一段。本步固定需求层「出路困难时如何布置井室并解决放空水去向」；「上下叠合」「压力流进在运管」属手段，第3步再按「手段不进问题」剥离。

## 四、第一版拟覆盖的特征边界（非正式权要，仅防写偏）

**拟入独权（优化后骨架）：**

1. 井室；排泥阀井在上、排泥湿井在下，同一井室竖向分隔。
2. 两根并行的输水管（待检修的一根 + 当时在运的一根）。
3. 泄水管：把待检修输水管内余水导入排泥湿井。
4. 泵水组件：设于排泥湿井内，将湿井内放空水加压送出。
5. 应急出水阀：**设于井室内**；泵水组件经该阀连通两根输水管中未检修、仍在运行的一根，从而把放空水排入该在运管。

**明确不进独权（从权/说明书）：**

| 项 | 去向 | 理由 |
|----|------|------|
| 输水管上的阀门（旧权第一/第三阀门、垫块） | 从权 | 发明人：非必要；推测为选择排空该管上/下游侧 |
| 两根泄水管及阀组外侧位置、正三通 | 从权 | 附图细部 |
| 分隔层板、吊装口、集水坑、爬梯 | 从权 | 叠合/抽排细部 |
| **井室外的应急出水阀井**（黄框） | **从权** | 发明人原布置；独权已改为集成进井室 |
| 旧权「应急泵水组件排地面涌水」 | **删除** | 与发明人应急出水阀不是同一件事 |

**待确认（不脑补进独权）：**

- 井室是只穿一根干管、还是两根干管都进井室？（图面可见一根蓝线穿大方框；两根干管都接到黄框选阀。独权写「两根并行输水管 + 阀选排入在运管」即可，不必先钉死是否双管穿井。）
- 应急出水阀是两只分管两根干管，还是一只切换阀？（图为黄框内两只阀；命名表再定。）
