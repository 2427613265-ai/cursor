# 阀门是否为独权必要特征

## 用户当前独权

1.一种一体化排泥井，其特征在于，包括井室、泄水管、泵水管；所述井室包括排泥阀井和排泥湿井；所述排泥阀井叠合设置在所述排泥湿井上方；所述排泥阀井通过所述泄水管与所述排泥湿井连通；所述排泥湿井经所述泵水管与下游管道连通，以使放空水以压力流的方式排入所述下游管道。

## 锚定问题

出路受限下，压力排水管放空水如何可靠外排。

## 判断

| 反问 | 结论 |
|------|------|
| 去掉阀门，放空水能否仍经湿井、泵水管压入下游？ | 管路若常通，理论上能流，但无法选择性放空/隔断，不成可用的排泥井 |
| 「排泥阀井」名称能否代替写入阀门？ | **不能**——名称不产生阀门这一技术特征 |
| 是否属于解决出路问题的创造性骨架？ | 阀门多为排泥井惯常必要件；**完整可实施仍须写入**，否则阀井悬空 |

**结论：阀门属于必要技术特征，应补入独权**（与泄水管/阀井放空路径配合）。

## 建议补写位置（择一）

优先：阀门设于排泥阀井内，并设于泄水管上（或泄水管的放空通路上）。

## 顺带缺口（非本题但相关）

当前独权未写清放空水如何自**压力排水管**进入井/泄水管；若交底有接管，建议在独权补「泄水管（或阀井）与压力排水管连通」，否则进水端可能不完整。
