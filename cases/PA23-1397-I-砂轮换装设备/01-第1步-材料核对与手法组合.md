## 4. 对比文件客观教导（事实支点摘要）

### 对比文件1（CN212532072U）

- 领域/目的：建筑工地遥控塔吊，解决普通塔吊效率低、安全性差、占用空间大。
- 结构核心：固定座塔身 + 第一/第二旋转装置 + 可伸缩吊臂 + 液压推杆三角支撑吊臂仰角 + 卷扬机/吊绳提吊 + 地面遥控。
- 双吊臂实施例（[0035]）：左右对称两根吊臂，目的是平衡与同时吊更多建材，**不是**同一摆臂两端分设立式吊具与水平吊具。
- **未公开**：拆装平台、砂轮换装、龙门吊底端滑轮/地面滑轨、立式吊具、水平吊具、压紧盘件。
- 审查意见称“吊臂5的两端分别设置有两个吊具”——与说明书及附图不符（吊臂外端经吊绳提吊；双臂是左右对称两臂，非单臂两端双吊具）。

### 对比文件2（CN115849276A）

- 领域/目的：大型断路器极柱放平吊装方法。
- 结构：专用翻转机架 + 油缸驱动翻转平台 + L形支撑台板限位凹槽承托下法兰 + C字型夹持板夹持极柱；吊运工具为常规**行吊**，与翻转装置分立。
- **未公开**：龙门吊、摆臂两端立式/水平双吊具、滑轨行走、盘状砂轮的楔形垫块承托与柔性垫、砂轮换装工艺协同。
- “放置或翻转物件”仅为上位功能标签；其夹持对象为圆柱极柱/法兰，与盘状砂轮边沿承托的受力与定位逻辑不同。

- 对比文件1本已能完成建筑材料吊运，引入砂轮拆装翻转平台、改塔身为龙门吊滑轨、改吊绳为立式/水平专用吊具，会**整体改写其发明目的与结构范式**（固定塔身遥控塔吊 → 厂房内砂轮换装专机），并非在其原目标上“锦上添花”的小改。
- 审查员以“便于放置翻转”的普遍动机论证结合——属于**看似变好**的普遍动机说得通、但具体方案对不上。

**主攻递进链（短而真）：**  
纠正问题上位 → 还原对比文件客观教导（作用并非相同；D1双臂≠双取向吊具）→ 针对具体技术问题无技术启示 / 无合理结合动机 →（成立时）从“想改进吊装”到本案“龙门吊双取向吊具+可翻转拆装平台服务砂轮姿态转换”仍有鸿沟 →（成立时）拆核心+造新系统（须放弃D1塔吊核心与D2断路器夹持核心，再造砂轮换装专机）。

**不默认写**：结合必失败、听谁的、互斥物理冲突——本案更像领域错配与特征误认，硬写失败预期易显得强行。

## 7. 是否倾向修改 + 篇幅分配

**倾向：修改权利要求（情形一）。**

理由：  
1. 一通默认以一次答复争取授权为目标；审查员已断言“重新组合/进一步限定亦无前景”，更需把**区分度最高、审查员最难用常规手段带过**的特征成组并入独权，把创造性论证锚在修改后方案上。  
2. 原独权1被审查员拆成“吊+翻转平台+常见吊具”三块分别贴D1/D2/公知，孤点独权易被逐项击破；成组并入后才能形成“砂轮姿态转换专机”完整逻辑链。  
3. 具体并入哪些从权/说明书段落、范围宽窄平衡——**留待第2步**，本步不展开。

**一通篇幅分配：**  
修改说明 → 2.1（区别特征+技术问题+与审查员概括对比）为主体锚点 → 2.2内嵌A/B/C/D（及系统E）逐条答复 + 首先/其次/再次/最后归纳 → 2.3技术进步镜像问题 → 其他权利要求精选1～2项退一步防线。

预估2.2逐条答复条数 **K≈4**（B、C、D为主战场；A并入2.1；E并入系统相关条或作为第4条；从权误认在C/D条内带过权2/权9等关键误认）。
