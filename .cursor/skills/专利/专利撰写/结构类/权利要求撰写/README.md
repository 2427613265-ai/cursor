# 结构类·权利要求撰写

本目录从未删除。与方法类「权利要求撰写」被收束/恢复不同，结构类正文铺陈一直是下面两份。

## 分工

| skill | 管什么 |
|-------|--------|
| `结构类独权撰写` | 三版策略与 plan（经 `独权撰写` 分流进入）：核心区别一句话+关键创新点→组成最小集→第一版→审定技术主题并重新核定→第二版→再上位→第三版→可选变劣；第1～5步细则与方法案共用 |
| **`结构类权利要求撰写`** | 装置/结构独权及从权引入新部件时的铺陈：先总列**同级**再展开；**列名未展不得交付**；参与机制的部件须有关系/作用面；产品权禁止写使用过程。曾用名 `patent-structural-claim-drafting` |
| **`功能性限定使用边界规范`** | 默认用结构/位置/连接限定；仅当结构说不清或功能表述更清楚简洁时才用功能性限定；禁止效果性收尾 |

写某一版结构独权正文前，由 **`结构类独权撰写`** 必读 `结构类权利要求撰写`（列名未展不得交付；关系落地；产品权不写使用过程），按需读 `功能性限定使用边界规范`。对象名经 `部件命名优化总控`（结构案各版均开命名表）。

点名 **`结构类权利要求撰写`**（或「先总列后展开」「列名未展」「作用面」）→ 直读该页。

**禁止**把方法/算法案套进本目录的「先总列后展开」。
