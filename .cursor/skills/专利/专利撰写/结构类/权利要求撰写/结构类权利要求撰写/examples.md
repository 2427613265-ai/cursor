# 结构类权利要求撰写：正反例

配合 `结构类权利要求撰写`。例子只说明铺陈与关系怎么写，不是可抄模板。

## 从权 · 上下位（规则二）

```
……还包括输水廊道；
所述输水廊道为船闸既有充泄水廊道；
所述输水廊道包括阀门、出水口和侧支孔；
所述阀门控制所述出水口的通断；
所述出水口经所述侧支孔与所述船闸闸室连通。
```

顶层「还包括」只有廊道；阀、口、孔是下位。

**错误：** `还包括输水廊道、阀门、出水口和侧支孔` —— 子件与母件并列，部件树错了。

## 错误：边列边展开（规则一）

```
一种XX装置，其特征在于，包括外罩，所述外罩的内壁安装有风叶……
```

风叶未出现在总列句，层次乱。应先「包括外罩、风叶和……」，再展开安装。

列举句里夹带连接同样不行：先「包括固定套筒和旋转接头」，再分句写固定连通、可转动插接。

## 错误：列名未展（规则一）

总列了底板、侧板、背板、三块锚板和加劲板，后文只写三块锚板轴向布设。底板、侧板、背板、加劲板无位置/连接 → 不得交付。须逐件至少一句焊接或设置关系。

## 错误：只写部件、不写关系（规则三）

```
一种散热装置，包括壳体、风机、翅片组和导流板。
```

四件互不相干，第1步「截面积增大→横向扩散」无处落地。

**改：** 总列后写 `所述导流板设置于所述风机与所述翅片组之间`，并写清流道截面积沿流向增大。喇叭形、夹角进从权。

## 错误：作用面写丢（规则三）

```
所述导流板设置于所述风机与所述翅片组之间。
```

关系有了，但气流铺开发生在导流板进风侧与翅片组进风端面。机制要求写作用面时，补 `所述导流板的出风侧朝向所述翅片组的进风端面`（用语按交底核实）。

## 错误：产品权写成使用过程（规则四）

```
一种夹紧装置，包括……，其特征在于，使用时先将工件放入所述卡爪之间，然后旋转所述手柄使所述卡爪合拢，从而夹紧工件。
```

**改：** `所述手柄与所述卡爪通过螺纹副传动连接，所述螺纹副被配置为将所述手柄的转动转换为所述卡爪沿所述导轨的相向移动。`

要保护操作顺序，另写方法独权，不要塞进产品权1。

## 动词宽窄（规则五）

独权 `所述支架与所述底座转动连接`；从权再写 `通过铰接轴铰接`，再从权 `所述铰接轴上套设有扭簧`。独权直接写「铰接轴＋扭簧」会把范围钉死，除非那就是区别点。
