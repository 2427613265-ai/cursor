# 结构类权利要求撰写：总列展开 + 关系落地

## 适用场景

- 撰写「一种XX装置/机构/系统」等**产品**独立权利要求。
- 从权一次性引入**新部件**（含「还包括…」，尤其两个以上或带内部构成）。
- **不适用**方法类（按步骤写，禁止套本页「先总列后展开」）。

**挂接：** `结构类独权撰写` 写各版正文前、以及 `从权撰写` 引入新部件时必读。点名本 skill /「先总列后展开」「列名未展」「关系完整性」「作用面」时**直读本页**。不代替三版策略。正反例见同目录 `examples.md`。

**曾用名：** `patent-structural-claim-drafting`。

**配套：** 功能/效果表述见 `功能性限定使用边界规范`；对象名走 `部件命名优化总控`。第1步机制三栏见 `核心区别技术特征确定`；组集时的载体/关系见 `最小技术特征集与第一版独权`。本页管**落笔句式**。

## 核心规则

### 规则一：同级先总列，再展开

在「其特征在于」（或「XX包括」）之后，**先用一个独立分句把本层全部同级部件一次性列全**（如「包括外罩、风叶和降尘组件」），句末即止，**不得夹带**内部结构、连接或位置。

列完后再按清单顺序逐件展开：位置、连接、自身结构。部件还有子件时**递归**：先列子件清单，再展开。

**列名未展＝不得交付：** 清单中每一件后续须至少有一句位置、连接或自身结构。只出现在「包括A、B和C」里、后文无呼应的，不得交付。从权须能勾选「已逐件展开」。

### 规则二：同级并列 ≠ 上下位归属（硬性）

落笔「包括 / 还包括」前先画部件树。

| 关系 | 正确 | 错误 |
|------|------|------|
| **同级** | `包括A、B和C` 或从权 `还包括A和B` | — |
| **上下位**（B、C 是 A 的内部构成） | 本层只列 **A**；展开写 `所述A包括B和C` | 把子件与母件同句并列 |

自检：清单每一项是本层独立对象，还是已列母件内部的零件/孔口/阀门？后者只能写在「所述母件包括…」下。从权顶层「还包括」只列本层新母件/同级件。

区分两种「包括」：`所述A包括B和C` 是**组成**；`所述A与B连接` 是**装配**。层级写乱则不清楚。

### 规则三：关系完整性与作用面（硬性）

总列解决「有哪些件」；**关系**才是技术方案。审查指南：技术特征也可以是要素之间的相互关系。

1. **参与第1步机制的部件，展开时至少一条位置或连接关系**，把它锚定在方案里。只写「包括壳体、风机、翅片组和导流板」互不相干，机制不成立，即使每件都有自身形状也不算展开合格。  
2. **机制发生在特定面或部位时必须写作用面**（进风侧、抵接面、出风端面等）。只写部件之间「设置于……之间」而不指明作用部位，会出现「关系写了但机制仍不必然成立」。  
3. 与机制无关的纯容器/机架，有一条安装关系即可；不得为凑关系把实施例螺丝、焊缝写进独权（具体连接方式进从权，见规则五）。

本条与规则一不冲突：总列句仍不夹带关系；关系写在**展开句**。

### 规则四：产品权利要求禁止写工作过程（硬性）

保护主题是产品，不要写「使用时先……然后……从而……」。动作步骤对产品权的限定取决于它是否带来结构/配置；把使用过程写入产品独权既不扩大范围，还可能被解释成附加限定。要保护使用过程，另写方法独权。

需要表达运动能力时，写成结构或被配置关系，例如「所述手柄与所述卡爪通过螺纹副传动连接，所述螺纹副被配置为将转动转换为相向移动」——这是结构，不是操作规程。功能/效果收尾边界见 `功能性限定使用边界规范`。

### 规则五：关系动词独权取宽、从权取窄

| 类型 | 宽（独权优先） | 中 | 窄（从权） |
|------|----------------|----|------------|
| 位置 | 设置于、位于、朝向 | 贴合、间隔设置、沿……延伸 | 抵接、嵌设、呈××夹角 |
| 固定 | 连接 | 固定连接 | 焊接 / 螺纹连接 / 卡接 |
| 活动 | 活动连接 | 转动连接 / 滑动连接 | 铰接 / 经滑轨滑动连接 |
| 流体 | 连通 | 密封连通 | 经管路连通 |

独权用宽档，除非该窄写法本身就是区别点。从权沿同一关系逐级收窄，这是从权第一条产线。不用「若干」（含义不确定）；数量「两个」「多个」独权慎用。

### 规则六：两段式划界（可选，不强制）

现有技术清楚、能干净划出共有特征时，可用前序（主题 + 与最接近现有**共有**的必要特征）+「其特征在于」+ 特征部分（贡献）。**禁止把发明贡献划进前序**。改进是整体性的、或未检索（第1步已写盲判）时，用规则一的不分段总列。不另开独权步骤，不要求每案划界。

## 短示范（总列后展开且关系落地）

```
一种XX装置，其特征在于，包括外罩、风叶和降尘组件；
所述风叶安装在所述外罩的内壁；
所述降尘组件设置在所述风叶的一侧，所述降尘组件包括环管和多个内喷雾管；
所述环管同轴设置在所述风叶的出风侧；
多个所述内喷雾管呈放射状固定连通于所述环管的内壁，每个所述内喷雾管的管壁上开设有多个内雾化孔；
所述内雾化孔的开口方向与所述风叶所在平面之间形成有夹角。
```

上下位、列名未展、只列部件不写关系、作用面丢失、误写使用过程：见 `examples.md`。

## 检查清单

- [ ] 「其特征在于」后第一句已用「包括A、B和C」列全本层**同级**部件，且未夹带结构/关系  
- [ ] 未把母件内部零件与母件并列；从权「还包括」未抬子件  
- [ ] 总列每一件均已展开；有未展项 → **不得交付**  
- [ ] **关系：** 参与机制的部件展开句中有位置或连接；不是互不相干清单  
- [ ] **作用面：** 机制发生部位已写出（无需作用面的写「无」）  
- [ ] **产品权未写使用步骤**；运动能力已改成结构或被配置关系  
- [ ] 独权关系动词取宽档，除非窄写法本身是区别点  
- [ ] 展开顺序与总列顺序一致
