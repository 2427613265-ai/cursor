# 清楚性与逻辑一致性共用内核

> **本文件是规则唯一源。** `权利要求清楚性与逻辑一致性规范` 与 `说明书具体实施方式清楚性与逻辑一致性规范` 只保留对象差异与挂接；六条共性规则以本内核为准。  
> 不作为用户说「质检」时的直触入口。

将下文「检查对象」替换为：**权利要求文本** 或 **说明书具体实施方式叙述**（由调用方 skill 指定）。

## 规则一：孤岛特征

**定义**：某技术特征（部件、参数、步骤/动作）只出现一次——前文无铺垫、后文无再利用/依赖/连接配合，像孤岛游离于方案之外。

**例外（勿轻易判孤岛）**：
- **公知术语**（如螺栓、电机、处理器/控制器）
- **暗含于紧邻后续操作**（如「设有转轴」后紧跟「绕所述转轴转动」），或在另一申请文件部分已有完整呼应

**判定**：对该特征三问——后文还有没有用到？是否公知？作用能否从紧邻上下文直接看出？三问皆否 → 孤岛。

**处置**：勿擅自删除；先区分「漏写呼应」还是「本身不必要」，向用户说明。

## 规则二：突然出现且非客观清楚物理量

- **客观清楚物理量**（长度、角度、温度、转速等）：可不额外定义。
- **人为定义词**（调节比、覆盖系数、响应等级等）：首次使用须有明确界定/计算方式，否则不清楚（权要侧还须权要内就地定义，见调用方）。

**判定**：每个「量/比例/系数/等级」先问是否本领域公知物理量；若否，查是否已定义。

## 规则三：模糊或含义不确定用语

避免无客观边界的表述（大致、左右、明显、较好、合理、适当等），除非文本给出可量化或可判断标准。

**判定**：程度副词/相对形容词 →「边界在哪？本领域能否据此准确判断？」

布置/排列类口语（如「对称错位」）亦属边界不清：此为**非名称**，调用方可直挂 `交底口语名改写为自明结构名规范` / `自定义名词就地定义`。拟入权**名称**不自明则走 `部件命名优化总控`，不要在本页直跳执行叶。

## 规则四：歧义与反例

- **歧义**：同一表述可解读出两种以上不同技术含义。
- **反例**：能构造字面符合描述、但达不到声称效果、或机构按字面无法正常工作/明显不是发明想保护的情形。

**判定（反例测试）**：读完后尝试构造「按字面却行不通/违背发明目的」的场景；能构造则须补限定或改表述。

## 规则五：清楚、简洁

- 避免无谓重复与修饰堆砌；一段/一条 ideally 一个核心意思。
- 同一技术点勿在多处用不同句式反复强调致需来回对照。
- 每个特征应只有一种自然理解；读完能直接构建结构/流程。

**判定**：若需读两遍以上才能确定修饰对象 → 不够清楚简洁。

## 规则六：物理/数学常识与前后逻辑

- **违背常识**：物理上不可能或量纲/数学关系明显错误。
- **前后矛盾**：同一文件不同位置、或权要↔说明书、或从权↔其所附权利要求之间互相排斥。

**判定**：查量纲与数量级；核对同一部件/参数多处描述是否可同时成立。

## 共用检查清单（调用方按对象改写措辞）

- [ ] 有无孤岛特征（或属公知/暗含例外）？
- [ ] 有无未定义的人为术语（非客观物理量）？
- [ ] 有无无客观边界的模糊用语？
- [ ] 能否构造反例？有无歧义表达？
- [ ] 是否清楚简洁、少冗余？
- [ ] 是否符合物理/数学常识？有无前后矛盾？
