# 从权分层次布置（正反例）

本页配合 `从权分层次布置`。例子只说明层次与代入，不是可抄的权要模板。

## 例：关键创新点逐层落实

独权第1步关键创新点＝「用预先设定的解锁触摸动作，把触摸屏设备从锁定切到工作」。独权已概括为预定触摸动作；滑动轨迹、起终点、图像随手指移动等是实施例保底。

### 错误 A：一条塞完

权2同时写入「沿预定轨迹滑动 + 解锁图像随手指移动 + 轨迹须过屏幕中点」。后面权3～权10全是无关边角。关键创新点没有层次，无效时一刀切到独权。

### 错误 B：独立改进硬串联冒充分层

权2写滑动解锁，权3在权2下加「还包含加密模块」，权4在权3下加「外壳防摔」。加密、防摔与解锁层次无关，应平行引权1。

### 正确

- 权2（引权1）：解锁触摸动作为沿预定轨迹的滑动（主干层）。  
- 权3（引权2）：滑动过程中预定图像随触摸点移动（再具体）。  
- 权4（引权1）：与解锁无关的独立改进，平行。  

## 例：假想代入被引用权全文

权1已有「触摸屏设备处于锁定状态」。权2（引权1）增加「接收预定解锁触摸动作」。

### 错误

写权3（引权2）时只盯着「再限定轨迹形状」，忘了代入后方案里设备仍须处于锁定、且须能切到工作状态，结果权3写的前置与权1锁定状态矛盾，或使用了权2并未引入、权1也没有的部件名。

### 正确

写权3前先在心里展开：锁定中的触摸屏设备 + 接收预定解锁触摸动作 + 本条要加的轨迹限定。确认轨迹是对「预定解锁触摸动作」的加细，锁定/切换仍接得上，再落笔「根据权利要求2……」。

## 例：树状而非链状

权1为散热装置。可独立细化的方向：导流板形状、翅片间距、风机安装、壳体材料。

### 错误

权2导流板 → 权3在权2下加翅片间距 → 权4在权3下加风机 → 权5在权4下加材料。想只用「材料」回退时，被迫带上导流板+间距+风机全部限缩。

### 正确

权2、权4、权6、权8均引权1，各起一个一级分支；形状再具体串在权2下（权3），间距串在权4下（权5）。互不牵连。

## 例：方法参数三档梯度

独权已写固溶温度 480℃～560℃（L1，能实施最宽边界）。

### 错误

从权直接写「温度为 520℃」。对比文件公开 490℃ 时独权倒下，中间区间 500℃～540℃ 从未出现，专利法第 33 条不能再概括进去。

### 正确

- 权2（引权1）：500℃～540℃（L2，效果显著区间；端点已写入）。  
- 权3（引权2）：520℃（L3，实施例点值）。
