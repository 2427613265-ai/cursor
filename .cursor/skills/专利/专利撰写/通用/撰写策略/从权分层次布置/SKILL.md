# 从权分层次布置（核心权利要求组的从权）

`从权撰写` **第2步布局、第3步逐条写**必读。正反例见同目录 `examples.md`。只管**核心独立权利要求**下面的从权怎么分层、怎么想；门禁、形式、依附编号仍走 `从权撰写`。次要独权组见 `次要权利要求组撰写`。

从权撰写复杂，本页只抓布局骨架。其余注意点仍用从权撰写已有门禁，不在此另开长文。

---

## 三个重点（硬性）

### 1. 关键创新点是从权的重点，须逐层落实

独权第1步的**关键创新点**（立地，见 `核心区别技术特征确定`）默认作从权保底，是本核心组从权的**主骨架**，应当通过从权**逐层**写进去，而不是一条从权塞完、也不是只拿边角下放组铺满费用预算却把关键创新点晾在一边。

**逐层：** 先写较宽的一层（权2常接关键创新点的主干），再在其下加更具体的一层（结构细部、参数、路径、优选配合）。独权阶段「宜下放 / 未入最小集 / 第二版剔出」的种子，按所附属的层次挂到对应从权，不要打乱层次去平行堆。

**不是：** 把彼此独立的改进点硬串联成一条链冒充分层。独立改进仍须**平行**引同一合适基础（多为权1）。平行/串联判定见 `权利要求引用结构检查`；本页管「关键创新点要分层占位」，不替代该检查。

### 2. 树状而非链状

布局默认是**多条一级从权都直接引权1**，各成独立细化方向；同一方向的加细才串联成该分支的二级、三级。

```
链状（禁止当默认）           树状（默认）
1                            1
└─2                          ├─2 ── 3        （关键创新点主干→再具体）
  └─3                        ├─4 ── 5        （另一独立维度）
    └─4                      └─6 ── 7        （参数/材料等）
      └─…
```

链状下靠后的从权自动带上前面全部限缩；答辩时只想并入后面某特征，也被迫接受前面全部，范围塌缩极快。树状下各一级分支互不牵连，可组合的中间方案更多。

**做法：** 针对独权每一个可独立细化的方向，各起一个直接引权1的一级从权，再在其下延伸二级、三级。一级数量 ≈ 可独立细化的维度（机械案常见 3～6 个）。关键创新点主干通常占权2（引权1），其再具体层串在该分支下。

多项从权可用于分支末端汇总（`根据权利要求1至4中任一项所述的……`）；该项之后不得再被另一项多项从权引用（`权利要求形式合规性规范`）。

平行/串联的判定仍走 `权利要求引用结构检查`；本条禁止的是「把整份从权写成一条长链」。

### 3. 每一条从权都是一个独立的技术方案

引用某一条权利要求只是**简化写法**。思考时、组织语言时，都应当把被引用权利要求（及其引用链一直到权1）的内容**以假想方式完全代入**，再展开本条要加的特征。

写完后在心里把引用链拼成一份完整方案：须仍能独立实施，本条新特征接得上、不缺前提、不与已有特征矛盾。句子可以只写「根据权利要求X……，其特征在于……」，但不得把本条当成悬空片段来想。

## 方法案：参数三档梯度

工艺/有数值范围的方法案，创造性争议常落在参数上。同一参数拆成三档、分置三项（L2/L3 在从权；L1 在独权已有则从权从 L2 起）：

| 档 | 落点 | 写什么 |
|----|------|--------|
| L1 | 独权（若该参数已入独权） | 能实施的最宽边界 |
| L2 | 从权（效果显著区间） | **中间层端点必须写入文本**（进从权最好，说明书「优选」次之）；否则专利法第 33 条答辩退不到该中间范围 |
| L3 | 从权（点值） | 最佳实施例点值 |

L2 引含 L1 的权，L3 引 L2，成为该参数分支上的串联。多参数可同步收窄（同一从权）或分置不同从权以增加组合。无数值范围则本项写「无」，不必硬凑。

附加步骤须写明插在 `Si` **之前/之后**，不要只写「还包括清洗」。方法从权主题名称仍是「方法」，不要写成装置。

## 布局时怎么用（第2步）

1. 在布局表标出：哪几条落实关键创新点的第几层（主干 / 再具体 / 再优选）；**哪几条是直接引权1的一级分支**。  
2. 关键创新点占位**优先于**边角诱鱼、纯说明书细部。独权下放组仍强制入库；与关键创新点冲突时，先保分层骨架，其余合并或进暂缓。  
3. 同一关键创新点的加细 → 串联；与之无关的独立改进 → 平行引权1（或同一合适基础）。**禁止**权2～权10默认画成一条长链。  
4. 方法案有数值范围 → 参数分支按上表占 L2/L3；端点未入独权也未拟入从权的，标「待写入说明书优选」并说明法 33 条风险。  
5. 核心组默认按 **10 项费用预算**排权2～权10（见 `从权撰写`）；层次不够用则加条须改表再确认；为次要独权让位可少于 9 条从权，须标明让出的项给哪一组。不得把两层无关的加细塞进同一条从权充数。  
6. 最可能用作回退的特征放编号靠前（权2、权3常先被审查员评价）。限定同一部件/同一参数的从权相邻排。

可细化方向只作助判，**不**要求每层都写满：结构常见连接下位、部件结构、附加件、参数/材料；方法常见子步骤、参数梯度、实现手段下位、附加步骤。整机/对侧主体通常是**并列独权**，不塞进核心组从权（见 `次要权利要求组撰写`）。

## 逐条写时怎么用（第3步）

写权 N 前：用一两句复述「代入后的完整方案是什么」（可极短，但须真代入）。再写本条新增特征。交付时勾：「已假想代入被引用权全文」。

**过窄：** 关键创新点整份堆在权2，后面从权与保底无关；或该平行的独立改进被串进关键创新点链；或整份从权一条长链。  
**过残：** 只写引用号、不代入，本条特征与权1/被引权接不上或矛盾；方法参数有中间范围却从未写入文本。

## 禁止

- 用边角特征占满费用预算，关键创新点未逐层落实。  
- 默认链状布局（权2→3→…→10 一条龙）。  
- 以「引用了权X」代替假想代入。  
- 把独立改进硬串联冒充分层。  
- 方法参数中间端点既不进从权也不进说明书，却指望答辩时再概括。  
- 同批写次要独立权利要求组。
