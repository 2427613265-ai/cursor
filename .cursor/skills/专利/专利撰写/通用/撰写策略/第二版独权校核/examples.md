# 第二版校核：新主题下对齐与再删减（正反例）

本页配合 `第二版独权校核`。例子只说明**校核顺序**，不是可抄的权要模板。

## 例：触摸屏解锁（主题已改为「触摸屏设备」）

**第4步已确认：** 技术主题＝一种触摸屏设备的解锁方法。  
**第一版（摘要）：** 一种触摸屏手机的解锁方法，包括：所述触摸屏手机处于锁定状态，接收对触摸屏的触摸动作；……将所述触摸屏手机切换到工作状态。

### 错误 A：只改前序

第二版写成「一种触摸屏设备的解锁方法」，特征里仍处处「所述触摸屏手机」。主题与特征对不上，保护仍像钉在手机上。

### 错误 B：改完用语就交差，不再删减上位

全文「手机」已换成「设备」，但第一版里若还留着仅手机才有的钉死（例如依赖通话键、蜂窝模块），新主题下并不合适；组集时漏掉的，本步还能查出。

### 正确

1. **用语对齐：** 前序与特征中的「触摸屏手机」全部改为「触摸屏设备」。  
2. **新主题下是否合适：** 锁定/工作状态、触摸动作、预先设定的解锁触摸动作不依赖「手机」，保留；仅手机才有的特征删除或下放。  
3. **再一次删减/上位：** 对着核定问题再问能否更宽（例如不必钉死某一种手势形状）。  
4. 第二版前序与正文统一为触摸屏设备，方案仍完整可实施。

## 例：内燃机运动机构（主题已改为转换机构）

第一版标题已是「一种往复-旋转运动相互转换的机构」，正文若仍写「内燃机气缸」「燃烧室」，等于主题没落地。第二版应改成该机构自身所需的往复侧/旋转侧构件；内燃机专有部分能删则删、能上位则上位。
