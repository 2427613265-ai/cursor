# 第二版独权校核

**步号：** 结构案 plan 第5步；方法案 plan 第6步。主题/问题须已确认（结构案第4步、方法案第5步）。正反例见同目录 `examples.md`。本步写出第二版全文；核心独立权利要求是权要的重中之重，**必须再校核一遍**，不得因「组最小集时已经考虑过」而跳过。

审主题那一步只定主题和问题，**不**改写权要。本步才在新主题、新问题下改第一版。

---

## 为何要再校核

第一版是在原主题下连缀出来的。主题一变，正文里仍可能留着旧主题的钉死词（前序已改成「触摸屏设备」，特征里还在写「触摸屏手机」）；有些特征在新主题下不再合适；删减、上位在组集时做过，再想一遍往往能查出新问题。

---

## 操作（顺序硬性）

1. **全文对齐新主题用语。** 不只要改前序「一种××」。凡第一版中仍指向旧主题的词，一律改成与审定主题一致（触摸屏手机 → 触摸屏设备）。主题未改则本项写「无改」。这是校核，**不是**方法案第6步的命名总控优化。  
2. **问：新主题下这些特征还合适吗？** 换到新主题所覆盖的对象上，该特征是否仍成立、是否把范围又钉回旧领域？不合适则删、概括或下放。  
3. **再一次删减、上位。** 对着已核定的技术问题，问去掉或改宽后问题是否仍解决、方案是否仍完整可实施。组集时考虑过的，本步仍要再问。去非必要走 `独立权利要求必要技术特征检查`（该检查可自建 plan；主题用语对齐与「是否合适」须在其前或并入其第1步，不得只改前序就交第二版全文）。  
4. **写出第二版。** 前序用审定后的主题；特征与之对应；保留最小区别骨架。  
5. **三句闸（交付前，各一句结论；不得写成六道检验报告）。** 未命中的域写「无」。过不了则改第二版后再交，不另开校核步。

**过窄：** 只改标题，正文仍写旧产品名；或该删的钉死路径没删。  
**过残：** 为扩围抽空到无法实施，或不清楚。

### 三句闸

1. **闭门造车。** 盖住说明书只看权1。结构案：能否据此画出装配关系（部件落点、作用面）？方法案：能否据此排出工序表（每步输入来源与产物）？不能 → 缺关系或 I/O，补进独权或回最小集。某特征删了仍能画/能排，且核定问题仍解决 → 冗余，下放。  
2. **因果链。** 倒读第1步三栏：效果 ← 机制 ← 权1里哪个特征？链上缺环必须补；链外特征下放；链完整却依赖权1未写的默认工况/材料 → 该前提是漏掉的必要特征。至少有一个区别特征落在这条链上，否则创造性会退化成「替代方案」。  
3. **物理自洽。** 按案型只核命中项：力/热/流体/电/物料是否从哪来到哪去；结构有无连接矛盾或运动说不通；方法有无因果倒置、循环无出口；多参数时角点（全上/全下/交叉）会不会使方案失效。不通则改特征或加关联限定，不靠说明书口头补。

清楚性用语（孤岛、模糊词）仍走 `权利要求清楚性与逻辑一致性规范`；本闸管「做不出来 / 效果无落点 / 物理上不通」。必要特征检查筛「多」，与本闸同批勾选，不另开报告。

## 写正文前（类型分流）

| | 方法/算法案 | 结构/装置案 |
|--|-------------|-------------|
| 校核顺序 | 上表 1→5 | 同左 |
| 必经 | `方法类权利要求具体撰写规则总控` → `方法类权利要求专有细则`（本版：第一节含骨架/单侧/约束、第六节命名、第三节路径/不变量、第二节、第五节；闭环案加第四节）+ `独立权利要求必要技术特征检查` | `结构类权利要求撰写`（含关系/作用面、产品权禁止使用过程）+ `独立权利要求必要技术特征检查` |
| 命名 | **本案唯一一次命名优化**：经总控 → 专有细则第六节 → `部件命名优化总控`；对照表确认前不得写第二版正文（结构案可拆 5a/5b，方法案可拆 6a/6b）。主题用语对齐 ≠ 本项 | 先 `部件命名优化总控` 交相对第一版的对照表（尤其清材料/场景钉死），**确认前不得输出第二版全文** |

方法案非区别输入宜「获得/获取××」，具体获得步骤进从权；区别性获得不得误省。

## 交付格式

1. **锚定**：已确认的审定主题 + 核定问题。  
2. **用语对齐表**：旧主题用词 → 新主题用词（须覆盖前序**和**特征；无改则写明）。  
3. **新主题下不合适者**（删 / 概括 / 留 + 一句理由）。  
4. **再一次删减/上位**（相对第一版；标出本步新发现 vs 组集时已拟删）。  
5. **第二版独立权利要求全文**。  
6. **对照**：删除 / 概括 / 下放清单。  
7. **三句闸**（各一句）：闭门造车｜因果链｜物理自洽（未命中写「无」）。  
8. 标注「**第二版独权（新主题校核 · 无非必要特征）**」（方法案可补「命名已优化」）。

---

## 禁止

- 未确认审定主题与核定问题即写正文。  
- 只改前序，正文仍用旧主题用词。  
- 以「第一版已经考虑过」为由不做再一次删减/上位。  
- 三句闸未过仍交付；用六道检验长表代替三句闸。  
- 同批倾倒从权全文或结构案第三版。  
- 为扩围编造交底无启示的新手段，或抽空最小区别骨架。
