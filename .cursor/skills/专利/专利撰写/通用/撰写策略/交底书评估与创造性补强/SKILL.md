# 交底书评估和独权初步撰写（已退役）

本 skill **已退役**，勿再按旧五步流程执行。

## 为何退役

原「交底书评估和独权初步撰写」与 `交底书技术方案理解`、`独权撰写` **职责交叠**（入口总览、体检、理解转入、初版独权、主问题清单分散在三处），导致 plan 编号混乱、阶段边界不清。现已拆为两个主 skill：

| 原职责 | 现归属 |
|--------|--------|
| 浅显可写性确认、全流程总览 plan、体检 | `交底书技术方案理解` 第1～2步 |
| 白话读懂（名片/场景/构成/过程/创新点） | `交底书技术方案理解` 第3～6步（含主问题候选） |
| 交底书第一版～第三版独权、重新界定问题、可选创造性、收束 | `独权撰写` 第1～8步（三版递进，总览 2.1～2.8） |

## 拿到交底书后应怎么做

1. **入口**：打开并执行 `交底书技术方案理解`（第1步即输出新的两阶段总览 plan）。
2. **读懂并确认可写独权后**：转入 `独权撰写`，从 **2.1 交底书初版独权** 开始。
3. **可选创造性**：仍用 `创造性评估与独权补强`，位置在独权撰写「按主问题修订」之后、「再上位」之前。

详见同目录 `README.md` 中的推荐调用顺序。
