# 递交独权变劣与从权回退（第三版之后 · 可选）

## 适用场景

- 已完成 `独权撰写` **第三版独权**（或用户已确认的同等「定稿独权」）。
- 用户希望：**递交用的权1比定稿更宽**，定稿里更优/更具体的限定不扔掉，而是进从权退守。
- 典型触发语：「变劣一下再递交」「定稿进从权、递交独权放宽」「整体式进独权、分节进从权」「递交稿比第三版再宽一档」。

## 核心思路（先读懂再动笔）

| 称谓 | 含义 |
|------|------|
| **定稿独权** | 第三版（或用户指定的定稿）：清楚、范围已经过三版策略打磨的那一版 |
| **递交独权** | 在定稿基础上**再去掉或改宽一层「改进限定」**后的权1，用于正式递交 |
| **变劣 / 放宽** | 代理出口语：不是写成不能用的劣解，而是让权1覆盖更上位/更简化的实现，保护面更宽 |
| **从权回退** | 定稿相对递交独权多出来的特征，**成组**写入从权，作创造性/无效程序中的退路 |

**一句话：** 定稿保质量 → 递交权1再放宽抓范围 → 定稿多出的改进进从权保退路。

## 在总流程中的位置（硬性）

```text
…… → 第三版独权（定稿）
        ↓
【本 skill · 可选】递交独权变劣与从权回退
        ↓
独权撰写 · 收束（正式稿默认=递交独权；未做本 skill 则=第三版）
```

- **不得**在第二版或第三版未完成时做本 skill。  
- **不得**用本 skill 替代第三版命名/清楚性优化（那是第三版的事）。  
- 本 skill 结束后返回 `独权撰写` 收束步，不自动开写说明书。

## 能力边界

- 产出：递交权1全文 + 从权回退组（可列数条示例从权，非完整从权树强制一次写完）。  
- 不得编造交底未记载且未经确认的新结构；变劣只能是**去掉/上位定稿已有限定**，不能换成另一套发明。  
- 递交权1仍须构成**完整可实施**方案，并保留足以识别发明贡献的最小骨架；禁止宽到纯公知组合、无法与现有技术区分。  
- 形式与表达仍遵守结构类先总列后展开、主谓宾、指代、自定义名词就地定义等通用规范。

---

## 输出控制（plan 硬性）

必须用 TodoWrite 等同步；一步一交付；始终一个 `in_progress`；格式 `【第X步 / 共N步】`。

### 固定 plan（共4步）

```text
第1步 锁定定稿独权 + 标出可变劣特征清单【须用户确认变劣点】
  ↓
第2步 撰写递交独权（放宽后的权1）
  ↓
第3步 成组从权回退（定稿改进 → 从权）
  ↓
第4步 对照表 + 风险提示 + 返回独权撰写收束
```

- 第1步未确认变劣点 → **禁止**写递交独权。  
- 禁止第2步与第3步合并成一次超长倾倒（可同轮先交递交独权，确认后再交从权组）。

---

## 第1步：锁定定稿 + 可变劣清单

1. 复贴或引用**定稿独权**全文（默认=第三版；用户另指定须写明）。  
2. 列出定稿中每一类「可下放的改进限定」，并建议变劣方式：

| 类型 | 定稿中的样子 | 变劣后进递交权1的常见写法 |
|------|----------------|---------------------------|
| 结构分型/分节 | 叠梁门 = 挡水门节 + 输水门节 | 整体门体 / 上游门体（不强制分节） |
| 安装依托 | 设于既有检修门槽 | 独权不写门槽；从权再写既有门槽 |
| 位置优选 | 输水门节在最下方 | 独权不写；从权写最下方 |
| 材料/驱动/阀型 | 电动球阀、钢制等 | 上位为流量调节阀等 |
| 数量/并联 | 多管并联 | 独权保留「至少一根」；多管进从权 |
| 运行能力 | 闸门可开启连通等 | 按案情决定留独权或进从权 |

3. 标注「**待确认：拟变劣点**」——哪些进递交权1放宽、哪些必须留在递交权1（最小骨架）。  
4. **须用户确认**后再写第2步。

**交付物：** 定稿定位 + 可变劣清单 + 建议保留的最小骨架。  
**禁止：** 同批输出递交独权全文、完整从权。

---

## 第2步：递交独权

按已确认的变劣点重写权1。

**硬性要求：**

1. 比定稿**更宽**（限定更少或更上位），不得比定稿更窄。  
2. 方案完整可实施；主谓宾完整；结构类仍先总列后展开。  
3. 自定义名词就地定义。  
4. 标注「**递交独权（定稿变劣稿）**」。  
5. 附：相对定稿删除/上位对照（一条一条对应）。

**交付物：** 递交权1全文 + 与定稿对照。  
**禁止：** 同批倾倒全部从权树；抽掉最小创造性骨架导致权1无法区分现有技术（若风险高，须在正文写明并请用户确认是否继续）。

---

## 第3步：从权回退

把「定稿有、递交权1没有」的特征**成组**写成从权（或从权组建议）。

**硬性要求：**

1. **成组**：同一改进点的关联特征尽量挂在同一条或串联引用链上（例如：分节叠梁 → 最下方 → 既有门槽）。  
2. 引用合规：只引在前权利要求；多项从权不得作为另一多项从权的基础（见 `权利要求形式合规性规范`）。  
3. 结构类从权一次引入多个新部件时，先总列后展开（见 `结构类权利要求撰写`）。  
4. 每组注明：对应定稿哪一句、退守解决什么更具体问题/效果。  
5. 本步可先交**核心回退组**（与变劣点一一对应）；其余锦上添花从权可列清单留待从权专轮。

**交付物：** 从权条文（或核心组+待写清单）+ 与变劣点映射表。  
**禁止：** 把递交权1仍需要的最小骨架误下放到从权；为留后手而把权1掏空。

---

## 第4步：对照 + 风险 + 交接

1. **三栏对照：** 定稿独权 | 递交独权 | 从权回退组。  
2. **风险提示（必写）：**  
   - 递交权1变宽后，新颖性/创造性答辩压力是否明显上升；  
   - 说明书技术问题/有益效果是否仍与递交权1对齐（若「少改主体」等只在从权，问题陈述勿再绑死在独权上）；  
   - 待同步说明书的术语与实施例。  
3. 提示返回 `独权撰写` **收束**：正式递交稿默认=本 skill 递交独权；定稿第三版作为内部对照稿保留。  
4. 可选：建议对递交权1做一次 `单条权利要求审查`。

**交付物：** 对照摘要 + 风险 + 收束衔接。  
**禁止：** 同轮说明书定稿。

---

## 与本案类示例（帮助理解，非固定模板）

定稿：上游叠梁门包括挡水门节和输水门节，管贯穿输水门节……  
变劣递交：上游门体**整体**设置……管贯穿上游门体……  
从权回退：上游门体为上游叠梁门，包括挡水门节和输水门节；管贯穿输水门节 → 再从权：最下方；既有门槽。

## 与其他 skill 的关系

- 前置：`独权撰写` 第7步第三版。  
- 后接：`独权撰写` 收束；其后说明书 / 从权展开 / `单条权利要求审查` / `权利要求书质检`。  
- 与第三版「成组下放」的区别：第三版下放的是相对再上位问题的非必要/过窄特征；本 skill 下放的是**相对递交权1而言、定稿中多留的那层改进**，即使该改进在定稿独权里曾是优选完整方案的一部分。
