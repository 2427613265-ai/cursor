# 创造性评估与独权补强（独权形成后的中段处理，所有案件类型通用）

## 适用场景

- 已经完成交底书体检，并形成了一版**交底书初版独权**或**经主问题优化后的独权**。
- 现在要处理的是："这版独权创造性够不够""如果不够，往哪里补""补强后的独权怎么构建"。
- 不负责交底书前处理，也不负责独权的形式表达细节；本skill位于"独权初步形成之后、说明书和全套权利要求定稿之前"。

## 与前后 skill 的分工

- 与 `交底书评估和独权初步撰写` 的分工：前者负责交底书体检、初版独权和待确认主问题；本skill负责在已有独权草案基础上判断创造性是否足够，并在不足时补强。
- 与 `独立权利要求必要技术特征检查` 的分工：该skill负责独权的必要技术特征筛选、上位概括、从权下放边界；本skill负责当独权即使经过筛选后，创造性仍不足时，如何补强技术问题和技术方案。
- 与 `说明书技术问题陈述撰写`、`说明书有益效果撰写` 的分工：本skill中确定的主问题、深化问题、以及补强后的核心效果，后续应落实到说明书对应段落，但本skill本身不负责说明书正文定稿。

## AI 使用本skill的能力边界（重要）

- **创造性评估依赖现有技术检索。** AI 本身不具备专利数据库检索能力；在没有检索结果、也没有用户提供现有技术概况时，不能凭空断言"有创造性/没有创造性"，更不能编造对比文件。
- 在缺少检索结果时，只能给出**倾向性判断**，并明确标注不确定性来源。
- 本skill提出的深化技术问题、补强特征、极端场景、意想不到效果，本质上是**合理推演和建议方向**，不是既定技术事实；应提醒用户/发明人确认其技术可行性和真实意图后，再写入正式申请文件。

## 第一步：明确评估对象和评估口径

在开始评估前，先固定当前工作对象：

- 当前要评估的是哪一版独权（交底书初版、主问题修订版、还是已经过一轮必要技术特征筛选的版本）；
- 当前独权所对应的主技术问题是什么；
- 当前独权相对于交底书，已经做过哪些概括、精简或下放。

如果评估对象本身还不稳定，先固定一版工作稿，再进入后续判断；否则容易把"独权过宽"和"独权文本尚未定稿"混为一谈。

## 第二步：做创造性初判

围绕当前独权，先回答以下问题：

1. 相比现有技术，**区别技术特征**是什么？
2. 这些区别技术特征分别解决了什么问题？
3. 它们带来了什么技术效果？
4. 对本领域技术人员来说，这些区别是否容易想到？

结论建议分成三档：

- **创造性基本足够**：可以进入后续说明书撰写和从权布局，无需刻意补强；
- **创造性边缘可争**：建议保留当前独权作为一条主线，同时准备一组补强方案或补强版独权作为备选；
- **创造性明显不足**：应进入后续补强路径，重新构建更有支撑力的独权。

## 第三步：判断问题到底出在哪里

创造性不足，不一定都是同一种原因。要先分型：

### 1. 问题定得太浅

- 当前独权只解决表层问题；
- 与现有技术相比，只是做了常规优化；
- 区别技术特征不足以支撑更深层技术效果。

### 2. 方案写得太薄

- 真正有贡献的区别技术特征没有写进独权；
- 为了追求宽保护，把当前创造性的最小骨架也删薄了；
- 本来应当成组保留的特征，被拆散或过早下放。

### 3. 现有问题有价值，但技术效果说服力弱

- 区别技术特征虽存在，但效果不突出；
- 与现有技术相比，改进幅度看起来像常规替换、常规并列、常规拼装；
- 缺少能够突出非显而易见性的场景或效果表达。

只有先判断属于哪一类，后面的补强路径才不会发散。

## 第四步：补强路径一——深化技术问题（问题 → 方案）

当创造性不足的原因是"问题定得太浅"时，优先走这一路径。

执行方法：

- 从当前主问题出发，继续追问：该方案除了直接解决表层问题外，是否还触及一个更本质、更难、更具价值的问题？
- 观察交底书已有特征中，哪些实际上指向了更深层的约束条件、系统瓶颈、协同关系或极限要求。
- 以这个更深层问题为出发点，重新组织或补充独权特征。

输出要求：

- 明确指出"原主问题"与"深化后的问题"分别是什么；
- 说明为何深化后的问题更能体现区别技术特征的价值；
- 说明为了解决深化后的问题，需要把哪些特征补回独权，或者新增哪些经确认可行的特征。

## 第五步：补强路径二——从极端场景反推（场景 → 手段 → 效果）

当创造性不足的原因是"技术效果说服力弱"时，优先考虑这一路径。

执行方法：

- 设想该方案在极端工况、极端规模、极端环境、极限性能要求下会遇到什么短板；
- 思考要使方案在该极端场景下仍然成立，需要增加什么非常规手段；
- 再反推这些手段将带来什么超出一般预期的技术效果。

常见极端场景包括但不限于：

- 极高温 / 极低温 / 强腐蚀 / 高湿；
- 高频 / 高速 / 高压 / 大载荷；
- 极小体积 / 极大规模 / 极低能耗 / 极高精度；
- 长时间连续运行 / 维护困难 / 安装条件受限。

输出要求：

- 指明采用了哪个极端场景；
- 说明该场景为什么能逼出新的区别技术特征；
- 说明这些新特征带来的技术效果为什么可能具有非显而易见性。

## 第六步：补强路径三——把已知贡献重新组合成可主张的最小骨架

当创造性不足的原因是"方案写得太薄"时，优先使用这一路径。

执行方法：

- 回看已经从独权中删除或下放到从权的一组特征；
- 判断其中是否有一组特征本应作为当前创造性的最小骨架保留在独权中；
- 把这组特征按其内在协同关系重新并入独权，而不是零散挑一两个点回填。

这一步尤其适用于以下情况：

- 当前独权为了追求宽保护，被削得过薄；
- 独权和从权之间的职责划分失衡；
- 当前独权已无法稳定支撑与现有技术的区别论证。

## 第七步：构建补强后的独立权利要求

只有在完成前述至少一条补强路径后，才进入本步。

补强后独权的构建原则是：

- **基础部分**：保留交底书中真实存在、且已被用户/发明人认可的核心技术贡献；
- **增强部分**：加入经过确认可行的补强特征；
- **结构原则**：让新增特征与补强后的技术问题、技术效果一一对应，避免只加特征、不改问题。

输出时应至少同时给出三项内容：

1. **补强后独权全文**；
2. **相对补强前独权新增/恢复了哪些特征**；
3. **每一项新增或恢复特征分别解决什么问题、带来什么效果**。

## 第八步：判断补强后独权是否已经够用

补强不是加得越多越好。补强后还要反查：

- 是否已经足以支撑当前拟申请的专利类型；
- 是否仍保留了合理的保护范围，没有因过度补强而写得过窄；
- 是否把本该作为从权储备的内容一股脑塞进了独权；
- 是否需要同时保留一版较宽主线独权和一版较强备选独权。

如果补强后创造性已基本站住，则可回到独权筛选和从权布局阶段；若仍明显不足，则应如实告知用户，说明需要进一步检索、进一步确认方案，或者重新评估申请路径。

## 输出模板建议

使用本skill时，建议按以下顺序对用户输出：

1. **当前评估对象**：当前是哪一版独权；
2. **创造性初判**：足够 / 边缘可争 / 明显不足；
3. **不足原因分型**：问题太浅 / 方案太薄 / 效果说服力弱；
4. **拟采用的补强路径**：深化问题 / 极端场景 / 重组最小骨架；
5. **补强后独权**：若已完成补强则输出正文；
6. **仍待确认事项**：需要用户或发明人确认的技术事实。

## 与其他 skill 的衔接顺序

典型顺序如下：

```
交底书评估和独权初步撰写
  → 结构类/方法类/算法类独权撰写
  → 独立权利要求必要技术特征检查
  → 本skill（创造性评估与独权补强，必要时介入）
  → 回到独权筛选/从权布局
  → 通用/说明书撰写
  → 权利要求质检/权利要求书质检
```

其中，本skill不要求每案必用；只有在创造性需要专门评估或明显需要补强时再调用。
