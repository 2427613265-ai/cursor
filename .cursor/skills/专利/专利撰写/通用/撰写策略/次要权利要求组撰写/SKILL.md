# 次要权利要求组撰写（核心组之后）

`从权撰写` **第5步**必读。正反例见同目录 `examples.md`。须已完成**核心权利要求组**（核心独立权利要求 + 其从权）。本步不改写权1主题，不替代核心组从权。

---

## 核心组与次要组

多独权写法下，每一项独立权利要求与其从权各成一个**权利要求组**。这些独权通常**不等同**：

| | 含义 |
|--|------|
| **核心独立权利要求** | 一般是权1，最重要 |
| **核心权利要求组** | 权1 + 其从属权利要求（第1～4步已完成） |
| **次要独立权利要求** | 其他独立权利要求 |
| **次要权利要求组** | 次要独权 + 其从权 |

提出「核心权利要求组」，是因为广泛采用多个独立权利要求。次要组写在核心组**已经完成**之后。

**单边原则**下，各组内容常对应撰写，维权地位往往无主次；但第一组仍基本决定后面各组写什么，第一组仍是主要的。

---

## 为何要写（三原则）

须先判定本案用哪几条（可多选；均可「不需要」并写理由）。**不要**无申请类型/无上下游/无多主体时硬凑。

### 1. 产业链原则（侵权诉讼便利）

改进落在产业链某一环（如电动机），申请人的直接对手却在另一环（如洗衣机厂）。核心独权主题应落在真正改进的那一环（电动机），**不得**为了告洗衣机厂就把权1写成洗衣机（范围过窄，甩干机、电冰箱用同一电动机就罩不住）——这与独权第4步 `审定技术主题与重新核定技术问题` 一致。

仅有电动机权要时：洗衣机厂多从市场采购该电动机，只要证明合法进货渠道，往往可不负赔偿责任，告直接对手的目的达不成。也可因地方保护不便在电动机厂生产地起诉，而电动机大宗直供、难取异地销售证据。

为此在核心组之后增加次要独权，例如主题改为洗衣机，特征为使用核心组所述电动机。有洗衣机权要，可直接告洗衣机厂；洗衣机对公众销售、地点遍布，取证与选择诉讼地更自如。

### 2. 对应原则（对应不同专利类型 / 进入他国）

如软件：写完方法权利要求组后，再对应写装置权利要求组。在**中国**专利法下意义往往不大；在**美国**等常有必要。用户考虑今后进入他国、或点名要对应撰写时才做，不作为中国案默认必写。

### 3. 单边权利要求原则（便于确定侵权者）

完整方案牵涉多个实施主体时（通讯、云计算常见：客户端、服务器、网络提供商），若只能告「整条链」，责任分不清，且其中一方可能是专利权人的合作伙伴。

须按不同主体把完整方案**拆开**写成可单独实施的独权，使权利人能选择告谁。申请人若是服务器厂家，可不把网络提供商绑进同一独权。

## 操作（顺序硬性）

1. **判定：** 本案需要产业链 / 对应 / 单边中的哪几条；均不需要则写明理由，本步结束（从权撰写 2.5 可 `cancelled`）。  
2. **布局次要组（须确认）：** 每组写清：原则、新主题（一种洗衣机 / 一种装置 / 客户端侧方法…）、与核心组关系、拟引用的核心权项。次要组从权**不**默认再铺 9 条；条数须明示。  
3. **逐组写：** 先次要**独立**权利要求，再其从权。从权仍走 `从权撰写` 第3步门禁（假想代入、命名、依附编号）。编号接在核心组之后，全篇连续、不跳号（`权利要求形式合规性规范`）。禁止一次倾倒全部次要独权加从权。

次要独权是**新主题的独立权利要求**，不是核心独权的从权（主题已变，不得写成「根据权利要求1所述的洗衣机」这种从权句式）。引用核心组技术特征时过 `权利要求形式合规性规范`；**默认只引权1**。勿把「权利要求1－n」写糊成不合规多项引用。

次要独权须与核心独权属于**一个总的发明构思**（单一性）；不是另写一项无关发明。交底未出现的下游产品（如洗衣机）若作产业链客体，须有技术逻辑（确属使用该改进的整机）或标「待确认」，不得编造另一发明。

**过窄：** 把权1改成下游整机，取消核心主题。  
**过残：** 次要独权抽空核心必要特征，或把多主体步骤仍写在同一独权里迫使共同侵权。

## 交付格式

1. 判定（用哪些原则 / 均不需要 + 理由）。  
2. 若需要：各组布局表（主题、原则、与核心组关系、从权条数）。  
3. 逐组：次要独权全文 → 其从权（按门禁）。  
4. 标注「**次要权利要求组（产业链 / 对应 / 单边）**」或「**本案无需次要权利要求组**」。

## 禁止

- 核心组未完成即写次要组。  
- 为告下游而改写权1主题。  
- 无涉外/用户需求时把方法+装置对应组当中国案必做。  
- 同批倾倒全部次要组正文。  
- 用本步代替结构案递交变劣（变劣仍是同一独权放宽，见 `结构类独权撰写` 第8步）。
