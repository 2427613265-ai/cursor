# 最小集与第一版：一句话展开（正反例）

本页配合 `最小技术特征集与第一版独权`。例子只说明**怎么从一句话展开最小集再连缀**，不是可抄的权要模板。条件句正式稿须走 `条件判断语句规范`。

## 例：触摸屏解锁（承接第1步一句话）

**已确认的一句话：** 使用特别的触摸动作解锁触摸屏设备。  
**一句话里已点到的词：** 特别的触摸动作、解锁、触摸屏设备。  
**不宜整份入集的实施例细节：** 按接触移动解锁图像、具体手势形状（第1步关键创新点，默认下放）。

### 错误 A：把一句话当独权

只写「使用特别的触摸动作解锁触摸屏设备」。这句话不是完整技术方案：「特别的触摸动作」不清楚，也没有锁定/工作状态，无法实施。

### 错误 B：把实施例整份当最小集

把「滑动 + 移动解锁图像 + 预定手势」全部入集。第一版又缩回滑屏一条路，第1步顶天作废。

### 错误 C：拆词后不再补支撑、又引入非必须项

只留「触摸动作、解锁、触摸屏设备」，同时塞进「手机」把客体收窄。方案说不圆，范围又无故比一句话窄。

### 正确：清楚化 + 补必不可少支撑 + 再连缀

**清楚化：** 「特别的触摸动作」→「预先设定的解锁触摸动作」（权要能用、仍停在第1步边界上，不是滑屏钉死）。

**完整方案支撑（一句话字面上没有、但缺了说不圆）：**

| 特征 | 为何必不可少 |
|------|----------------|
| 触摸动作 | 要接收并拿去比对的对象；与「预先设定的解锁触摸动作」不是同一物 |
| 锁定状态、工作状态 | 解锁前后设备所处状态；没有这两态，「解锁」无处落地 |
| 触摸屏 | 接收触摸动作的表面；与「触摸屏设备」不是同一物 |

**最小集（示意）：** 触摸动作；预先设定的解锁触摸动作；锁定状态；工作状态；触摸屏设备；触摸屏。

**同名：** 「触摸屏」≠「触摸屏设备」；「触摸动作」≠「预先设定的解锁触摸动作」。独权须沿用这些名称，不能列了「工作状态」却只写「解锁」。

**第一版连缀（示意，条件句已按规范改写）：**

一种触摸屏设备的解锁方法，包括：所述触摸屏设备处于锁定状态，接收对触摸屏的触摸动作；判断所述触摸动作是否与预先设定的解锁触摸动作相同，若是，则将所述触摸屏设备切换到工作状态；若否，则保持所述触摸屏设备处于锁定状态。

连接词（包括、接收、判断、切换、保持等）把最小集连成方案，本身不是新的技术特征。不要把客体无故收成「触摸屏手机」。
