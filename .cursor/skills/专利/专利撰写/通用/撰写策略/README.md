# 通用·撰写策略

本分支用于存放**不区分结构类/方法类/算法类**的策略层 skill：解决交底书能不能写、方案怎么读懂、独权怎么分流与递进、创造性够不够、从权如何布局与逐条撰写等整体方向问题；具体某一句权利要求/说明书的措辞形态，仍由类型分支与通用规范承担。

## Plan 控输出（本分支硬约定）

`交底书技术方案理解`、`独权撰写`（分流后的执行层）、`从权撰写`（及创造性等）**必须使用 Cursor plan / 待办清单功能**：

1. **交底理解**：第1步只建本 skill 子步骤 plan；**不在入口倾倒**独权 2.1～2.9 细目；交接时提示转入 `独权撰写` 分流。  
2. **独权撰写（入口）**：只输出类型判定 + 下游 skill；**不**自建 2.1～2.9。  
3. **结构类独权撰写 / 方法类独权撰写**：转入后第1步列出阶段二细目（2.1～2.9；创造性在第二版与再上位之间；递交变劣在第三版与收束之间）并同步待办。  
4. **同步 TodoWrite / CreatePlan**；始终一个 `in_progress`。  
5. **一步一交付**；从权须先确认布局再写；禁止未确认布局倾倒多条从权正文（「核心链一批后停」除外）。  
6. **用户说「一口气写完」仍分步**。

## 推荐调用顺序

```
阶段一  交底书技术方案理解【入口】
        可写确认 → 术语词典 → 场景痛点 → 外行总故事
        → 构成地图 → 工作过程 → 体检 → 创新点/问题候选/交接
  ↓
阶段二  独权撰写【分流】
        S 结构案 → 结构类独权撰写（自建 2.1～2.9）
        M/A 方法·算法 → 方法类独权撰写（自建 2.1～2.9）
              2.1～2.7 三版递进（含可选创造性、再上位确认）
              2.8 【可选】递交独权变劣与从权回退
              2.9 收束
  ↓
阶段三  从权撰写
        盘点 → 布局9条【确认】→ 逐条撰写（门禁 Read）→ 复核
  ↓
  → 权利要求质检 / 说明书撰写
```

说明：

- **三版要求依次提高**（结构执行层）：第一版忠实交底问题；第二版对准新界定问题且无非必要特征；第三版再上位后追求逻辑表达清楚且保护范围最大。
- **递交变劣不等于否定第三版**：第三版是定稿质量基准；递交权1可再放宽，定稿多出的改进进从权退守。
- **从权撰写**负责完整从权树；执行层第8步只提供回退种子，不替代本 skill。
- **撰写方法服务于策略**：类型铺陈、必要特征检查、表达规范等在对应版本/门禁表加码调用。
- **方法/算法案**走 `方法类独权撰写`；禁止硬套结构「总列后展开」。

新增相关 skill 时更新本 README；凡多步策略 skill 均应内置 plan 控步。
