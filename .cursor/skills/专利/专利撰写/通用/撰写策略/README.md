# 通用·撰写策略

本分支用于存放**不区分结构类/方法类/算法类**的策略层 skill：解决交底书能不能写、方案怎么读懂、独权怎么按三版递进定问题与范围、创造性够不够、递交前是否再放宽独权、从权如何布局与逐条撰写等整体方向问题；具体某一句权利要求/说明书的措辞形态，仍由类型分支与通用规范承担。

## Plan 控输出（本分支硬约定）

`交底书技术方案理解`、`独权撰写`、`从权撰写`（及创造性等）**必须使用 Cursor plan / 待办清单功能**：

1. **入口第1步列全流程总览**：含独权 2.1～2.9；其后接从权撰写；创造性在第二版与再上位之间；递交变劣在第三版与收束之间。  
2. **同步 TodoWrite / CreatePlan**；始终一个 `in_progress`。  
3. **一步一交付**；从权须先确认布局再写；禁止未确认布局倾倒多条从权正文（「核心链一批后停」除外）。  
4. **用户说「一口气写完」仍分步**。

## 推荐调用顺序

```
阶段一  交底书技术方案理解【入口】
  ↓
阶段二  独权撰写
        2.1～2.7 三版递进（含可选创造性、再上位确认）
        2.8 【可选】递交独权变劣与从权回退
        2.9 收束
  ↓
阶段三  从权撰写
        盘点 → 布局9条【确认】→ 逐条撰写（门禁 Read）→ 复核
  ↓
  → 权利要求质检 / 说明书撰写
```

说明：

- **三版要求依次提高**：第一版忠实交底问题；第二版对准新界定问题且无非必要特征；第三版再上位后追求逻辑表达清楚且保护范围最大。
- **递交变劣不等于否定第三版**：第三版是定稿质量基准；递交权1可再放宽，定稿多出的改进进从权退守。
- **从权撰写**负责完整从权树；独权第8步只提供回退种子，不替代本 skill。
- **撰写方法服务于策略**：类型铺陈、必要特征检查、表达规范等在对应版本/门禁表加码调用。
- **方法/算法流程型独权**：类型铺陈与扩围执行 `方法类/权利要求撰写/方法类权利要求撰写`（与结构类的 `结构类权利要求撰写` 对称）；`独权撰写` 仅挂接，不在本策略文件内重写 I/O 细则。

新增相关 skill 时更新本 README；凡多步策略 skill 均应内置 plan 控步。
