# 通用·撰写策略

本分支用于存放**不区分结构类/方法类/算法类**的策略层 skill：解决交底书能不能写、方案怎么读懂、独权怎么按三版递进定问题与范围、创造性够不够等整体方向问题；具体某一句权利要求/说明书的措辞形态，仍由类型分支与通用规范承担。

## Plan 控输出（本分支硬约定）

`交底书技术方案理解` 与 `独权撰写`（及创造性等）**必须使用 Cursor plan / 待办清单功能**：

1. **入口第1步列全流程总览**：含独权撰写三版递进 2.1～2.7；创造性标在第二版与第三版之间。  
2. **同步 TodoWrite / CreatePlan**；始终一个 `in_progress`。  
3. **一步一交付**；禁止同批多版独权或「重新界定+第二版」合并倾倒。  
4. **用户说「一口气写完」仍分步**。

## 推荐调用顺序

```
阶段一  交底书技术方案理解【入口】
        浅显确认 → 体检 → 读懂 → 问题分层/候选
  ↓
阶段二  独权撰写（三版递进）
        2.1 固定交底书技术问题
        2.2 第一版独权
        2.3 重新界定技术问题（须说明怎么考虑）
        2.4 第二版独权（无非必要技术特征）
        2.5 【可选】创造性评估与独权补强
        2.6 再上位技术问题 + 第三版独权（清楚 + 范围最大）
        2.7 收束
  ↓
  → 说明书撰写 / 从权 / 权利要求质检
```

说明：

- **三版要求依次提高**：第一版忠实交底问题；第二版对准新界定问题且无非必要特征；第三版再上位后追求逻辑表达清楚且保护范围最大（含「至少一块」「第一/第二门」等命名优化）。
- **撰写方法服务于策略**：类型铺陈、必要特征检查、表达规范等在对应版本加码调用。
- `独立权利要求必要技术特征检查` 主要服务第二版清非必要、第三版再筛。
