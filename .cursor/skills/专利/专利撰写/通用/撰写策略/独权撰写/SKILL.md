# 独权撰写（正式独权阶段，所有案件类型通用）

## 适用场景

- 已完成 `交底书技术方案理解` 与 `交底书评估和独权初步撰写`，手头有**交底书初版独权**和**待确认主问题**；入口第1步总览中的**阶段三**。
- 现在要做的是：**正式撰写独权**——确认主问题、按主问题修订；**可选**对修订稿做创造性评估与补强；然后再上位一层技术问题并据此再次修改独权（筛选/下放特征）。
- 不负责交底书体检、初版独权忠实转化。

## 典型触发

- 「按主问题改独权」「正式写独权」「再上位一下技术问题」「独权撰写」
- 交底书初步撰写结束后，用户确认主问题并要求继续

## AI 使用本 skill 的能力边界（重要）

- 本 skill 产出的是**正式独权工作稿**（含必要时的上位修订版），不是说明书定稿。
- 上位与下放不得编造交底书未记载、且未经用户/发明人确认的新结构/步骤；缺事实标「待确认」。
- 具体措辞、句式、部件铺陈顺序，按案件类型参照 `结构类权利要求撰写` 等类型规范，并对照通用分支下的主谓宾、指代、自定义名词等规范；本 skill 管**策略步骤与内容取舍**，类型 skill 管**表达形态**。
- 必要技术特征的逐特征反问细则，复用 `独立权利要求必要技术特征检查`，不在本 skill 重复展开判断口诀。
- 创造性评估的实质判断在 `创造性评估与独权补强`；本 skill 第3步只做转入/跳过决策与交接，不在本步倾倒评估全文。

## 输出控制（硬性：用 plan 控步）

本 skill **禁止**在同一次回复中一次性输出「主问题确认 + 按主问题修订独权 + 再上位后独权」。必须用 **plan** 驱动，一步只交一个交付物，等用户确认后再进入下一步。

### 硬性规则

1. **先建 / 回扣 plan，再按 plan 交付**：第1步建立本阶段子 plan，并**回扣入口全流程总览**中阶段三的编号（3.1～3.5）；其后严格按序推进。
2. **一步只做一个交付物**：须等用户确认（或明确说「下一步/继续」）再进入下一步；用户说「一口气写完」时仍分步。
3. **不得跳步**：不得跳过主问题确认直接写上位独权；不得把「按主问题修订」与「再上位修订」同批输出；**不得在再上位之后才第一次做创造性评估**。
4. **每步输出格式**：`【第X步 / 共N步】步骤名称` + 本步正文 + 请用户确认 + 预告下一步。
5. **始终只有一个「进行中」**。
6. **创造性为可选但位置固定**：第3步由用户决定执行或跳过；若执行，必须针对第2步「按主要技术问题修订后的独权」，完成后再进入第4步再上位。

### 本 skill 固定 plan（共5步；对应总览 3.1～3.5）

```text
第1步 确认主技术问题 + 建立/回扣阶段三 plan
  ↓
第2步 按已确认主问题修订独权（输出「按主要技术问题修订后的独权」）
  ↓
第3步 【可选】创造性评估与独权补强
      （转入 `创造性评估与独权补强`；或用户确认跳过）
      评估对象 = 第2步修订稿；补强后以补强稿作为后续再上位的输入
  ↓
第4步 再上位技术问题 + 第二轮独权筛选/成组下放
  ↓
第5步 输出正式独权工作稿收束 + 待确认事项 + 交接
```

总步数 N = 5。不得擅自把第3步挪到第4步之后；若用户只要其中某一步，仍须标明该步在 plan 中的位置。

若第3步跳过：在回复中写明「用户确认跳过创造性评估」，直接进入第4步；第4步输入仍为第2步修订稿。  
若第4步审查结论为「无需再上位」：交付理由与特征保留说明，第5步以第4步输入稿（第2步稿或补强稿）作为正式工作稿——**不得跳过第4步不问**。

---

## 第1步：确认主技术问题 + 建立/回扣 plan

**本步要做的事：**

1. 承接 `交底书评估和独权初步撰写` 第5步给出的待确认主问题（及备选）。
2. 以用户提示为准：用户可确认候选、改表述、或另定更深/更侧重的主问题。
3. 列出本阶段完整 5 步 plan（回扣总览 3.1～3.5），标明第3步为可选创造性，位置在按主问题修订与再上位之间。
4. 醒目标注**已确认主技术问题**全文，供后续修订与说明书技术问题陈述对齐。

**本步交付物：** 已确认主问题 + 完整阶段三 plan。  
**本步禁止：** 输出修订后独权全文；展开上位分层长文；展开创造性评估正文。

---

## 第2步：按已确认主问题修订独权

在交底书初版独权基础上，使独权记载的技术方案与已确认主问题**精准对应**。

执行要求：

- **前序与特征选取均服务于该主问题**；与主问题无关或可由从权覆盖的特征，可考虑后移。
- **写成完整独权正文**（含前序与「其特征在于」之后的特征部分），标注为「按主要技术问题修订后的独权」。
- **对照说明**：相对交底书初版独权做了哪些调整、各调整与主问题的对应关系。
- 表达形态按案件类型调用 `结构类`/`方法类`/`算法类` 权利要求撰写规范。

**本步交付物：** 「按主要技术问题修订后的独权」全文 + 相对初版的调整要点 + 预告下一步为可选创造性（或跳过后进入再上位）。  
**本步禁止：** 同批做进一步上位审查；同批输出创造性初判/补强独权全文。

---

## 第3步：【可选】创造性评估与独权补强

在第2步「按主要技术问题修订后的独权」已经交付并经用户确认后执行本步决策。

**执行方式：**

1. 询问用户：是否对本稿做创造性评估与（若不足）补强。
2. **若执行**：明确告知转入同分支 `创造性评估与独权补强`；评估对象固定为第2步修订稿（或用户指定的该稿微调版）；按该 skill 自有 plan 分步交付；完成后回到本 skill，以**补强后独权**（若未补强则为原修订稿）作为第4步输入。
3. **若跳过**：写明「跳过创造性评估与补强」，第4步输入 = 第2步修订稿。

**本步交付物：** 执行/跳过决定 +（若执行）转入声明与返回后的当前独权版本定位（修订稿 / 补强稿）。  
**本步禁止：** 在本步内不经创造性 skill 而自行倾倒长篇创造性评述与补强独权；禁止在未完成第2步时进入本步。

---

## 第4步：再上位技术问题 + 第二轮独权筛选

在第2步修订稿（或第3步补强稿）基础上，**不要立即将其视为最终独权**。应进一步审查：当前技术问题是否仍偏具体，是否还存在继续上位概括的空间；若存在，则据此对独权做第二轮筛选与成组下放。

这一步是正式独权撰写内部的扩宽层，位于**按主问题修订（及可选创造性）之后**，用于避免把仅服务于较具体问题的一整组特征过早写死在最宽独权中。

执行要求：

- **先问技术问题是否仍偏具体**：看当前解决的是本质问题、实施层问题，还是某种优选效果层问题；若仍明显贴近具体实施方式、具体性能目标或具体应用场景，应考虑再上位一层。
- **把技术问题分层看待**：至少区分上位技术问题、当前主要技术问题、以及更具体的次级技术问题，并梳理各层与独权特征的对应关系。
- **重新核查必要技术特征**：对当前输入独权再次逐特征提问——「如果把该特征删除、概括或改写为更宽泛的说法，方案是否仍能解决更上位的技术问题？」若能，则该特征相对于更上位问题已非必要，可考虑移出。细则调用 `独立权利要求必要技术特征检查`。
- **允许成组下放，不鼓励零碎拆散**：只在解决较具体技术问题时才必要的多个关联特征，宜作为一组整体下放到从属权利要求。
- **保留当前最小创造性骨架**：**不得为了给后续答复留后手，而把支撑当前创造性的核心区别技术特征整体提前下放**。若第3步刚补强过，尤须避免把刚补进独权的最小骨架整组下放。
- **说明书同步公开**：凡拟下放的一组特征及其对应的较具体问题、效果、替代实施方式，均应在说明书中充分公开（本步只列明下放清单与公开提示，不写说明书正文）。
- **输出**：若发生上位与精简，输出「按更上位技术问题再次修订后的独权」，并说明相对输入稿哪些特征保留为最宽骨架、哪些成组下放及各自对应的次级问题/效果；若无需再上位，明确写明理由。

**本步交付物：** 上位与否结论 +（若上位）再次修订后的独权全文 + 下放特征组清单（或「无需再上位」说明）。  
**本步禁止：** 同批写说明书实施例；把本步前移到创造性之前（除非用户明确要求且总览已同步改写——默认禁止）。

---

## 第5步：正式独权工作稿收束 + 交接

收束本 skill 的工作结果：

1. 标明**正式独权工作稿**是第4步后的版本（若未再上位，则为第4步的输入稿：第2步修订稿或第3步补强稿）。
2. 列出仍待确认事项（若有）。
3. 提示下一步可转入说明书撰写等；若第3步跳过且用户事后仍要评创造性，说明需另开创造性 skill，但默认主路径已按总览完成。
4. **本 skill 到此结束**，不自动连跑说明书。

**本步交付物：** 正式独权工作稿定位说明 + 待确认事项 + 下一环节衔接。  
**本步禁止：** 同轮输出说明书定稿。

## 与其他 skill 的衔接顺序

```
【入口总览】
阶段一 交底书技术方案理解
  → 阶段二 交底书评估和独权初步撰写（初版独权 + 待确认主问题）
  → 阶段三【本 skill】
        确认主问题 → 按主问题修订
        →【可选】创造性评估与独权补强
        → 再上位并筛选/下放 → 正式工作稿收束
  → 通用/说明书撰写
  → 权利要求质检/权利要求书质检
```

- 与 `交底书评估和独权初步撰写`：前者只出初版独权与待确认主问题，并在入口第1步列出含本阶段的总览 plan。
- 与 `创造性评估与独权补强`：**可选**；插在本 skill 第2步与第4步之间；评估对象为「按主要技术问题修订后的独权」。
- 与 `独立权利要求必要技术特征检查`：本 skill 第4步（及第2步精简时）调用其判断方法；「再上位 + 下放」的流程位置在本 skill 第4步。
- 与类型权利要求撰写 skill：本 skill 决定写什么、留什么；类型 skill 决定怎么把部件/步骤写清楚。

## 检查清单

- [ ] 已确认主技术问题后再改独权，未擅自定稿主问题
- [ ] 已建 5 步 plan，且回扣总览；创造性（若有）在按主问题修订之后、再上位之前
- [ ] 第2步与第4步未同批倾倒
- [ ] 第3步已明确执行或跳过创造性
- [ ] 第4步已明确回答「是否再上位」；若上位已输出再次修订独权与下放组
- [ ] 未为留后手而把最小创造性骨架整体下放
- [ ] 结束后未自动连跑说明书
