# 独权撰写（阶段入口：只分流）

## 适用场景

- 已完成 `交底书技术方案理解`（或用户明确跳过理解并已有交底），进入**独权阶段**；
- 用户说「写独权」「三版独权」「重新界定技术问题」「开始写权1」等，且**未点名**「结构类独权 / 方法类独权」专版。

**硬性规则：** 本 skill **只判定客体类型并分流**，不产出三版独权全文、不重新界定问题定稿、不跑递交变劣正文。细则在下游专版执行。

**不适用：** 「质检」→ `质检总控`；已点名「结构类独权 / 装置独权」→ 直接 `结构类独权撰写`；写从权 / 说明书 → 对应阶段 skill。

---

## 分流表

| 类型 | 判定线索（示例） | 下一步 |
|------|------------------|--------|
| **S. 结构/装置案** | 「一种××装置/机构/系统」；以部件、位置、连接关系为主；交底附图为结构图 | **`结构类独权撰写`**（三版递进 2.1～2.9；含可选创造性、递交变劣） |
| **M. 方法案** | 「一种××方法」；以步骤、工况、操作为主 | **方法类独权撰写（待建）**：写明暂无专版，请用户确认是否改走结构表述、补充方法专版，或仅用通用横切（`条件判断语句规范` / `预设值与参数来源检查`）做临时梳理——**禁止**把方法案硬套 `结构类独权撰写` 的「先总列后展开」 |
| **A. 算法/数据处理案** | 模型、特征、训练、优化目标等数据流程为主 | 同方法案处理（待建专版）；禁止伪装成结构独权 |
| **H. 混合案** | 结构骨架 + 控制/算法步骤 | 默认先按**结构骨架**进 `结构类独权撰写`；运行/算法接口在结构独权中从宽处理或下放从权；若用户明确以方法为主保护，按 M 处理 |
| **U. 类型不明** | 交底两可、名称含糊 | 用两三句列出候选类型与倾向，**请用户确认**后再分流；不得猜测后直接开写三版 |

---

## 执行顺序（硬性）

1. **读已有理解结论 / 交底标题与权要客体倾向**（装置 vs 方法）。  
2. **给出分流结论**：类型字母（S/M/A/H/U）+ 将调用的 skill 名 + 一句理由。  
3. **立刻转入**下游 skill（结构案 → Read 并执行 `结构类独权撰写`）；本页不展开其 2.1～2.9。  
4. 方法/算法专版未建时：只交付「暂不可自动走结构三版」的说明与可选处置，停住等用户指示。

---

## 与下游、邻接 skill 的关系

| skill | 关系 |
|-------|------|
| `结构类独权撰写` | **结构案执行层**（原通用独权三版正文）；本入口分流后的默认主路径 |
| `结构类权利要求撰写` | 结构独权正文铺陈细则（先总列后展开）；由 `结构类独权撰写` 挂接，本入口不直写 |
| `创造性评估与独权补强` | 挂在**结构类**独权链路第5步（第二版之后）；由执行层调度 |
| `从权撰写` | 独权定稿（第三版或递交变劣稿）之后 |
| `交底书技术方案理解` | 阶段一；结束后提示转入**本入口**再分流 |
| `专利撰写总控` | 顶层写案子时，独权阶段指向**本入口** |

---

## 最低交付

分流时输出：

1. 当前判定类型（S/M/A/H/U）；  
2. 将调用的下游 skill 名（或「专版待建 + 请用户选择」）；  
3. 一句判定理由 / 前置条件。  

禁止在本 skill 内输出独权权利要求全文或多版对照。

## 检查清单

- [ ] 已判类型，未跳过分流直接套结构三版  
- [ ] 结构案已指向 `结构类独权撰写`，未在本页写正文  
- [ ] 方法/算法案未误用结构「总列后展开」冒充独权专版  
- [ ] 类型不明时已请用户确认
