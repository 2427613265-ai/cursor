# 独权撰写（阶段入口：只分流）

## 适用场景

- 已有交底书（或用户明确要写独权），进入**独权阶段**；
- 用户说「拿到交底书」「写案子」「写独权」「三版独权」「重新核定技术问题」「开始写权1」等，且**未点名**「结构类独权 / 方法类独权」专版。

**硬性规则：** 本 skill **只判定客体类型并分流**，不产出独权全文、不重新核定问题定稿、不跑递交变劣正文。细则在下游专版执行。

**不适用：** 「质检」→ `质检总控`；已点名「结构类独权 / 装置独权」→ 直接 `结构类独权撰写`；已点名「方法类独权 / 算法独权」→ 直接 `方法类独权撰写`；已点名「核心区别技术特征确定」→ 可直进该 skill（第1步细则，不代替策略 plan）；已点名「最小技术特征集与第一版独权」→ 可直进该 skill（第2/3步细则，不代替策略 plan）；已点名「审定技术主题与重新核定技术问题」→ 可直进该 skill（第4步细则，不代替策略 plan）；已点名「第二版独权校核」→ 可直进该 skill（第5步细则，不代替策略 plan）；已点名「从权分层次布置」或「次要权利要求组撰写」→ 可直进该 skill（从权第2/3步或第5步细则，不代替 `从权撰写` plan；次要组须已有核心组）；已点名「方法类权利要求具体撰写规则总控」或 `方法类权利要求专有细则`（含旧六叶名）→ 可直进该 skill（写正文细则，不代替策略 plan）；写从权 / 说明书 → 对应阶段 skill。

## 分流表

| 类型 | 判定线索（示例） | 下一步 |
|------|------------------|--------|
| **S. 结构/装置案** | 「一种××装置/机构/系统」；以部件、位置、连接关系为主；交底附图为结构图 | **`结构类独权撰写`**（核心区别一句话+关键创新点→组成最小集→第一版→审定技术主题并重新核定→第二版；其后保留再上位→第三版→可选递交变劣） |
| **M. 方法案** | 「一种××方法」；以步骤、工况、操作为主 | **`方法类独权撰写`**（核心区别一句话+关键创新点→组成最小集→第一版→审定技术主题并重新核定→第二版；正文细则经其挂接 `方法类权利要求具体撰写规则总控`） |
| **A. 算法/数据处理案** | 模型、特征、训练、优化目标等数据流程为主 | **`方法类独权撰写`**（同上；禁止伪装成结构独权） |
| **H. 混合案** | 结构骨架 + 控制/算法步骤 | 用户明确以方法为主 → M；否则默认先按**结构骨架**进 `结构类独权撰写`，运行/算法接口从宽或下放从权 |
| **U. 类型不明** | 交底两可、名称含糊 | 用两三句列出候选类型与倾向，**请用户确认**后再分流；不得猜测后直接开写 |

---

## 执行顺序（硬性）

1. **读交底标题与权要客体倾向**（装置 vs 方法）。  
2. **给出分流结论**：类型字母（S/M/A/H/U）+ 将调用的 skill 名 + 一句理由。  
3. **立刻转入**下游 skill（结构 → `结构类独权撰写`；方法/算法 → `方法类独权撰写`）；本页不展开其阶段二细目。方法正文细则不在本页展开，由下游经 `方法类权利要求具体撰写规则总控` 挂接 `方法类权利要求专有细则`。  
4. 类型不明时停住等确认，不得默认套结构或方法流程。

## 与下游、邻接 skill 的关系

| skill | 关系 |
|-------|------|
| `结构类独权撰写` | **结构案执行层**；S / 部分 H |
| `方法类独权撰写` | **方法/算法案策略执行层**；M / A / 部分 H |
| `核心区别技术特征确定` | **第1步细则**（顶天一句话 + 立地关键创新点）；由结构/方法类独权撰写第1步挂接，本入口不直跳 |
| `最小技术特征集与第一版独权` | **第2/3步细则**（一句话展开最小集 + 连缀第一版）；由结构/方法类独权撰写第2/3步挂接，本入口不直跳 |
| `审定技术主题与重新核定技术问题` | **第4步细则**（审定技术主题 + 重新核定技术问题）；由结构/方法类独权撰写第4步挂接，本入口不直跳 |
| `第二版独权校核` | **第5步细则**（新主题下校核第一版：对齐用语、删减/上位得第二版）；由结构/方法类独权撰写第5步挂接，本入口不直跳 |
| `方法类权利要求具体撰写规则总控` | **方法/算法案正文细则入口**；由 `方法类独权撰写` 在写第3/5步正文时挂接，再读 `方法类权利要求专有细则`（本入口不直跳） |
| `结构类权利要求撰写` | 结构独权正文铺陈细则；由 `结构类独权撰写` 挂接 |
| `条件判断语句规范` / `预设值与参数来源检查` 等 | 方法独权横切；经 `方法类权利要求具体撰写规则总控` 挂接 |
| `从权撰写` | 独权定稿之后（方法案默认第二版；结构案第三版或递交变劣稿）；第2/3步见 `从权分层次布置`，第5步见 `次要权利要求组撰写` |
| `专利撰写总控` | 顶层写案子时，默认独权阶段指向**本入口** |

---

## 最低交付

分流时输出：

1. 当前判定类型（S/M/A/H/U）；  
2. 将调用的下游 skill 名；  
3. 一句判定理由 / 前置条件。  

禁止在本 skill 内输出独权权利要求全文或多版对照。

## 检查清单

- [ ] 已判类型，未跳过分流直接开写独权  
- [ ] 结构案 → `结构类独权撰写`；方法/算法案 → `方法类独权撰写`  
- [ ] 未把方法案硬套结构「总列后展开」，也未把结构案硬套纯步骤独权  
- [ ] 类型不明时已请用户确认
