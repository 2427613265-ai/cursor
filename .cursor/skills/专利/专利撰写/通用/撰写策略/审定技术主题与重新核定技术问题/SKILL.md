# 审定技术主题与重新核定技术问题（独权第4步细则）

方法/结构类独权**第4步**必读。正反例见同目录 `examples.md`。只对着**已交付的第一版独立权利要求**反推，**不**写第二版正文。

原先的技术主题（交底标题、第一版前序「一种××」）是在核心权利要求写成**之前**定的，没有把该权全部特征可能扩到的范围算进去，**一般过窄**，偶有过宽。本步先审**技术主题**，再核**技术问题**。二者都服务第5步第二版；只改问题不改主题，第二版仍钉在发明人最初领域。下游整机（如洗衣机）不是把权1主题收窄的理由；核心主题仍按第一版特征能用到哪来定，整机保护放 `次要权利要求组撰写`。

**技术主题 ≠ 技术问题。** 主题是权要标题/前序客体及其所属领域（一种触摸屏设备的解锁方法；一种往复-旋转运动相互转换的机构）。问题是这份权1实际能稳定消除的不良后果。

---

## ① 审定技术主题

1. **锁定反推对象：** 复贴或引用第3步第一版全文。交底名称、第1步一句话只作对照，**不得**代替第一版。  
2. **看全部特征能用到哪。** 问：这些特征是否绑死在发明人最初行业/产品上，还是换到相邻设备/领域仍成立？交底实施例全在某一行业，不代表主题必须停在该行业。  
3. **过窄（默认要防）：** 发明人从手机、内燃机出发，特征本身已能用于其它触摸屏设备、压缩机等。不审主题，保护会被钉死在最初设想的领域——这一步最常被漏。  
4. **过宽（必要时收）：** 主题盖到特征撑不住的领域，或空到不像一项发明。实用新型更要防过宽：发明评价创造性时可考虑的对比技术领域较宽，收窄主题对发明创造性帮助通常不大；实用新型可考虑的对比技术领域较窄，收窄有时有意义。须标明本案申请类型后再取舍。  
5. **未过界：** 扩主题须能从第一版特征合理读出，符合技术逻辑、有实现可能；不是另一类发明，也不是编造交底毫无启示的新领域。

第3步「客体不得无故窄于一句话」只避免连缀时比一句话更窄。本步是写成第一版之后，按**全部特征**再审主题，可能比一句话再放宽一层（内燃机运动机构 → 往复-旋转转换机构）。

---

## ② 重新核定技术问题

在已审（或确认无需改）的主题下，定这份第一版**实际能稳定解决**的问题层级。不是把交底问题换个说法，也不是把手段写进问题。

| 操作 | 怎么用 |
|------|--------|
| **交底问题盘点（对照）** | 分清核心痛点 vs 附带/宣传；附带不得当主问题。不是本步起点。 |
| **特征反推** | 对着第一版全文：实际稳定消除哪一层不良后果。 |
| **手段不进问题** | 问题只写后果/需求缺口，不写算法名、专用机构名、具体参数。 |
| **范围落点** | 过窄→第二版被迫留钉死路径；过宽→假宽或无可实施依托。 |
| **可检验** | 假定第二版只剩必要特征：能否完整解决拟核定问题？不能则回调问题或回到第一版/交底补事实。 |

**方法/算法案：** 创造性通常已够。本步**默认不是**为补强创造性选问题，而是把问题定到合适层级，使第二版能丢掉场景/工具/参数钉死、扩保护范围。  
**结构/装置案：** 落点须能被第一版中高贡献手段撑住；过宽难支撑新颖性/创造性。

---

## 交付格式（第4步正文）

1. **反推对象**（第一版独权；可摘要，须能对上全文）。  
2. **原技术主题**（交底/第一版前序）→ **审定后的技术主题**（一句；过窄放宽 / 过宽收窄 / 合适不改）+ 特征依据（为何这些特征撑得住或撑不住该领域）。  
3. **申请类型**（发明 / 实用新型）对主题宽窄的影响（一句）。  
4. **重新核定后的技术问题**（一句或两句）。  
5. **核定考虑**（先写明反推对象=第一版；方法案写明以扩围为主；不按三点分述）。  
6. **与交底问题表述的差异**（对照，不是起点）。  
7. **对第二版的预期**：第5步见 `第二版独权校核`；本步只写拟对齐的主题用语、拟删/概括哪些因主题或问题不再绑死的特征。**不得**在本步写出第二版全文。  
8. 标注「**待确认：审定后的技术主题 + 重新核定后的技术问题**」。

---

## 禁止

- 第3步独权全文未交付即做本步；同批输出第二版。  
- 跳过审主题，只改问题。  
- 只拿交底标题、一句话或最小集空推，不对着第一版全部特征。  
- 把手段写入问题；把本步写成再摘交底声称问题。  
- 为扩主题编造交底无启示的新领域。  
- 结构案用第6步再上位顶替本步未做的主题审定。
