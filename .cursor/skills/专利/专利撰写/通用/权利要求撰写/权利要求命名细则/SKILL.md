# 权利要求命名细则

原 `部件命名优化总控`、`部件命名具体优化`、`交底口语名改写为自明结构名规范`、`方位与场景限定上位规范`、`自定义名词就地定义` 已收束于此。点名旧名即读本页对应节。

**间接校正仍外指：** 同物多名识别 → `权利要求表达清楚性规范`；同类件序数消歧 → 同上指代节；母子件层级 → `结构类权利要求撰写`；名称偷带功能 → `功能性限定使用边界规范`。

## 分节何时用

| 时机 | 必用节 |
|------|--------|
| 结构案各版独权正文前；方法案**仅第二版**正文前；每条从权新名 | 〇闸门 + 一分型，再按型用二～五节 |
| 交底口语/图纸习惯名 | 三、口语改写 |
| 左/右、上/下、上游/下游、迎水/背水、内外、场景钉死语 | 四、方位与场景 |
| 非公知概念、自造词 | 五、就地定义（先问能否改名） |

---

## 〇、适用与闸门

- 结构案：第一/二/三版独权写出正文前必须先交命名对照表，**用户确认前不得输出该版独权全文**。  
- 方法/算法案：**第一版不优化**（沿用交底原名）；**第二版唯一一次**优化并交表，确认前不得写第二版正文；无第三版。  
- 每条从权：新名至少查口语、非必要定语、与已入权名冲突（第二节规则五）。

对照表列：原名｜分型｜第一档｜第二档｜推荐采用名｜对保护范围的影响｜用户选择。关键名至少两档（结构案第三版硬性；方法案第二版关键名须两档）。

---

## 一、分型（A～H）

对每个拟入权名称：

| 类型 | 典型 | 本页 |
|------|------|------|
| A 夹带材料/性能/效果/用途/场景定语 | 高强螺栓、防腐护套 | **必须**第二节；定语偏功能效果可并行 `功能性限定使用边界规范` |
| B 交底口语/图纸习惯/临时名 | 小板、那个支撑件 | **必须**第三节，再回第二节 |
| C 名称含方位或场景词 | 左侧板、下游支架 | **必须**第四节，再回第二节 |
| D 改不动仍不自明 | 本案特有词、缩略词 | **必须**第五节 |
| E 同物多名 / 同名多物 | 同一件多名或两件共裸名 | 同名多物：**必须**第二节规则五；同物多名：`权利要求表达清楚性规范` 识别 |
| F 同类件消歧 | 第一/第二锚固单元 | `权利要求表达清楚性规范` 指代节 |
| G 母子件层级可疑 | 子板与母箱写成同级「还包括」 | `结构类权利要求撰写` |
| H 名称偷带功能效果 | 调心垫板、限位挡块 | `功能性限定使用边界规范` + **必须**第二节 |

直接命名顺序：第二节 →（非自明）第三节 →（含方位/场景）第四节 →（仍不自明）第五节。命中则追加间接校正，不必八项全跑。

---

## 二、去非必要定语、两档对照、同名多物

1. 拆出结构核心词（板、杆、箱、座、孔等）与修饰语（钢、高强、防腐、调心、上游、左、专用等）。优先留结构边界词。  
2. 材料/性能/效果/场景定语须追问是否为解决当前问题所必需；非必要则删、上位或下放。`高强螺栓` 默认审为 `螺栓`。效果词若只是偷带效果，改中性结构名。  
3. 优先级：**自明结构名 > 功能结构名 > 原口语名+解释**。  
4. 关键名至少两档对照：更清楚 vs 更宽；更宽若写糊则退回上一档。独权必须交表确认。  
5. **同名多物（硬性）：** 不同结构位置/功能归属不得共用裸名。写每个新名必问：已入权名表里是否已指另一件？是 → 先消歧再落笔。对照范围：独权看本版拟用名；从权看权1至本条之前（含平行从权）。消歧首选归属前缀（`锚固箱加劲板` / `拉杆加劲板`），同条同类件用第一/第二并转清楚性指代节。禁止指望读者猜。优先改后写/新引入那条；前条过泛可两边都改。

---

## 三、口语改写为自明名

不要默认原词照抄再靠「其中」补课。判断标准：本领域不查说明书，单看权要能否理解。

**三问：** 是否不自明？有无更常见、边界更清的结构名或可核对几何/位置表述？改名是否只改表达、不改技术事实？能改清楚 → 直接改名；会改错含义或仍不清 → 第五节（先前置白话）。

布置/排列口语（「对称错位」等）优先改成可核对关系（错开相对谁、对称相对哪条中心线）。**禁止：** 能改名却不改；布置黑话原样入权。

---

## 四、方位与场景限定上位

管**要不要钉死、如何扩围**；参照物是否清楚见 `权利要求表达清楚性规范` 指代节。禁止误伤结构名中的「侧/向」（侧支孔、轴向、径向不是「左侧」）。

先问：解决技术问题所必需，还是交底图/实施例习惯？习惯 → 能上位则上位；必要关系 → 保留。两步：①改掉或放宽后是否仍清楚且能多覆盖等同实施；②不能扩围则不要改成空泛第一/第二。

| 类 | 处理 |
|----|------|
| 观察方位（左/右、前/后、上/下） | 默认 **一侧/至少一侧/一端**；两侧都要写入且须消歧用第一/第二；不对称且为区别时才保留左/右。从权默认一侧，交底「左侧」收回下游从权或说明书 |
| 上游/下游 | 流向是骨架则**保留**；勿盲目改第一/第二 |
| 迎水/背水、进水/出水 | 功能面有技术含义则保留；任一侧均可则上位为「设置于…一侧」，具体侧下沉从权 |
| 内外侧 | 装配关系本身则保留并写清参照；仅实施例习惯可改「一侧壁」等 |
| 场景钉死（防洪、高水头、枢纽专名） | 较宽权能删则删或改领域通用名；专名留说明书/最下游从权 |

从权出现上表用语须按类选型并写一句理由；不要「一侧」上位后又夹带「左侧」缩回（除非本条就是实施例收回）。

---

## 五、自定义名词就地定义

权要须自足可读。非公知概念按序：**①改自明名 → ②名称出现前白话写清再引入短名 → ③「其中」兜底**。禁止黑话先行再堆「其中」；禁止用未定义解释未定义；禁止只在说明书里定义。

②模式：`[普通话交代构成/计算/作用] → 作为「短名」→ 后文「所述短名」`。前文已钉死含义的，不要再加「其中」复述。

③仅当必须多次回指、①②做不到或极臃肿时，紧接首次出现用「其中，所述××为……」一次说清。含义归本节；参数**来源**归 `方法步骤条件与参数规范`。
