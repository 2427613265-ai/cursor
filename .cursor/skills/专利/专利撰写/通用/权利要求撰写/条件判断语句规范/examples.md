# 条件判断语句：正反例

配合 `条件判断语句规范`。不是可抄权要模板。

## 单分支写窄（独权不该写全 else）

发明点只是「超阈值则降风机转速」，另一侧维持现状并非发明。

❌ 独权：
```
判断所述检测值是否大于第一阈值，若是，则降低所述风机的转速；若否，则保持所述风机的转速不变。
```
对手只实现「超阈值降速」、不实现「未超则保持」的明确分支，可能被解释为未落入全部分支。

✔ 独权：
```
在所述检测值大于第一阈值的情况下，降低所述风机的转速。
```
另一侧进说明书或从权。

## 两分支都必要（解锁）

符合预定触摸则解锁、否则保持锁定，两侧都是控制逻辑。

✔
```
判断所述触摸动作是否与预先设定的解锁触摸动作相同，若是，则将所述触摸屏设备切换到工作状态；若否，则保持所述触摸屏设备处于锁定状态。
```

## 口语与时间点

❌ `如果检测值超过上限，那么生成警告` → ✔ `在所述检测值超过预设上限的情况下，生成警告信息。`  
❌ `当用户权限为管理员时，允许删除` → ✔ `在所述用户权限为管理员权限的情况下，允许执行删除操作。`  
❌ `检查温度是不是太高了，是的话就打开风扇` → ✔ `在所述温度值高于安全阈值的情况下，启动散热风扇。`

## 嵌套须拆步

❌ 单步内「若是则再判断 B」。  
✔ 拆成独立步骤；每步仍按「单侧发明用在……的情况下 / 两侧必要用若是若否」。
