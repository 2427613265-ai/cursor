# 通用·权利要求撰写

本分支存放**不区分结构/方法/算法**的权利要求撰写细则。案件类型专属规范见 `结构类/权利要求撰写/`、`方法类/权利要求撰写/`。

## 已有 skill（收束后）

| skill | 管什么 |
|-------|--------|
| **`权利要求命名细则`** | 分型、去非必要定语、口语改自明名、方位/场景上位、就地定义；方法案仅第二版优化。原命名总控及四叶已收束 |
| **`权利要求表达清楚性规范`** | 主谓宾、该/其与方位参照、孤岛与清楚性（须先读共用内核）。原主谓宾/指代/清楚性三叶已收束 |
| **`权利要求形式与依附规范`** | 引用方向、多项择一、主题名称、编号连续；「所述××」列词溯源覆盖。原形式合规与依附编号已收束 |
| **`方法步骤条件与参数规范`** | 「判断是否…若是…若否…」；预设值/阈值须先有来源。原条件句与预设值两叶已收束 |
| `独立权利要求必要技术特征检查` | 独权各特征是否为解决已核定问题所必需；第7步清非必要（不用于第4步组集） |

结构专有仍在 `结构类/权利要求撰写/`：`结构类权利要求撰写`、`功能性限定使用边界规范`。

独权/从权将 `权利要求命名细则` 列为硬性门禁（方法案仅第二版）。质检：`质检总控` → `权利要求质检总控` → `权利要求书质检`，按必读/按需加载上表。
