# 左右侧方位限定上位规范（独权与从权通用）

## 适用场景 / 触发词

**应当加载本 skill 的典型情形：**

- 撰写或改写**从属权利要求**时，正文或布局拟写入「左侧」「右侧」「左阀」「右廊道」等；
- 撰写**独立权利要求**第三版命名/扩围时，交底用左/右描述对称或可互换布置；
- 用户问「左侧右侧怎么上位」「要不要改成第一/第二侧」「从权要不要写死左侧」；
- 质检/单条审查发现权利要求被左/右不必要钉死。

**不替代：**

- `权利要求指代与参照清晰性规范`——方位词是否有参照物、是否清楚；
- `独权撰写` 中「第一×× / 第二××」总规则——本 skill 是其在**左/右观察方位**上的专条展开；独权第三版遇到左/右时，**本 skill 与独权命名规则一并遵循**。

---

## 核心规则

「左侧 / 右侧」通常是**相对于某一观察方向或图纸习惯**的标签，多数情况下**不是**解决技术问题所必需的结构关系。

默认策略：

1. **能上位则上位**——不把保护范围钉死在交底图的某一侧；  
2. **上位后仍须清楚**——读权利要求能知道「哪一侧」与其它部件如何对应；  
3. **实施例左/右下沉**——交底图的具体左侧/右侧，优先放说明书，或由更下游从权收回。

---

## 上位档位（由宽到窄）

| 档 | 典型写法 | 适用 |
|----|----------|------|
| **A 最宽** | **一侧**；**至少一侧** | 左右对称或功能等价，任一侧实施即可；从权/独权优先档 |
| **B 次宽** | **第一侧 / 第二侧**（或第一×× / 第二××） | 两侧都要写入同一条、必须消歧；且改序数比保留左/右**更能扩大**保护范围（不依赖看图方向） |
| **C 保留** | **左侧 / 右侧** | 左右**结构或功能不对称**，发明贡献就绑在指定侧；或仅作实施例级从权细化 |

### 两步判断（不得跳步）

与 `独权撰写` 序数命名规则对齐：

1. **先问能否扩围**：去掉或改掉「左/右」后，是否仍清楚，且能覆盖「镜像布置 / 对侧同样实施」？  
   - **能 → 选 A（一侧 / 至少一侧）**；两侧都要出场且需成对指代时再考虑 B。  
2. **若不能扩围**（例如左右机构根本不同，或「左侧」本身就是区别特征）：**保留 C**，不要为「看起来更上位」而改成第一/第二。

**禁止：** 不问扩围、默认把所有「左侧」改成「第一侧」。

---

## 从属权利要求专项（硬性）

撰写从权（含 `从权撰写` 第3步逐条写）时：

1. **布局或正文一出现「左/右」** → 必须先 Read 本 skill，再落笔。  
2. **默认写 A 档**：用「一侧阀门」「一侧出水口」等；交底的「左侧」在该条的「已遵循 skill / 说明」或说明书中交代「本实施例为左侧，亦可为右侧」。  
3. **需要钉死交底图侧向时**：单独用更下游从权收回，例如：  
   `进一步地，所述一侧阀门为左侧阀门，所述一侧出水口为左侧出水口。`  
4. **不要**在同一条从权里既用「一侧」上位、又无必要地夹带「左侧」把范围缩回去（除非该条职责就是实施例收回）。  
5. 若独权已用「一侧」，从权不得无故改回更窄的「左侧」作为**唯一**限定，除非该从权目的就是限缩到实施例侧。

### 从权交付物自检（微型）

- [ ] 本条若含左/右或已上位为一侧：已声明遵循本 skill  
- [ ] 选用了 A/B/C 哪一档，一句话理由  
- [ ] 若用 A/B：交底「左侧/右侧」是否安排进说明书或下游从权

## 与易混用语的区分

| 用语 | 含义倾向 | 处理 |
|------|----------|------|
| **左侧 / 右侧** | 观察方位（看图左/右） | 按本 skill 上位或保留 |
| **一侧 / 另一侧** | 不绑定观察方向的两侧之一 | 常用上位结果 |
| **上游 / 下游** | 水流/工艺方向，通常比左/右稳定 | **不要**盲目改成第一/第二；另按独权命名两步判断 |
| **侧支、侧向、侧壁** | 「侧」表示旁向/侧面结构，**不是**「左侧」 | **禁止**为上位左/右而删改「侧支孔」等已定义结构名中的「侧」字；结构名保留，另用就地定义 |

## 写法示范

### 示范1：廊道单侧进鱼（对称可互换）→ 从权用 A 档

```
❌ 过窄：所述左侧阀门控制所述左侧出水口的通断；所述左侧出水口经所述侧支孔与所述船闸闸室连通。

✅ 上位：所述一侧阀门控制所述一侧出水口的通断；所述一侧出水口经所述侧支孔与所述船闸闸室连通。
```

下游从权（可选）：`所述一侧阀门为左侧阀门，所述一侧出水口为左侧出水口。`

### 示范2：两侧都要写且需消歧 → B 档

```
✅ 所述输水廊道配置有第一侧阀门和第二侧阀门；所述第一侧阀门与第一侧出水口对应，所述第二侧阀门与第二侧出水口对应。
```

（若交底左右功能完全等价、本条又只需「有阀门的那一侧进鱼」，仍优先 A，不必强行第一/第二。）

### 示范3：必须保留左/右（C 档）

仅当技术方案依赖不对称布置时，例如「仅左侧开孔、右侧封闭形成必要流态」，保留「左侧」并在说明书说明为何不可对侧替换。

## 检查清单

- [ ] 出现的「左/右」是否仅为观察标签，而非必要结构不对称？  
- [ ] 是否已按两步判断在 A/B/C 中选型，并避免默认第一/第二？  
- [ ] 上位为「一侧」后，阀、口、通道等称谓是否全条一致？  
- [ ] 「侧支/侧向」类结构名是否被误伤？  
- [ ] 从权是否把交底图左/右不合理地写死在较宽的那一条上？  
- [ ] 清楚性：一侧与其它部件的对应关系是否仍可读？（参照物问题另查指代 skill）
