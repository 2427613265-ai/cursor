## 主谓宾

## 问题类型示例

### 1. 动作执行者不明确

❌
```
S3：接收用户输入的数据，进行加密处理，并存储至数据库；
```

✅
```
S3：所述输入模块接收用户输入的数据，所述加密模块对所述数据进行加密处理，所述存储模块将加密后的数据存储至数据库；
```

### 2. 状态归属不明

❌
```
其特征在于，处于工作状态时，温度控制在30-50℃范围内
```

✅
```
其特征在于，所述加热模块处于工作状态时，所述加热模块的温度控制在30-50℃范围内
```

### 3. 关系主客体不明

❌
```
通过弹性连接件连接
```

✅
```
所述固定座与所述活动臂通过弹性连接件连接
```

### 4. 并列动作主语混淆

❌
```
S3：所述控制器接收传感器信号，分析信号特征，发出控制指令，执行相应动作；
```

✅ 方案A
```
S3：所述控制器接收传感器信号，分析信号特征，并发出控制指令；所述执行机构根据所述控制指令执行相应动作；
```

✅ 方案B（拆步）
```
S3：所述控制器接收传感器信号；
S4：所述控制器分析所述信号的特征，并发出控制指令；
S5：所述执行机构根据所述控制指令执行相应动作；
```

## 易错句式对照

| 句式 | ❌ | ✅ |
|------|----|----|
| 动词开头 | 接收数据，进行处理… | 所述处理器接收数据，进行处理… |
| 「通过…」开头 | 通过加密算法对数据进行加密 | 所述加密模块通过加密算法对数据进行加密 |
| 被动缺施动者 | 数据被加密后存储 | 数据被所述加密模块加密后，由所述存储模块存储 |
| 并列换主语 | 所述控制器接收信号、处理信号，触发执行 | 所述控制器接收信号、处理信号，并触发所述执行机构执行相应动作 |

## 允许省略示例

✅ 同句并列、主语相同：
```
所述控制器接收信号、分析信号、并发出指令
```

✅ 「用于」锚定：
```
所述处理模块用于接收数据、处理数据并输出结果
```

## 典型案例

### 案例1：结构类主语省略

❌
```
其特征在于，还包括加密模块，
接收所述处理器发送的数据，
进行加密处理，
并将加密后的数据发送至所述通信模块。
```

✅
```
其特征在于，还包括加密模块，
所述加密模块用于接收所述处理器发送的数据，对所述数据进行加密处理，并将加密后的数据发送至所述通信模块。
```

### 案例2：方法类主语省略

❌
```
S3：获取用户输入，验证输入格式，判断是否有效，若是，则存储至数据库；
```

✅
```
S3：所述服务器获取用户输入；
S4：所述服务器验证所述输入的格式，判断所述输入是否有效；
S5：若判断结果为有效，则所述服务器将所述输入存储至数据库；
```

### 案例3：多主体交互

❌
```
S3：发送请求至服务器，接收服务器返回的响应，解析响应数据，并显示在界面上；
```

✅
```
S3：所述客户端发送请求至服务器，接收服务器返回的响应，解析所述响应中的数据，并将解析结果显示在界面上；
```

### 案例4：状态描述

❌
```
其特征在于，处于待机状态时，降低功耗；处于工作状态时，提高处理速度。
```

✅
```
其特征在于，所述处理器处于待机状态时，所述处理器降低功耗；所述处理器处于工作状态时，所述处理器提高处理速度。
```

## 指代与参照

## 指代词示例

### 1. 「该」→「所述」

❌ `包括固定座和活动臂，该固定座通过螺栓连接至底座`  
✅ `包括固定座和活动臂，所述固定座通过螺栓连接至底座`

### 2. 多同类对象

❌ `包括第一固定座、第二固定座和连接杆，其中，所述固定座与所述连接杆通过螺栓连接`  
✅ `……其中，所述第一固定座与所述连接杆通过螺栓连接`

### 3. 「其」不明

❌ `所述处理器接收所述传感器的信号，并对其进行处理`  
✅ `……并对所述信号进行处理`

### 4. 代词链过长

❌ 权3：`……其特征在于，其还包括加强筋`（「其」需回溯多层）  
✅ `……其特征在于，所述固定座还包括加强筋`

### 5. 并列混淆

❌ `所述第一模块和所述第二模块通过数据线连接，其输出端连接至控制器`  
✅ `……所述第一模块的输出端连接至控制器`

## 方位词示例

### 1. 周向缺参照轴

❌ `设有沿周向间隔分布的多个限位槽`  
✅ `设有沿所述枢转轴的周向间隔分布的多个限位槽`

### 2. 转动缺轴

❌ `所述活动臂能够相对于所述环管整体转动`  
✅ `所述活动臂能够绕所述枢转轴相对于所述环管整体转动`

### 3. 平行/垂直

❌（必要时加强）仅写两轴平行但整体坐标系不清  
✅ `所述第一轴和所述第二轴均垂直于所述底板平面且相互平行`

### 4. 螺旋缺参照

❌ `所述加热管呈螺旋状缠绕延伸`  
✅ `所述加热管绕所述芯轴呈螺旋状缠绕延伸`

### 5. 上下缺参照（清楚性）

❌ `所述支撑板位于上方`  
✅ `所述支撑板位于所述底座的上方`  
> 若问题是左/右是否过窄、要不要上位 → 转 `权利要求命名细则`

## 综合案例

### 案例1：结构类指代+方位

❌
```
该转轴可绕周向转动，且其外表面设有沿轴向延伸的凹槽。
```

✅
```
所述第一转轴可绕自身轴线转动，且所述第一转轴的外表面设有沿所述第一转轴的轴向延伸的凹槽。
```

### 案例2：方法类「其」

❌ `所述服务器接收客户端请求和用户数据，对其进行验证，并将其存储至数据库`  
✅ `……对所述用户数据进行验证，并将验证通过的所述用户数据存储至数据库`

### 案例3：多层从权复述

❌ 权4：`其特征在于，其输出端连接至显示器`  
✅ `其特征在于，所述处理器的输出端连接至显示器`
