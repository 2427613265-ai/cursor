# 权利要求表达清楚性规范

原 `权利要求主谓宾结构规范`、`权利要求指代与参照清晰性规范`、`权利要求清楚性与逻辑一致性规范` 已收束于此。正反例见同目录 `examples.md`（从权默认摘要自检，疑点再读示例）。

**必须先 Read** `清楚性与逻辑一致性共用内核`，检查对象 = **权利要求文本**。形式引用硬伤与「所述××」出处见 `权利要求形式与依附规范`。左/右等要不要扩围见 `权利要求命名细则` 第四节（本节只管参照清楚）。

## 分节何时用

| 时机 | 节 |
|------|----|
| 各版独权正文、从权摘要自检 | 一、主谓宾；二、指代与参照 |
| 撰写自查 / 整份质检清楚性 | 先共用内核，再三、权要侧差异 |

---

## 一、主谓宾

每个动作、状态、关系都必须有明确主语，避免省略导致执行者不清楚。

1. 动作必有执行者；状态必有归属；关系必有双方。  
2. 仅当主语**唯一、邻近、结构性已锚定、不引起歧义**时可承前省略。  
3. 易错：动词开头、「通过…」开头、被动缺施动者、并列动作中途换执行者未标出。  
4. 修正：补主语 → 调句式 → 拆句。不要为清楚而堆砌主语。

从权摘要：每个动作/状态能指出主语或合法承前省略；并列动作换执行者已重写主语。

---

## 二、指代与方位参照

1. **指代：** 优先「所述+完整名称」；少用「该」「其」；多同类必须消歧；代词链超过 2 层宜复述全称。并列结构后「其输出端」须能唯一确定。全文已统一用「该」且无歧义可接受。  
2. **方位参照（清楚，非扩围）：** 周向/轴向/径向、转动、移动、平行/垂直/倾斜、螺旋/弧形等，文字内必须能回答「相对于什么」。上/下/左/右作清楚性时也要有参照物；是否改为「一侧」扩围见命名细则第四节。

从权摘要：无「该/其」造成多对象歧义；出现周向/轴向/平行/上下等时文字能回答「相对什么」。

---

## 三、权要侧清楚性（相对共用内核）

先勾共用内核六条，再补：

- 非公知概念须在**权利要求内部**说清，落地写法见 `权利要求命名细则` 第五节（改自明名 / 前置白话 / 「其中」兜底）。不可只推说明书。  
- 反例常表现为：字面满足全部限定，却解决不了背景问题或不是发明想保护的方案。  
- 同物多名：同一特征全篇名称统一。  
- 同名多物（识别）：不同部件不得共用裸名；**改名落地**见 `权利要求命名细则` 第二节规则五。  
- 预设值先获取后使用 → `方法步骤条件与参数规范`。  
- 「所述××」是否落在引用链上 → `权利要求形式与依附规范`（不在本节重写算法）。

- [ ] 动作/状态/关系有主语或合法省略  
- [ ] 优先「所述」；多同类已消歧；方位词有参照物  
- [ ] 共用内核已勾；无同物多名；同名多物已转命名细则消歧
