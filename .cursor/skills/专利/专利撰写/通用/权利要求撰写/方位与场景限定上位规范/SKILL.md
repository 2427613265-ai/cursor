# 方位与场景限定上位规范（独权与从权通用）

## 适用场景 / 触发词

**应当加载本 skill 的典型情形：**

- 撰写或改写**从属权利要求 / 独立权利要求**时，出现或拟写入：左侧/右侧、前/后、上/下、上游/下游、迎水侧/背水侧、内侧/外侧、防洪、高水头、工程专名等；
- 用户问「左右怎么上位」「上游下游要不要改第一第二」「背水侧能不能上位」「场景词怎么放宽」；
- 质检/单条审查发现权利要求被观察方位或场景语不必要钉死。

**不替代：**

- `权利要求指代与参照清晰性规范`——方位是否有参照物、是否清楚；
- `独权撰写` 命名总规则——本 skill 是其在**方位/场景定语**上的专条展开；
- `自定义名词就地定义`——自定义结构名仍须就地定义（可与本 skill 并行）。

---

## 核心规则（各类共用）

1. **先问：这个限定是解决技术问题所必需，还是交底图/实施例习惯？**  
   - 习惯标签 → 能上位则上位；  
   - 必要结构/功能关系 → 保留。  
2. **两步判断（不得跳步）：**  
   - ① 改掉或放宽后，是否仍清楚，且能多覆盖等同实施方式？能 → 上位；  
   - ② 不能扩围 → 不要为「看起来更上位」而改成第一/第二或空泛词。  
3. **实施例具体侧向/场景下沉**：交底图的左/右、某枢纽专名等，优先说明书或下游从权收回。  
4. **禁止误伤结构名中的字面「侧/向」**：如「侧支孔」「轴向」「径向」中的字，不是观察「左侧」。

---

## 一、观察方位对（左/右 · 前/后 · 上/下）

**特征：** 多相对于看图方向或安装习惯，左右/前后镜像后方案往往仍成立。

| 档 | 写法 | 适用 |
|----|------|------|
| **A** | **一侧**；**至少一侧**；**一端**；**一侧端部** | 对称或可互换，优先 |
| **B** | **第一侧 / 第二侧**；**第一端 / 第二端** | 两侧都要写入同一条且需消歧，且序数比左/右更能扩围 |
| **C** | **左侧 / 右侧**；**前部 / 后部**；**上部 / 下部** | 不对称且为必要区别时保留 |

**从权默认：** 用 A；交底「左侧」用下游从权或说明书收回。

```
❌ 所述左侧阀门……所述左侧出水口……
✅ 所述一侧阀门……所述一侧出水口……
（下游从权可选）所述一侧阀门为左侧阀门……
```

**前/后、上/下同理：** 若仅为相对图纸，可改为「一侧/另一侧」「一端/另一端」「靠近××的一侧」；若「上部开口、下部封闭」本身解决技术问题，保留上/下。

---

## 二、流程 / 流体方向（上游 / 下游）

**特征：** 通常锚定**水流、物流、工艺顺序**，比左/右稳定，**不要盲目改成第一/第二**。

| 情形 | 处理 |
|------|------|
| 「上游门—缓冲池—下游闸室」等流向关系是方案骨架 | **保留**上游/下游（或改为已定义的部件名，如「所述缓冲池上游侧」） |
| 仅因图面把两个同类件标成上游件/下游件，功能完全对称可互换 | 可考虑第一×× / 第二××（仍先做两步判断） |
| 想扩围但不想丢流向 | 用「沿水流方向的上游侧 / 下游侧」并点明参照（水体/闸室），**清楚优先于序数** |

**禁止：** 把所有「上游叠梁门」无脑改成「第一叠梁门」导致与流向关系变糊。

---

## 三、功能侧（迎水侧 / 背水侧 · 进水侧 / 出水侧 · 高压侧 / 低压侧）

**特征：** 往往描述**受力、过流、工艺功能面**，常有技术含义，不是纯看图左/右。

| 情形 | 处理 |
|------|------|
| 阀在背水侧、拦污在迎水侧等，是布置贡献或必要关系 | **保留**迎水侧/背水侧（参照物：门体/水流） |
| 交底写死「背水侧」但任意一侧安装阀均可 | 可上位为「设置于所述门体的一侧」或「设置于所述输水管上」；背水侧下沉从权/说明书 |
| 进水口/出水口 | 保留功能名；不要改成含糊的第一口/第二口，除非两侧同构成对 |

```
✅ 保留（常见）：所述流量调节阀设置于所述上游门体的背水侧。
✅ 可上位（若任一侧均可）：所述流量调节阀设置于所述输水管上。
   （从权）……且位于所述上游门体的背水侧。
```

---

## 四、内外侧（内侧 / 外侧 · 内壁 / 外壁 · 腔内 / 腔外）

| 情形 | 处理 |
|------|------|
| 「安装于内壁」「开口朝向外侧」是装配关系本身 | **保留**内外，并保证参照物清楚 |
| 内外仅实施例习惯、镜像外壳同样可装 | 可改为「一侧壁」「朝向远离××的一侧」等，仍须清楚 |

---

## 五、场景 / 用途 / 工程钉死语

**特征：** 防洪、高水头、某某枢纽、1000 吨级等，常把范围缩到交底场景。

| 档 | 处理 |
|----|------|
| 独权 / 较宽从权 | 能删则删，或上位为领域通用名（如「检修门」「船闸过鱼系统」） |
| 说明书 / 最下游从权 | 保留「高水头」「防洪检修」等实施例语境 |

与 `独权撰写` 第三版「过窄材料/结构/用途定语能上位则上位」一致；本 skill 负责提醒**从权也不要无必要重复钉死**。

---

## 六、易混：「侧」字不是「左侧」

| 用语 | 处理 |
|------|------|
| 侧支孔、侧向孔口、侧壁、旁通 | **结构/方向用语，保留**；用就地定义说清含义 |
| 左侧通道、右侧阀门 | **观察方位**；按第一节上位 |
| 轴向、径向、周向 | 属参照系方位 → 指代 skill 管清楚；本 skill 一般不改名 |

---

## 从属权利要求专项（硬性）

1. 布局或正文一出现本 skill 覆盖的限定语 → **先 Read 再写**。  
2. **观察方位对**默认 A 档；**功能侧 / 上下游**默认谨慎保留，仅当确认可互换才上位。  
3. 交付物写明：本条用了哪一类、选了哪一档、一句话理由。  
4. 同一条不要「一侧」上位后又无必要夹带「左侧」把范围缩回（除非本条职责就是实施例收回）。

## 检查清单（总）

- [ ] 每个方位/场景定语是否经过「必要 vs 习惯」判断？  
- [ ] 观察方位是否优先「一侧／一端」而非默认第一/第二？  
- [ ] 上游/下游、迎水/背水是否被盲目序数化？  
- [ ] 场景钉死语是否不必要地出现在较宽权利要求中？  
- [ ] 上位后是否仍清楚（参照物另查指代 skill）？
