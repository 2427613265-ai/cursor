# 权利要求依附编号与术语出处规范

## 适用场景

- **撰写从属权利要求时**（`从权撰写` 第3步门禁、单条交付前微型自检、第4步全文核对表）；
- **整份权利要求书质检时**（`权利要求书质检` 维度二第1点／输出项「依附编号错误」）；
- 单条审查中发现「所述××」可能无先行基础时按需加载。

**本 skill 管什么：** 「所述／该」等回指用语所指向的名词，其**首次引入是否落在本条引用链上**——即依附编号与术语出处是否一致。

**不管什么：**

- 引用方向、多项择一、主题名称等**纯格式** → `权利要求形式合规性规范`；
- 独立改进该平行、依赖该串联等**引用结构策略** → `权利要求引用结构检查`；
- 指代词是否应写全称、多对象消歧 → `权利要求指代与参照清晰性规范`（可与本 skill 并行）。

---

## 核心规则（一句话）

**只要从权用到了某个须回指的词，而本条引用链上找不到该词的首次引入，就是依附编号／术语出处错误，必须改；禁止凭感觉写「所述有先行基础」。**

---

## 机械核对算法（撰写与质检同一套）

对每一条从属权利要求 \(N\)：

### 1. 列词

列出本条正文中所有带「所述」（及同等回指如不当使用的「该」）的名词。

- 「所述锚固箱的底板」→ **分别**核对「锚固箱」与「底板」；
- 主题名称重复（如「所述……锚固结构」仅作引用套话）可不入表，但特征部分的部件／步骤名必须入表。

### 2. 溯源

对每个词，在**本条之前的全部权利要求**（权1～权 \(N-1\)，**不是**只在当前引用链上）中查找**首次出现／首次引入**的权号。

- 本条以「包括／还包括／设有××」等**首次引入**、且未写成「所述××」的词 → 记为「本条新引入」，不要求上游出处。
- 公知且未当作本发明部件名回指的用语（如单独出现的「混凝土」作材料修饰）按案件判断；一旦写成「所述××」并当作已定义部件，必须溯源。

### 3. 取最大号

在「须有出处」的词中，取其首次出现权号的**最大值** \(M\)（并保留每个词各自的首次权号，供逐词覆盖判定）。

### 4. 覆盖判定

画出本条引用链：权 \(N\) → 直接引用对象 → … → 权1。

**通过条件：** 每个须出处的「所述××」，其首次出现权号都落在该引用链上的某一节点。

**失败条件：** 任一所述词的首次出现权号**不在**引用链上（典型：词在平行从权中引入，本条却只引权1）。

### 5. 失败则三选一处置（禁止带病交付／带病出质检结论而不给改法）

| 代号 | 处置 | 适用 |
|------|------|------|
| **A. 改引用** | 改为引用（或经串联能覆盖）首次出现该词的权利要求 | 技术上本就依赖该上游从权 |
| **B. 本条首次引入** | 去掉不当「所述」，改为「所述母件设有／包括××」在本条给出 | 不欲串联、且本条可自足引入 |
| **C. 布局调整** | 先写／合并能提供出处的上游从权，或增加组合依赖后再写本条 | A/B 都不顺时 |

质检输出时：逐条写明「权 \(N\) → 问题词 → 首次出现于权 \(X\) → 当前链 → 建议 A/B/C」。

## 交付用表（撰写必附）

### 单条微表（`从权撰写` 每条交付）

| 所述词 | 首次出现权号 | 本条引用链是否覆盖 | 处置（通过／A／B／C） |
|--------|--------------|--------------------|------------------------|

### 全文核对表（`从权撰写` 第4步；质检可复用）

| 权号 | 所述词（可多词合并） | 首次出现权号 | 引用链 | 覆盖 | 处置 |
|------|----------------------|--------------|--------|------|------|
| … | … | … | … | 是/否 | 通过／A／B／C＋说明 |

**任一行「覆盖=否」且未标明已处置 → 从权撰写不得收束；质检必须列入「依附编号错误」。**

## 正反例（锚固结构案型）

### 反例1：平行从权引入的子件被下游误用（权6）

- 权2引入「顶板」；权4引入「底板」；权5引权1写螺栓连接；权6引权5写「所述锚固箱的底板与所述钢牛腿的顶板之间…」。
- 引用链 6→5→1 **不含**权2、权4 → **失败**。
- 处置：**B** 在权6写「所述锚固箱设有底板，所述钢牛腿设有顶板，所述底板与所述顶板之间…」；或 **A/C** 调整引用／组合布局使链覆盖权2与权4。

### 反例2：侧板仅在权4出现，权7却引权1（权7）

- 权4引入「侧板」；权7引权1写「焊接固定于所述锚固箱的侧板外侧」。
- 链 7→1 无侧板 → **失败**。
- 处置：**A** 改为引权4；或 **B**「所述锚固箱设有侧板，…固定于所述侧板外侧」。

### 正例

- 权2引入「塔壁钢板」；权3引权2写「所述塔壁钢板的内侧设有抗拔锚筋」→ 链 3→2→1 覆盖 → **通过**。

## 与其他 skill 的挂接

| Skill | 关系 |
|-------|------|
| `从权撰写` | **门禁必读**；第3步按本规范做微表；第4步按本规范做全文表；算法以本文件为准，从权撰写内仅保留短指引＋表格式 |
| `权利要求书质检` | **维度二第1点执行本规范**，不在质检 skill 内重写算法；输出格式仍用质检总控的「依附编号错误」栏 |
| `权利要求质检总控` | 整份链路中「依附编号」＝调度执行本规范 |
| `权利要求清楚性与逻辑一致性规范` | 「引用编号与术语来源对应」专项指向本规范 |
| `权利要求形式合规性规范` | 只做编号大小／多项格式；不做术语出处 |
| `权利要求引用结构检查` | 只做平行／串联策略；策略正确仍可能术语出处失败，两套都要过 |

## 检查清单

- [ ] 每条从权的「所述××」已列全（含「所述A的B」拆开）
- [ ] 首次出现权号是在**全文前序权利要求**中查的，不是只在引用链上查的
- [ ] 每个须出处词的首次权号都落在本条引用链上
- [ ] 失败项已选 A/B/C 之一并改稿（撰写）或写入质检意见（质检）
- [ ] 撰写已附单条微表；从权收束已附全文核对表

## 应用范围

任意技术方案类型（结构类／方法类／算法类）的从属权利要求撰写与质检。独立权利要求无「引用链」问题，但独权内部「所述」仍须在本条已出现特征中有先行基础（本条自洽），不适用「改引用」处置。
