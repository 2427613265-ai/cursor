# 权利要求形式与依附规范

原 `权利要求形式合规性规范`、`权利要求依附编号与术语出处规范` 已收束于此。点名旧名即读对应节。平行/串联布局策略见 `权利要求引用结构检查`（策略对仍可能术语出处失败，两套都要过）。指代是否写全称见 `权利要求表达清楚性规范`。

## 分节何时用

| 时机 | 节 |
|------|----|
| 写从权 / 整份质检第一步 | 一、形式硬伤 |
| 从权出现「所述××」；从权第3步微表、第4步全文表；质检「依附编号错误」 | 二、术语出处 |

独立权利要求无引用链，但独权内部「所述」仍须在本条已出现特征中有先行基础（本条自洽），不适用「改引用」。

---

## 一、形式硬伤（《专利法实施细则》第二十五条）

非黑即白；质检须在引用结构与实质布局之前先排除。

1. **只能引用在前：** 权 N 引用号必须 **< N**，不得引自己或更大号。  
2. **多项须择一：** 引用两项以上须用「或」「任一项」，不得用「和」「及」「与」。  
3. **多项不得再被多项引用：** 多项从权可被**单独**引用（「根据权利要求3所述」），不得再被另一多项择一引用（「根据权利要求3或5所述」且3本身是多项）。  
4. **引用部分写明编号及主题名称**，主题名称与独权一致（装置/方法不可中途换成设备）。  
5. **编号从1连续、无跳号无重复**；每项独立成段、句号结尾；引导句式全篇统一（`一种XXX，其特征在于，……` / `根据权利要求X所述的XXX，其特征在于，……` / `根据权利要求X至Y中任一项所述的XXX，其特征在于，……`）。

核对：提取引用号是否均 < 自身 → 多项是否择一 → 被引号中有无多项从权 → 有无主题名称 → 全篇编号与句末句号。

---

## 二、依附编号／术语出处

**只要从权用到须回指的词，而本条引用链上找不到该词的首次引入，就是错误，必须改。禁止凭感觉写「所述有先行基础」。**

对每一条从权 N：

1. **列词：** 列出带「所述」（及不当「该」）的名词。「所述锚固箱的底板」分别核「锚固箱」与「底板」。主题名称套话可不入表；特征部分必须入表。  
2. **溯源：** 在权1～权 N−1 **全文前序**（不是只在当前引用链上）查首次引入权号。本条以「包括／还包括／设有××」首次引入且未写成「所述××」→ 记「本条新引入」。一旦写成「所述××」当已定义部件，必须溯源。  
3. **覆盖：** 画出引用链 N→…→权1。每个须出处词的首次权号都须落在链上某一节点。失败典型：词在平行从权引入，本条只引权1。  
4. **失败三选一（禁止带病交付）：**  
   - **A 改引用**（或经串联能覆盖首次出现该词的权）；  
   - **B 本条首次引入**（去掉不当「所述」，改为「所述母件设有／包括××」）；  
   - **C 布局调整**（先写能提供出处的上游从权或增加组合依赖）。  

质检：逐条「权 N → 问题词 → 首次出现于权 X → 当前链 → 建议 A/B/C」。

### 交付用表

单条微表（从权每条）：所述词｜首次出现权号｜引用链是否覆盖｜处置（通过／A／B／C）

全文表（从权第4步／质检可复用）：权号｜所述词｜首次出现权号｜引用链｜覆盖｜处置  

**任一行「覆盖=否」且未标明已处置 → 从权不得收束；质检必须列入「依附编号错误」。**

## 最低自检

- [ ] 引用号 < 本条；无多项套多项；主题名称与独权一致；编号连续  
- [ ] 「所述××」已列全（含「所述A的B」拆开）；首次权号在全文前序中查  
- [ ] 每个须出处词的首次权号都在本条引用链上；失败已 A/B/C
