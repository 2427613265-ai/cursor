# 部件命名具体优化（执行叶）

**定位：** 命名执行叶。由 `部件命名优化总控` 在 **A 型 / E 型**（以及口语或方位改名之后的两档审查）打开。

**禁止直触：** 撰写独权/从权或质检名称问题时，须先走 `部件命名优化总控`。若误进本页，立刻回到总控分型，不在本页独自收口对照表策略。

本页**不管**：口语名能不能改成自明名、名称里的方位词要不要上位、改不动怎么就地定义。那些由总控按流水线打开对应叶。本页只在「已经是（或即将作为）结构名/功能结构名」的前提下，处理定语、两档和同名多物。

适用对象与总控相同：结构部件名，以及方法/算法案的数据对象、中间量、模块、步骤产物名。

---

## 本页管什么

1. **去非必要缩限**：删除名称中不必写死的材料、性能、效果、用途定语；
2. **两档对照**：在清楚前提下给出更宽/更稳妥的一档；
3. **同名多物消歧**：不同件不得共用裸名。

深度（第一版少动、第二版去非必要、第三版扩围）由**调用方版本**决定；本页手法不变，不平行维护分版策略。

---

## 规则一：先拆成结构核心词和修饰语

- **结构核心词**（或方法案的对象核心词）：板、杆、箱、套、座、块、孔、槽、肋、螺栓、垫板；以及「比值」「特征簇」「节点」等；
- **可能可删或可上位的修饰语**：钢、高强、防腐、调心、限位、专用、防洪、锚下等。

优先保留真正限定结构（或数据对象）边界的词，审查修饰语是否必须保留。

名称中的左/右、上游/下游等**方位词**若尚未经总控打开 `方位与场景限定上位规范`，停止本页，标回 **C 型** 交总控。不要在本页做方位上位。

原名仍是口语/临时叫法、尚未改成结构名时，停止本页，标回 **B 型** 交总控。不要在本页改口语名。

---

## 规则二：材料/性能/效果/用途定语不当然保留

| 类型 | 常见词 | 审查动作 |
|------|--------|----------|
| 材料 | 钢、橡胶、不锈钢、聚四氟乙烯 | 该材料是否解决当前问题所必需；不是则删除或下放从权 |
| 性能/强度 | 高强、高压、高精度 | 先改成中性名；性能要求另作从权或说明书 |
| 效果/功能 | 调心、限位、防尘、防腐、抗拔 | 先问是在命名结构，还是偷带效果；仅效果则改中性结构名 |
| 用途（非方位） | 专用、塔端 | 是否为保护范围所必需；非必要则删除或下放 |

**示例：**

- `高强螺栓` → 默认审查为 `螺栓`；「高强」非区别点则不保留。
- `防腐护套` → 若只是用途，可考虑 `护套`；若本领域已固定成自明结构名可保留并说明。
- `球面调心垫板` → 「球面」是否结构必要；「调心」若只是效果，比较 `球面垫板` / `垫板`。

句尾「用于…」「从而…」不是本页范围，见 `功能性限定使用边界规范`（由撰写/质检调用方直挂，不经本页转发）。

---

## 规则三：每次至少两档对照

对拟入权的**关键名**：

`原名（或上一叶给出的候选名） → 第一档优化名 → 第二档优化名`

并判断：哪一档更清楚；哪一档更宽；更宽档会不会把边界写糊。更宽档已不清楚则退回上一档。

表头、确认闸门、独权/从权交表策略以 `部件命名优化总控` 为准。本页只负责填出第一档、第二档和推荐理由。

---

## 规则五：跨权利要求「同名多物」必须消歧（硬性）

**问题：** 两个（或多个）**不同结构位置 / 不同功能归属** 的对象，共用**同一个裸名**（例如权4箱内「加劲板」、权7拉杆端「加劲板」）。

与「同物多名」（同一件换了好几个叫法）相反，同样导致「所述××」指向不清。识别由 `权利要求清楚性与逻辑一致性规范` 负责；**改名落地**由本规则执行（经总控 E 型打开）。

**自检句（写每个新名称时必问）：**  
这个名字在本权利要求书**已出现的名称**里，是否已经用来指过**另一个不同位置或归属**的对象？

- 是 → 不得再使用该裸名，先消歧改名再落笔；
- 否 → 可通过。

**对照范围：**

- 写独权任一版：对照本版拟用全部名称内部是否互撞，并对照交底/上一版已定名；
- 写每一条从权：对照**权1至本条之前（含平行从权已写正文）**已入权的全部名称。

**消歧优先级（改名，不是只加「所述」）：**

1. **加归属前缀（首选）**：`锚固箱加劲板` / `拉杆加劲板`；
2. **加功能或位置结构定语**：`承压加劲板` / `箱内加劲板`；
3. **同条内多个同类件**：改用第一/第二；写法清楚性见 `权利要求指代与参照清晰性规范`（本页不 Read 该全文，对照表备注即可）；
4. **禁止**：不同权利要求各写一个裸名，指望读者靠上下文猜。

**若冲突发生在已写正文之间：** 优先改后写/新引入的那一条；若前条裸名过泛、后条改名仍易混，可将前条一并改为带归属前缀，全书统一。

## 操作步骤（本页内）

对总控交来的每个名称：

1. 若仍是口语名或名称中含未处理方位词 → **停止，标回总控 B/C 型**；
2. 拆词：核心词 vs 修饰语；
3. 判必要性：修饰语对当前条所解决问题是否必需；
4. 尝试去掉修饰语后是否仍清楚，给出两档；
5. 对照已入权名称表，执行规则五；冲突则加归属前缀或功能/位置定语；
6. 两档仍不自明 → **停止，标回总控 D 型**（不要在本页写「其中」定义）。

## 典型判法

### 例1：高强螺栓

- 第一档：螺栓；第二档：连接螺栓
- 若本条只限定「用螺栓连接」，`高强` 通常非必要；默认优先 `螺栓`；与销轴、焊缝区分时可用 `连接螺栓`。

### 例2：防腐护套

- 第一档：护套；第二档：密封护套 / 保护护套
- 若限定的是「外部套设一层套体」，`护套` 通常足够；`防腐` 多为用途/效果。

### 例3：横向限位挡块

- 第一档：限位挡块；第二档：挡块
- 「横向」对区别方向确有必要可保留；若句中关系已能看出方向则可去掉；再去掉 `限位` 后边界过空则停在第一档。

### 例4：两处「加劲板」

- 权4已有裸名 `加劲板`，权7拟再用 → 自检句命中；
- 权4 `锚固箱加劲板`，权7 `拉杆加劲板`（或后写条单方加前缀，前条过泛时两边都改）。

### 例5：调节比（方法案中间量，A 型定语）

- 若原名是「高精度调节比」，先问「高精度」是否必要；两档比较 `调节比` / 更中性的比值名。含义怎么说清属 D 型，交总控打开就地定义。
