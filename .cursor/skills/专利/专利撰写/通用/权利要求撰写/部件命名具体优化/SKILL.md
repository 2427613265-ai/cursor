# 部件命名具体优化（具体执行 skill）

## 适用场景

- 写独立权利要求第一版、第二版、第三版时；
- 写每一条从属权利要求时；
- 审核权利要求中的部件名称是否过窄、带有非必要效果/材料/性能定语、是否属于交底口语名或图纸习惯名时。

**定位：本 skill 是具体执行层，通常由 `部件命名优化总控` 先判型后再调用。**

---

## 核心目标

对部件名称做三件事：

1. **去口语化**：把交底口语名、图纸习惯名、临时叫法改成自明结构名或功能结构名；
2. **去非必要缩限**：删除名称中不必写死的材料、性能、效果、用途、场景定语；
3. **保清楚、再扩围**：在不牺牲清楚性的前提下，把名称改到更宽、更稳妥的一档。

---

## 核心规则

### 规则一：先问“这个名称是不是结构名本身”

先把名称拆开看：

- **真正的结构核心词**：板、杆、箱、套、座、块、孔、槽、肋、螺栓、螺母、垫板、支撑板等；
- **可能可删或可上位的修饰语**：钢、高强、防腐、调心、限位、锚下、上游、下游、左、右、专用、防洪等。

写权利要求时，优先保留真正限定结构边界的词，审查修饰语是否必须保留。

---

### 规则二：部件名称中的材料/性能/效果词，不当然保留

凡名称中带下列定语时，必须单独追问是否属于必要限定：

| 类型 | 常见词 | 审查动作 |
|------|--------|----------|
| 材料 | 钢、橡胶、不锈钢、聚四氟乙烯 | 先问该材料是否解决当前问题所必需；不是则上位删除或下放从权 |
| 性能/强度 | 高强、高压、高精度 | 先改成中性结构名；性能要求另作从权或说明书 |
| 效果/功能 | 调心、限位、防尘、防腐、抗拔 | 先问该词是在命名结构，还是偷带效果；若仅是效果，优先改成更中性的结构名 |
| 场景/用途 | 上游、下游、防洪、专用、塔端 | 先判断是否为保护范围所必需；非必要则上位或下放 |

**典型示例：**

- `高强螺栓` → 默认先优化审查为 `螺栓`；只有当“高强”本身是区别点或不可替代时才保留。
- `防腐护套` → 先问是仅表示用途，还是本领域已固定成自明结构名；若只是用途，可考虑 `护套`。
- `球面调心垫板` → 先问“球面”是否是结构必要限定；“调心”若只是效果词，可考虑改写为带球面配合面的垫板，或保留为功能结构名并说明理由。

---

### 规则三：优先改成“自明结构名 / 功能结构名”

命名优化优先级：

**自明结构名 > 功能结构名 > 原口语名 + 解释**

也就是说：

1. 能直接改成自明结构名，先改；
2. 纯结构名改不清楚时，可改成业内一看就懂的功能结构名；
3. 仍改不清楚时，再转 `交底口语名改写为自明结构名规范` 与 `自定义名词就地定义`。

---

### 规则四：每次至少做“两档命名对照”

对拟入权的关键部件名，至少在心里或书面完成两档比较：

`原名 → 第一档优化名 → 第二档优化名`

并判断：

1. 哪一档**更清楚**；
2. 哪一档**更宽**；
3. 更宽那一档会不会把结构边界写糊。

若更宽档已不清楚，则退回上一档；不要为扩围而牺牲可读性。

**独权额外硬性：** 因独权部件名直接关系保护范围，两档对照必须做成表格交付用户选择确认；列至少包括：原名、第一档、第二档、推荐采用名、对保护范围的影响、用户选择。未经用户确认，不得据此直接写独权正文。

---

### 规则五：跨权利要求「同名多物」必须消歧（硬性）

**问题类型：** 两个（或多个）**不同结构位置 / 不同功能归属** 的部件，在权利要求书中使用了**同一个裸名**（例如权4箱内「加劲板」、权7拉杆端「加劲板」）。

这与「同物多名」（同一件换了好几个叫法）相反，但同样导致「所述××」指向不清。

**自检句（写每个新部件名时必问）：**  
> 这个名字在本权利要求书**已出现的部件名**里，是否已经用来指过**另一个不同结构位置或功能归属**的件？

- 是 → 本条不得再使用该裸名，必须先消歧改名再落笔；
- 否 → 可通过。

**对照范围：**

- 写独权任一版：对照本版拟用全部部件名内部是否互撞，并对照交底/上一版已定名；
- 写每一条从权：对照**权1至本条之前（含平行从权已写正文）**已入权的全部部件名称。

**消歧优先级（改名，不是只加“所述”）：**

1. **加归属前缀（首选）**：`锚固箱加劲板` / `拉杆加劲板`；`拉索锚垫板` / `拉杆垫板`；
2. **加功能或位置结构定语**：`承压加劲板` / `箱内加劲板`；
3. **同条内多个同类件**：改用第一/第二，并转 `权利要求指代与参照清晰性规范`；
4. **禁止**：不同权利要求各写一个裸名「加劲板」「承压板」「垫板」，指望读者靠上下文猜。

**若冲突发生在已写正文之间：**  
优先改**后写/新引入**那一条的名称；若前条裸名过于泛化、后条改名仍易混，可将前条一并改为带归属前缀的名称，并保持全书统一。

**与清楚性规范的分工：**  
`权利要求清楚性与逻辑一致性规范` 负责识别「同名多物 / 同物多名」；**改名落地**由本规则执行。

## 分阶段要求

### 一、独权第一版

目标：忠实转写交底，但要先去掉明显口语名、临时名。  
此时允许保留部分较具体但清楚的名称，不追求最大扩围。

### 二、独权第二版

目标：结合重新界定后的技术问题，去掉名称中的非必要缩限词。  
重点清理：

- 高强/专用/防腐/高水头/上游等非必要定语；
- 数量、场景、材料等可概括词；
- 名称里偷带效果的词。

### 三、独权第三版

目标：在清楚前提下，把名称优化到保护范围最大。  
必须显式比较至少两档命名方案。

### 四、每条从权

目标：凡新出现一个部件名，都要问一遍：

1. 这是自明结构名吗？
2. 这里是不是把材料、效果、性能偷偷写进名字里了？
3. 这个词应该保留在名称里，还是改成中性结构名，把限定内容留到句子后半段？
4. **它是否与已入权的其他部件同名异物？**（规则五）

---

## 操作步骤

对每个部件名依次做以下判断：

1. **先拆词**：找出核心结构词和修饰词；
2. **判必要性**：修饰词是否对当前权利要求解决的问题必需；
3. **尝试上位**：去掉修饰词后是否仍清楚；
4. **尝试改名**：若原名口语化，改成结构名或功能结构名；
5. **同名冲突审查（硬性）**：对照已入权部件名表，执行规则五；冲突则加归属前缀或功能/位置定语消歧；
6. **必要时转其他 skill**：
   - 名称像方位/场景钉死语 → `方位与场景限定上位规范`
   - 名称本身是交底口语 → `交底口语名改写为自明结构名规范`
   - 改不动仍不自明 → `自定义名词就地定义`
   - 同条内多个同类件需序数消歧 → `权利要求指代与参照清晰性规范`

---

## 典型判法

### 例1：高强螺栓

- 原名：高强螺栓
- 第一档：螺栓
- 第二档：连接螺栓

判断：

- 若当前条仅想限定“通过螺栓连接”，则 `高强` 通常不是必要技术特征；
- 默认优先 `螺栓`；
- 若需要与销轴、焊缝等区分，可用 `连接螺栓`；
- `高强` 留到更下位从权或说明书。

### 例2：防腐护套

- 原名：防腐护套
- 第一档：护套
- 第二档：密封护套 / 保护护套

判断：

- 若本条真正限定的是“外部套设一层套体”，通常 `护套` 已足够；
- `防腐` 多为用途/效果词，优先删除或下放。

### 例3：横向限位挡块

- 原名：横向限位挡块
- 第一档：限位挡块
- 第二档：挡块

判断：

- 若“横向”对区别方向确有必要，可保留；
- 若仅在图上是横向，且从句子关系已可看出，则可上位成 `限位挡块`；
- 若再去掉 `限位` 后结构边界过空，则停在第一档。

### 例4：两处「加劲板」（同名多物）

- 权4锚固箱内已有：`加劲板`
- 权7拉杆端拟再写：`加劲板`

判断：

- 自检句命中：裸名已被另一结构位置占用；
- 消歧：权4改为 `锚固箱加劲板`，权7改为 `拉杆加劲板`（或后写条单方加前缀，前条过泛时两边都改）；
- 禁止两条从权各留一个裸名「加劲板」。

## 输出格式建议

当用户要求显式审查命名时，或**撰写独权任一版本时（硬性）**，须用下表：

| 部件原名 | 第一档优化 | 第二档优化 | 推荐采用名 | 对保护范围的影响 | 用户选择 |
|----------|------------|------------|------------|------------------|----------|
| 高强螺栓 | 螺栓 | 连接螺栓 | 螺栓 | 去掉性能定语，范围更宽且仍清楚 | 待确认 |

- **独权：** 必须交表并等用户确认/改选后，再写该版独权正文。  
- **从权：** 默认可简记结论；若命名会影响保护范围理解，升格为上表请确认。

若只是从权正常撰写且命名无争议，可只在心里完成同样判断，不必每次都外显整张表。

---

## 检查清单

- [ ] 本版独权 / 本条从权中的每个新增部件名，都已做过命名审查
- [ ] 名称中是否夹带了非必要材料、性能、效果、用途、场景定语
- [ ] 能否删掉这些定语而仍保持清楚
- [ ] 交底口语名是否已优先改成自明结构名
- [ ] 改不动的名称是否已转用“就地定义”规范
- [ ] 术语前后一致，没有同物多名
- [ ] **已对照已入权部件名表，没有跨权利要求的同名多物；冲突处已用归属前缀等消歧**

## 与其他 skill 的分工

- `部件命名优化总控`：本 skill 的总控入口，先分型再决定是否调用本 skill；
- `交底口语名改写为自明结构名规范`：处理口语名、临时名能否直接改写；
- `方位与场景限定上位规范`：处理名称中的左/右、上游/下游、防洪等场景钉死语；
- `自定义名词就地定义`：名称改不动时，负责在权利要求里定义；
- `权利要求清楚性与逻辑一致性规范`：识别同名多物/同物多名；**改名落地由本 skill 规则五执行**；
- `权利要求指代与参照清晰性规范`：同条内多个同类件的第一/第二消歧；
- `独权撰写`：第三版时强制做两档以上命名优化对照；
- `从权撰写`：每条从权新增部件名时，必须调用本 skill（含同名冲突审查）。
