# 部件命名优化总控（先分型，再调用具体 skill）

## 适用场景

- 写独权第一版、第二版、第三版之前；
- 写每一条从权之前；
- 审核权利要求中某个部件名是否要改名、上位、删定语、消歧、定义或调整母子件命名层级时。

**硬性规则：本 skill 是总控入口。独权/从权总控应先触发本 skill，再由本 skill 分流调用具体命名优化 skill。**

---

## 本 skill 管什么

本 skill **不直接替代所有具体命名规则**，而是先做三件事：

1. 识别当前部件名的问题类型；
2. 决定本轮要调用哪一个或哪几个具体 skill（直接命名类 / 间接校正类）；
3. 给出本轮命名优化的最小交付要求。

---

## 一、挂接清单（完整版）

### A. 直接命名类（必须挂接；命中即分流）

| 具体 skill | 管什么 |
|------------|--------|
| `部件命名具体优化` | 名称中的材料/性能/效果/用途/场景定语是否非必要；两档命名对照 |
| `交底口语名改写为自明结构名规范` | 交底口语名、图纸习惯名、临时名能否改成自明结构名/功能结构名 |
| `方位与场景限定上位规范` | 名称中的左/右、上/下、上游/下游、内/外、防洪等方位/场景钉死语是否应上位 |
| `自定义名词就地定义` | 改名后仍不自明的本案特有词，用“其中……”就地定义 |

### B. 间接校正类（建议挂接；按条件分流）

| 具体 skill | 管什么 | 何时分流 |
|------------|--------|----------|
| `权利要求清楚性与逻辑一致性规范` | 同物多名、同名多物、术语跳变 | 同一对象出现多种叫法，或不同对象共用一名时 |
| `权利要求指代与参照清晰性规范` | 第一/第二、所述××消歧；方位参照是否清楚 | 存在多个同类部件，或名称依赖序数/方位消歧时 |
| `结构类权利要求撰写` | 母件名与子件名层级；子件不得与母件同级并列 | 一次引入多个新部件，或展开某母件内部构成时 |
| `功能性限定使用边界规范` | 名称是否偷带功能/效果，是否应把功能从名称挪到句中限定 | 名称含调心、限位、防腐、抗拔、用于…等功能/效果色彩时 |

## 二、先识别问题类型

对每个拟入权部件名，按下表分型：

| 类型 | 典型表现 | 下一步调用 |
|------|----------|------------|
| A. 名称夹带材料/性能/效果/用途/场景定语 | 高强螺栓、防腐护套、上游锚固箱、专用支架 | **必须** `部件命名具体优化`；若定语偏功能效果，可并行 `功能性限定使用边界规范` |
| B. 名称是交底口语名/图纸习惯名/临时名 | 小板、连接块、那个支撑件、侧支结构 | **必须** `交底口语名改写为自明结构名规范`；改后再回 `部件命名具体优化` |
| C. 名称中带左/右、上/下、上游/下游、内/外等方位或场景词 | 左侧板、下游支架、外侧孔 | **必须** `方位与场景限定上位规范`；之后再回 `部件命名具体优化` |
| D. 名称改不动仍不自明 | 本案特有词、自造词、缩略词 | **必须** `自定义名词就地定义` |
| E. 名称前后一致性可疑 | 同物多名、同名多物、术语跳变 | **按条件** `权利要求清楚性与逻辑一致性规范` |
| F. 同类部件需要消歧命名 | 第一/第二锚固单元、所述锚下承压板指哪一块 | **按条件** `权利要求指代与参照清晰性规范` |
| G. 母件/子件命名层级可疑 | 把子板与母箱写成同级“还包括” | **按条件** `结构类权利要求撰写` |
| H. 名称偷带功能效果 | 调心垫板、限位挡块、防腐护套 | **按条件** `功能性限定使用边界规范` + **必须** `部件命名具体优化` |

## 三、调用顺序

默认按下列顺序分流（按需中止，不必五/八个全跑）：

### 直接命名链路（优先）

1. **`部件命名具体优化`**  
   处理高强、钢、防腐、调心、限位、专用等非必要定语；
2. 若名称本身不是自明结构名，转  
   **`交底口语名改写为自明结构名规范`**；
3. 若名称里含方位/场景词，转  
   **`方位与场景限定上位规范`**；
4. 若改名后仍不自明，转  
   **`自定义名词就地定义`**。

### 间接校正链路（命中条件时追加）

5. 名称含明显功能/效果色彩时，追加  
   **`功能性限定使用边界规范`**；
6. 一次引入多部件或展开母件内部构成时，追加  
   **`结构类权利要求撰写`**（核对命名层级）；
7. 存在多个同类件、需序数/方位消歧时，追加  
   **`权利要求指代与参照清晰性规范`**；
8. 落笔前若发现同物多名/同名多物，追加  
   **`权利要求清楚性与逻辑一致性规范`**。

> 说明：并非每个名称都要八个 skill 全跑一遍，而是先由本总控判型，再按需分流。

## 四、独权与从权的最低要求

### ★ 独权硬性闸门（因命名直接影响保护范围）

**每一版独权（第一版 / 第二版 / 第三版）在写出独权正文之前，必须先交付「部件命名优化对照表」供用户选择确认；未经用户确认，不得直接输出该版独权全文。**

原因：独权中的部件名称直接框定保护范围；命名过窄会不当限缩，命名过宽或不清会损害可实施性与确权稳定性，必须由用户对采用名做明示确认。

对照表最低列：

| 部件原名（交底/上一版） | 分型 | 第一档优化 | 第二档优化 | 推荐采用名 | 对保护范围的影响（一句话） | 用户选择 |
|------------------------|------|------------|------------|------------|----------------------------|----------|
| … | A/B/… | … | … | … | 变宽/变窄/更清楚/需定义 | 待确认 |

规则：

1. 关键入权部件（尤其是独权顶层部件与核心连接件）**逐一入表**，不得只口头说“已优化”；
2. 至少给出**两档**优化名（第三版硬性；第一、二版对关键名也须两档，次要名可一档+保留说明）；
3. 表中须标**推荐采用名**及**对保护范围的影响**；
4. 标注「**待确认：独权部件命名表**」；
5. **用户确认或改选采用名之后**，才允许进入该版独权正文撰写；
6. 若用户改选了更宽/更窄档，须按确认结果落笔，并在独权交付物中注明“命名已按用户确认表采用”。

### 1. 独权第一版

- 必须触发本总控；
- 至少完成：明显口语名、明显非必要定语的筛选；
- **先出命名对照表 → 用户确认 → 再写第一版独权**；
- 不要求本轮一定扩到最宽，但不能把明显错误名称直接带入。

### 2. 独权第二版

- 必须触发本总控；
- 至少完成：去掉与重新界定技术问题无关的材料/性能/效果/场景定语；
- **先出命名对照表 → 用户确认 → 再写第二版独权**；
- 若当前名称仍夹带非必要缩限，应改或下放。

### 3. 独权第三版

- 必须触发本总控；
- 由本总控强制分流到 `部件命名具体优化`，完成至少两档命名对照；
- **先出命名对照表（含保护范围影响说明）→ 用户确认 → 再写第三版独权**；
- 若名称涉及方位/场景词，再并行触发 `方位与场景限定上位规范`；
- 若存在同类件消歧或术语跳变，追加指代清晰性 / 清楚性规范。

### 4. 每条从权

- 必须触发本总控；
- 任何新增部件名称，至少要完成：
  - 是否口语名；
  - 是否带非必要定语；
  - 是否与前文术语冲突；
- 新引入多个子部件时，须追加 `结构类权利要求撰写` 核对命名层级；
- 从权默认可在本条交付物中简记命名结论；**若该条命名会实质影响后续独权重写或保护范围理解，应升格为显式对照表请用户确认**。

## 五、最低交付物

### 独权（硬性）

必须先交付命名对照表（见第四节表格），并得到用户确认后，才写独权正文。表内每个关键部件最终应对应下列处置之一：

1. **保留原名**；
2. **优化为更中性的结构名/功能结构名**；
3. **保留原名但转“其中”定义**；
4. **保留原名但把某些定语下放到更下位从权或说明书**；
5. **调整命名层级/消歧方式**。

### 从权（默认）

使用本总控后，本轮至少简记：

- 分型（A～H，可多选）；
- 已调用具体 skill 清单；
- 采用名 + 理由。

## 六、典型示例

### 示例1：高强螺栓

- 分型：A
- 调用：`部件命名具体优化`
- 处理：优先比较 `高强螺栓 → 螺栓 → 连接螺栓`

### 示例2：左侧承压耳座

- 分型：A + C + F（若两侧都有）
- 调用：`部件命名具体优化` → `方位与场景限定上位规范` → 必要时 `权利要求指代与参照清晰性规范`
- 处理：判断是否优化为 `一侧承压耳座` 或 `第一承压耳座`

### 示例3：锚下块

- 分型：B
- 调用：`交底口语名改写为自明结构名规范` → 再回 `部件命名具体优化`
- 处理：先尝试改为承压板、支撑块、垫块等自明名称

### 示例4：球面调心垫板

- 分型：A + H
- 调用：`部件命名具体优化` + `功能性限定使用边界规范`
- 处理：先问“球面”是否结构必要、“调心”是否效果偷渡；比较 `球面调心垫板 → 球面垫板 → 垫板`

### 示例5：锚固箱包括底板、侧板……（从权展开）

- 分型：G
- 调用：`结构类权利要求撰写`（先总列子件名，再展开；子件名不得与锚固箱同级“还包括”）
- 可并行：`部件命名具体优化` 审查各子件名

### 示例6：本案特有缩略词

- 分型：D
- 调用：`自定义名词就地定义`

## 八、与具体 skill 的关系（收口）

- 本 skill = **总控 / 分流入口**
- **直接命名类**
  - `部件命名具体优化` = 材料、性能、效果、用途、场景定语的具体执行
  - `交底口语名改写为自明结构名规范` = 口语名、图纸习惯名
  - `方位与场景限定上位规范` = 方位、场景钉死语
  - `自定义名词就地定义` = 改不动仍不自明的名称
- **间接校正类**
  - `权利要求清楚性与逻辑一致性规范` = 同物多名 / 同名多物收口
  - `权利要求指代与参照清晰性规范` = 同类件消歧命名与参照清楚
  - `结构类权利要求撰写` = 母件/子件命名层级
  - `功能性限定使用边界规范` = 名称中的功能/效果偷渡边界
