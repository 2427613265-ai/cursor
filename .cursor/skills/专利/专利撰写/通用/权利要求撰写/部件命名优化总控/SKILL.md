# 部件命名优化总控（入口：只分型、只分流、只收对照表）

拟入权名称的**唯一入口**。本页只做三件事：分型、按固定顺序打开执行叶、收口对照表（或从权简记）。**不写**删定语、改口语、方位上位、就地定义的手法。

**硬性：** 撰写或质检只要处理的是「拟入权名称」，须先触发本 skill，再由本页分流。禁止直触 `部件命名具体优化`。禁止本页一次写完改名细则。

---

## 架构（三层，禁止倒灌）

```text
时机层（本页不复述细则）
  结构独权各版     → `结构类独权撰写`（每版正文前开本页）
  方法/算法独权    → `方法独权命名时机`（仅第二版开本页；第一版禁止打开）
  从权新名         → `从权撰写`（本条有拟入权名称则开本页）
  质检遇名称问题   → `权利要求书质检` / `单条权利要求审查`（按需开本页）
        ↓
入口层（本页）
  分型 A～E → 按「单名流水线」打开执行叶 → 独权交对照表 / 从权简记
        ↓
执行层（四叶；由本页打开；互不转发、不回跳本页）
  `交底口语名改写为自明结构名规范`
  `方位与场景限定上位规范`     ← 仅名称中的方位/场景词
  `部件命名具体优化`           ← 定语删留、两档对照、同名多物
  `自定义名词就地定义`         ← 改完仍不自明时怎么说清
```

**拟入权名称**包括：结构部件名，以及方法/算法案的数据对象、中间量、模块、步骤产物名。不论客体，只要是要写进权利要求当名称用的词，都走本页。

---

## 名称 vs 非名称（分流边界）

本页**只**管拟入权名称。下列情形**不是**命名入口，由调用方直挂对应规范，不要为了「经过命名总控」而绕进来：

| 情形 | 直挂 |
|------|------|
| 句中方位/场景限定（如「设置在左侧」），不是名称的一部分 | `方位与场景限定上位规范` |
| 布置/排列口语（如「对称错位」），不是部件/对象名 | `交底口语名改写为自明结构名规范` |
| 非名称的参数/集合/中间量含义说清（该词不当名称用，或名称已定只补含义） | `自定义名词就地定义` |
| 母件/子件铺陈层级、先总列后展开 | `结构类权利要求撰写` |
| 句尾「用于…」「从而…」功能性限定 | `功能性限定使用边界规范` |
| 「该/其」、第一/第二的指代清楚 | `权利要求指代与参照清晰性规范` |
| 同物多名/同名多物的**识别** | `权利要求清楚性与逻辑一致性规范`（改名仍回本页 E 型） |

---

## 明确不挂（曾误挂，现禁止）

本页**不**把下列 skill 当作命名执行叶：`结构类权利要求撰写`、`功能性限定使用边界规范`、`权利要求清楚性与逻辑一致性规范`、`权利要求指代与参照清晰性规范`。

名称里的功能色彩词（调心、限位、防腐）并入 **A 型**，由 `部件命名具体优化` 删留。同类件序数消歧在对照表备注「见指代规范」，本页不 Read 该全文。

## 执行叶（仅四个；命中才 Read）

| 叶 skill | 管什么 | 何时由本页打开 |
|----------|--------|----------------|
| `交底口语名改写为自明结构名规范` | 口语名/图纸习惯名/临时名能否改成自明结构名或功能结构名 | **B 型** |
| `方位与场景限定上位规范` | 名称中的左/右、上/下、上游/下游、内/外、防洪等是否应上位 | **C 型** |
| `部件命名具体优化` | 材料/性能/效果/用途定语是否必要；两档对照；同名多物改名 | **A 型、E 型**；以及 B/C 改完后的两档与定语审查 |
| `自定义名词就地定义` | 改完仍不自明：先前置白话，必要时「其中」兜底 | **D 型** |

叶 skill **禁止**回跳本页，**禁止**互相 Read。发现越界（如具体优化碰到口语名）：停，把该名标回对应分型，由本页打开下一叶。

---

## 分型（每个拟入权名称；可多选）

| 类型 | 典型表现 | 打开 |
|------|----------|------|
| **A** 名称夹带材料/性能/效果/用途定语（含功能色彩：调心、限位、防腐） | 高强螺栓、防腐护套、专用支架、调心垫板 | `部件命名具体优化` |
| **B** 交底口语名/图纸习惯名/临时名 | 小板、那个支撑件、侧支结构 | `交底口语名改写为自明结构名规范` |
| **C** 名称中带方位或场景钉死语 | 左侧板、下游支架、外侧孔 | `方位与场景限定上位规范` |
| **D** 改完仍不自明 | 本案特有词、自造词、必须保留的缩略词 | `自定义名词就地定义` |
| **E** 同名多物（不同件共用裸名） | 权4箱内「加劲板」、权7拉杆端又「加劲板」 | `部件命名具体优化` 规则五 |

同物多名、术语跳变：先由清楚性规范识别，再视情况开本页统一用名（多属 E 的反面，改名落地仍走具体优化）。

## 单名流水线（硬性顺序）

对每个名称，按序执行**已命中**的步骤（未命中则跳过）。禁止先删定语再改口语名。

```text
① B → 口语改写（得到候选名，或判定改不动）
② C → 方位上位（只处理名称中的方位/场景词）
③ A / E → 具体优化（定语删留 + 两档对照 + 同名多物）
     B/C 即使未标 A，改名后也要过本步做两档（独权关键名）
④ D → 就地定义（①～③之后仍不自明才打开）
```

独权第三版（仅结构案）：本页必须打开 `部件命名具体优化` 做满两档；有 C 则②与③都要走。

## 何时打开本页（只指向，不复述）

| 调用方 | 本页 |
|--------|------|
| `结构类独权撰写` | 第一/二/三版写正文前**必须**打开；确认对照表前不得写该版独权全文 |
| `方法独权命名时机` | **仅第二版**必须打开；第一版禁止打开（沿用交底原名）。时机细则以该页为准，本页不平行维护 |
| `从权撰写` | 本条出现拟入权名称则打开；默认可简记，名称会实质改变保护范围理解时升格对照表 |
| 权要质检 | 名称过窄、口语、定语、同名多物、两档缺失 → 打开本页再分流；禁止直触具体优化 |

## 对照表（独权硬性；从权默认简记）

**独权：** 写出该次触发所对应版本的独权正文前，必须先交表并得到用户确认/改选。标注「**待确认：独权部件命名表**」。

| 名称原名（交底/上一版） | 分型 | 第一档 | 第二档 | 推荐采用名 | 对保护范围的影响（一句话） | 用户选择 |
|-------------------------|------|--------|--------|------------|----------------------------|----------|
| … | A/B/… | … | … | … | 变宽/变窄/更清楚/需定义 | 待确认 |

规则：

1. 关键入权名称（独权顶层对象、核心中间量、核心部件）**逐一入表**，不得只口头说已优化。
2. 至少两档：结构案第三版硬性；结构案第一、二版与方法案第二版对**关键名**须两档，次要名可一档+保留说明。
3. 须有推荐采用名与范围影响。
4. 用户确认或改选后，才写**该版**独权正文；落笔须用确认名。

每个关键名最终处置须为下列之一：保留原名 / 改为更中性的结构名或功能结构名 / 短名+前置白话（必要时「其中」）/ 定语下放到从权或说明书 / 消歧改名。

**从权默认：** 简记分型、已打开的叶、采用名+理由。会卡住后续独权重写或保护范围理解时，升格为上表。

---

## 最低交付（本页被点名或被闸门打开时）

1. 本轮拟处理名称清单 + 分型（A～E，可多选）；
2. 将按流水线打开的叶 skill 名（未命中的不打开）；
3. 独权：对照表（待确认）；从权：简记或升格表。

禁止在本页展开叶 skill 的改名手法全文；禁止输出独权/从权权利要求正文（正文回调用方）。

---

## 示例（只示范分流，不代替叶内手法）

**高强螺栓** → A → 只开具体优化（比较 螺栓 / 连接螺栓）。

**左侧承压耳座** → A+C（两侧都有则备注指代）→ ②方位上位 → ③具体优化（一侧承压耳座 / 承压耳座）。

**锚下块** → B → ①口语改写（如承压板）→ ③具体优化做两档。

**信息盲区**（方法案中间量）→ B 或 D → 能改自明名则①；改不动则④前置白话说清后再当短名。

**两处加劲板** → E → ③规则五（锚固箱加劲板 / 拉杆加劲板）。
