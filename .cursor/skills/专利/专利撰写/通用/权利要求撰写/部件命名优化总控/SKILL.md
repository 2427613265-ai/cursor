# 部件命名优化总控（先分型，再调用具体 skill）

## 适用场景

- 写独权第一版、第二版、第三版之前；
- 写每一条从权之前；
- 审核权利要求中某个部件名是否要改名、上位、删定语或定义时。

**硬性规则：本 skill 是总控入口。独权/从权总控应先触发本 skill，再由本 skill 分流调用具体命名优化 skill。**

---

## 本 skill 管什么

本 skill **不直接替代所有具体命名规则**，而是先做三件事：

1. 识别当前部件名的问题类型；
2. 决定本轮要调用哪一个或哪几个具体 skill；
3. 给出本轮命名优化的最小交付要求。

---

## 一、先识别问题类型

对每个拟入权部件名，按下表分型：

| 类型 | 典型表现 | 下一步调用 |
|------|----------|------------|
| A. 名称夹带材料/性能/效果/用途/场景定语 | 高强螺栓、防腐护套、上游锚固箱、专用支架 | **`部件命名具体优化`** |
| B. 名称是交底口语名/图纸习惯名/临时名 | 小板、连接块、那个支撑件、侧支结构 | **`交底口语名改写为自明结构名规范`**；必要时再回 `部件命名优化` |
| C. 名称中带左/右、上/下、上游/下游、内/外等方位或场景词 | 左侧板、下游支架、外侧孔 | **`方位与场景限定上位规范`**；之后再回 `部件命名优化` |
| D. 名称改不动仍不自明 | 本案特有词、自造词、缩略词 | **`自定义名词就地定义`** |
| E. 名称前后一致性可疑 | 同物多名、同名多物、术语跳变 | **`权利要求清楚性与逻辑一致性规范`** |

---

## 二、调用顺序

默认按下列顺序分流：

1. **先过 `部件命名具体优化`**  
   处理高强、钢、防腐、调心、限位、专用等非必要定语；
2. 若判断名称本身不是自明结构名，转  
   **`交底口语名改写为自明结构名规范`**；
3. 若名称里含方位/场景词，转  
   **`方位与场景限定上位规范`**；
4. 若改名后仍不自明，转  
   **`自定义名词就地定义`**；
5. 落笔前再用  
   **`权利要求清楚性与逻辑一致性规范`**  
   检查是否同物多名、同名多物。

> 说明：并非每个名称都要五个 skill 全跑一遍，而是先由本总控判型，再按需分流。

---

## 三、独权与从权的最低要求

### 1. 独权第一版

- 必须触发本总控；
- 至少完成：是否存在明显口语名、明显非必要定语；
- 不要求本轮一定扩到最宽，但不能把明显错误名称直接带入。

### 2. 独权第二版

- 必须触发本总控；
- 至少完成：去掉与重新界定技术问题无关的材料/性能/效果/场景定语；
- 若当前名称仍夹带非必要缩限，应改或下放。

### 3. 独权第三版

- 必须触发本总控；
- 由本总控强制分流到 `部件命名具体优化`，完成至少两档命名对照；
- 若名称涉及方位/场景词，再并行触发 `方位与场景限定上位规范`。

### 4. 每条从权

- 必须触发本总控；
- 任何新增部件名称，至少要完成：
  - 是否口语名；
  - 是否带非必要定语；
  - 是否与前文术语冲突。

---

## 四、最低交付物

使用本总控后，本轮至少要得到下列结果之一：

1. **保留原名**（并说明为何原名已经自明、且无非必要定语）；
2. **优化为更中性的结构名/功能结构名**；
3. **保留原名但转“其中”定义**；
4. **保留原名但把某些定语下放到更下位从权或说明书**。

---

## 五、典型示例

### 示例1：高强螺栓

- 分型: A（名称夹带性能词）
- 调用：`部件命名具体优化`
- 处理：优先比较 `高强螺栓 → 螺栓 → 连接螺栓`

### 示例2：左侧承压耳座

- 分型：A + C
- 调用：先 `部件命名优化`，再 `方位与场景限定上位规范`
- 处理：判断是否优化为 `一侧承压耳座` 或 `第一承压耳座`

### 示例3：锚下块

- 分型：B
- 调用：`交底口语名改写为自明结构名规范`
- 处理：先尝试改为承压板、支撑块、垫块等自明名称

### 示例4：某本案特有缩略词

- 分型：D
- 调用：`自定义名词就地定义`

- [ ] 当前这一版独权 / 这一条从权，是否已先触发本总控 skill
- [ ] 当前部件名称属于哪一类问题，是否已正确分流
- [ ] 是否已调用相应具体 skill，而非只在口头上说“注意命名”
- [ ] 是否已得到“保留 / 改名 / 定义 / 下放”中的一种明确处置结果

---

## 七、与具体 skill 的关系

- 本 skill = **总控 / 分流入口**
- `部件命名具体优化` = **处理材料、性能、效果、用途、场景定语的具体执行 skill**
- `交底口语名改写为自明结构名规范` = **处理口语名、图纸习惯名**
- `方位与场景限定上位规范` = **处理方位、场景钉死语**
- `自定义名词就地定义` = **处理改不动仍不自明的名称**
- `权利要求清楚性与逻辑一致性规范` = **做一致性收口**
