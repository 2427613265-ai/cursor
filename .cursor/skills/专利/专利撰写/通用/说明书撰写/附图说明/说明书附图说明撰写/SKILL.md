# 说明书"附图说明"部分撰写规范（所有案件类型通用）

## 核心规则：只能依据交底书已有的附图撰写

撰写"附图说明"部分时，**必须以交底书里实际存在的附图为基础**——撰写人通常不具备绘图能力，附图是由发明人提供的，不能凭空"发明"一张交底书里不存在的图。

具体要求：
1. 先核对交底书里实际有几张图、每张图分别画的是什么内容，附图说明部分严格按照这些已有的图来写，图的数量、顺序、每张图对应的内容都要跟交底书保持一致。
2. **不能凭空新增一张交底书里没有的图**——即使权利要求书后续经过修改、新增了交底书没有覆盖的技术特征（比如新增了某个从权对应的具体结构），也不能自己想象着编一张新图出来交差，充当"已有附图"来写。
3. 附图标记说明部分列出的标号，原则上应以交底书原图上实际标注的标号为基础，不能虚构一个交底书里不存在的对象标号；但**图号是否原样保留，要先服从专利撰写规则**。如果交底原图的编号体系本身已经符合专利撰写要求（无重号、无明显冲突、便于全文统一），可以直接沿用；如果原图存在重号、冲突或明显不利于正式申请文件统一管理，则应在**不改变图意和部件对应关系**的前提下重新编号，并在说明/提醒中注明是对交底原图标号做了规范化整理。
4. **附图标记说明的部件名称，默认应优先与当前权利要求书（尤其是独权和对应从权）已经采用的术语口径保持一致**。也就是说：图号先按专利撰写规则处理，名称文字应尽量同步到当前权利要求的优化后命名；只有当改名会明显改变原图所指对象的技术含义、或当前权利要求术语与原图对象并不能一一对应时，才保留交底原称并在说明/提醒中注明。

### 附图标记说明的“图号合规、名称可新”原则

附图说明撰写时，容易出现三种错误：一是把交底原图中本就冲突的编号原样搬进正式申请文件，导致不合规；二是图号虽然处理了，但没有整理成一套统一、不重号、便于全文管理的标记体系；三是附图标记说明中的名称文字仍机械照抄交底书旧叫法，导致与已经优化过的权利要求术语脱节。

正确处理原则是：

1. **图号先服从专利撰写规则**——正式申请稿应优先整理为一套**统一、不重号、便于全文管理**的附图标记体系；若交底原图编号本身无冲突、且已满足这一要求，则可保留原样；若有重号、冲突或明显不利于统一管理，则应规范化重编；
2. **同一对象跨图出现时，应尽量使用同一标号；不同对象不得共用同一标号**；
3. **名称文字尽量同步新术语**——若权利要求已把“老船闸原闸室”优化为“缓冲池”、把“LED诱鱼灯组”优化为“诱鱼灯组”，附图标记说明应优先采用优化后的名称；
4. **同步时不能改错对象**——例如当前权利要求把部件范围上位了，需确认该上位名仍能准确覆盖原图对应对象，不能为了统一术语而把原图中的具体部件硬换成不对应的新名；
5. **若图号做了规范化调整**，应在说明/提醒中交代该调整是为满足正式申请文件的编号规则，并建议后续与发明人核对更新后的附图版本。

## 核心发明点缺少附图时的处理方式

如果权利要求书（尤其是独权和排在前面的关键从权）里的核心技术特征，在交底书现有的附图里**没有对应的图能够体现**，正确的处理方式是：

1. 先按交底书现有的附图，把"附图说明"部分能写的内容写完；
2. **写完之后，专门用一段话提醒撰写人：哪些核心发明点目前没有对应的附图，需要联系发明人补充绘制新的附图**——列清楚具体缺的是哪个技术特征、建议补充什么类型的图（结构示意图/局部放大图/展开图等），方便撰写人去跟发明人沟通要图。

**不允许**跳过这一步提醒，也不允许自己代替发明人"创作"一张凭空想象的新图混在附图说明里当成已有的图来写——这一点是本skill最容易被违反、也最需要注意的地方：即使能"想象"出一张合理的图应该长什么样，也不代表可以自己编出来当成交底书已有的附图。

## 标点符号和排版格式

"附图说明"部分的标点和排版要按以下模版：

- 每张图的描述**单独成一段**（段与段之间空一行）；每段末尾用**分号"；"**，只有**最后一张图**的那一段以**句号"。"**结尾（图与图之间虽然分段、空行排版，但标点上仍是"用分号串起来的同一句话"，不是各自独立的完整句子）。
- 附图标记说明**单独另起一段**（与最后一张图的描述之间也空一行），开头直接写"**附图标记说明：**"（用中文冒号，不要另起markdown标题层级），紧接着用"1、XX；2、XX；3、XX；……"的格式，全部标号写在同一段里，用"；"分隔，最后一个标号后用句号"。"收尾。

模版示例（图与图之间、最后一张图与附图标记说明之间都要空一行）：

```
图1为本实用新型喷雾降尘装置的整体结构示意图；

图2为本实用新型的外罩与导喷套连接处截断局部结构示意图；

图3为本实用新型喷雾降尘装置的后视结构示意图；

图4为本实用新型的风罩与加固架连接处截断局部结构示意图。

附图标记说明：1、外罩；2、风叶；3、环管；4、外喷管；5、外雾化孔；6、喷雾管；7、喷孔；8、侧管；9、雾化喷头；10、导喷套；11、连接管；12、阀门；13、螺纹管；14、风罩；15、加固架；16、过滤网；17、电机。
```

## 方法类发明：第一张附图必须是方法流程图

如果本专利是方法类发明（权利要求以步骤S1、S2、S3……的形式撰写），**附图说明里的图1必须是方法流程图**，用于展示整个方法的步骤顺序和逻辑关系，之后再排列其他的结构示意图/局部放大图等。

如果交底书没有提供流程图（比如发明人只给了结构图，没给流程图），这属于"核心内容缺少附图"的情形，按上面的规则单独提醒撰写人去问发明人要一张流程图，不能自己画一个流程图逻辑出来充当"交底书已有的图"。

## 检查清单

- [ ] 附图说明里列出的每一张图，是否都能在交底书里找到对应的原图？有没有凭空编造的图？
- [ ] 图的数量、顺序，是否与交底书一致？
- [ ] 方法类发明，图1是否为方法流程图？如果交底书没提供，是否已经在提醒清单里列出？
- [ ] 权利要求书里的核心技术特征，有没有遗漏对应附图的情况？是否已经在撰写完毕后单独列出提醒？
- [ ] 附图标记说明部分列出的标号，是否都能追溯到交底书原图中的对应对象？若做了重编，是否仅为满足正式申请文件编号规则，且未改变图意和对象对应关系？
- [ ] 正式申请稿中的附图标记体系，是否已经整理为统一、不重号，并尽量保证同一对象跨图同号？
- [ ] 在不改变图号和图意的前提下，附图标记说明中的部件名称是否已经尽量同步为当前权利要求书采用的术语口径？
- [ ] 标点和排版是否符合模版：每张图单独成段、段间空一行，段末用"；"、只有最后一张图用"。"收尾；附图标记说明单独另起一段（与上文空一行）以"附图标记说明："开头，标号之间用"；"分隔、整段只在最后用一个句号？

## 应用范围

本规则适用于撰写或审核任意类型专利说明书"附图说明"部分。撰写时直接遵循本 skill；正式质检时由 `说明书质检总控` 挂接本 skill，按其检查清单核对。与 `说明书具体实施方式撰写` 配合使用：具体实施方式部分引用的附图标记，同样需要限定在交底书已有附图（或后续发明人补充提供的附图）范围内，不能引用一个不存在的图。
