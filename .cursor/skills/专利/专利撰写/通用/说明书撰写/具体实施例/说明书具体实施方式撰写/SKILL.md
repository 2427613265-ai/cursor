# 说明书"具体实施方式"部分撰写规范（所有案件类型通用）

## 核心结构：先复述，再展开

撰写具体实施方式时，针对每一条权利要求（或方法权利要求里的每一个步骤），按以下两段展开：

### 第一段：复述权利要求的技术方案（必须原样复述，不得改动）

**每一条权利要求的具体实施例，第一段都必须原样复述该权利要求的技术方案，不得改动、删减、增补或调整其技术特征的文字表述**——照抄权利要求书里的文字，**保留"所述"这种严谨、结构化的措辞风格**，作为这部分实施例的开头句。这一段是实施例与权利要求逐字对应的落脚点，不允许在此段做任何"顺句子""改措辞"的加工，任何解释、补充、附图标记都留到第二段展开时再写。

**复述时允许删除的形式用语（删除不算改动技术特征）：**

1. **"其特征在于"**：权利要求的形式用语（用于划分前序部分与特征部分），不是技术特征本身，复述到说明书时应当去掉，让句子直接连成通顺的技术叙述。
2. **从属权利要求的引用套话"根据权利要求X所述的（主题名称），"**：这是权利要求书里的依附格式用语，不是技术方案本身；**具体实施例中不得保留**（不要写成"根据权利要求5所述的具有可移动钻探设备的勘测平台，……"）。删除该引用套话后，用"**进一步地，**"直接接上该从权特征部分的原文（"所述……"起的技术特征文字仍须原样照抄）。

除此之外的技术方案文字仍要原样照抄，不得改动、删减、增补技术特征措辞。

- 独立权利要求段首可加固定引导语，例如"在本实施例中，"或"在本实施例中，如图X（至图Y）所示，"，随后紧跟复述的技术方案文字；引导语只是框架，不改变被复述的技术特征内容本身。
- 方法类专利：常用"S+数字、XXX"的步骤编号格式，直接原样复述该步骤对应权利要求的文字。
- 结构类专利（独立权利要求）：复述"一种XXX，包括XXX；所述XXX设置在……"这种结构表述（去掉"其特征在于"），不需要编号。
- 从属权利要求：第一段写作"**进一步地，**"+该从权特征部分原文（去掉"根据权利要求X所述的……"和"其特征在于"），**不得**在实施例里保留"根据权利要求X所述的……"引用套话；如需结合附图，写成"进一步地，如图X所示，……"。

### 第二段：用"具体而言，"过渡，按序展开

第二段固定用过渡语"**具体而言，**"引出详细说明（"在本实施例中，""进一步地，""如图X所示，"等属于第一段复述的段首引导语，不要拿到这里当展开段的过渡语混用）。展开遵守三条：

1. **按序覆盖，相邻可合段。** 技术特征按复述里出现的先后顺序写到，不漏项。位置上前后相接的特征写在同一段里，顺着配合关系往下讲。不必一个分句单独成段。
2. **配合只写这一下。** 结构展开里写该特征与相邻部件如何配合、运行中在这一处发生什么。用正面语句。端到端时序、多工况分支留给 `具体实施方式工作流程与原理撰写`（5E）。**不要**用假设否定来反证，即不要写「若缺少/若不设置/若不这样/若只有（另一结构）……则会……」。
3. **怎么实施写在同一处。** 结合附图标记写真实的结构、连接和操作，与上面的配合写在一起。

**不能遗漏**复述部分提到的任何一个技术特征，也**不能在展开时夹带**复述部分没有出现过的全新技术特征。优选细节必须另起，引导语用「在一个可选的实施方式中」「作为一种改进」「在另一实施例中」。「**进一步地**」只用于从权复述段的段首，不用于未入权方案。

**该条方案的有益效果（必须写）：** 效果写在「具体而言」同一段里，不另起段。先看这一条里哪些结构改变了水或汽的路径。

- **改变路径的关键结构**（如缓冲用的腔体、排气口、拦在来流上的格栅、改变下落位置的凹面、进水管出口与排气口的上下关系）：在同一段里用两到三句写清介质接着往哪走、速度在何处变化、汽液在何处分开。写到这一步机制。只写「分成多股」「呈漏斗」这种同义句，不算写够。
- **个数、对称、单纯的尺寸比较**：一句，只写它和相邻结构的直接对应。由这些特征推不出液面停在哪里、腔内压力是否均匀、排气量如何分配的，不要补写。
- 全篇不要每条都用「这样，」起句，不要写「本实施例的有益效果在于：」，也不要用「显著、有效、大大、进一步提高」。
- 独权已经写过的效果，从权不重复。端到端的操作顺序仍放在 5E。发明内容里的有益效果段仍然保留，实施例不整段照抄。

**装配一句例外：** 权利要求未写与外部的装配关系时，权1的「具体而言」段末可以有一句装配总述，写法见 `具体实施方式补充整体装配方式`。这一句不写入复述段。装配细部放到 5E 之前的详述段。

### 两段的语言风格差异

- 第一段（复述）：保持跟权利要求书一致的严谨书面语，不需要额外解释。
- 第二段（"具体而言"展开）：按部件怎么接、介质或步骤怎么走来写。句子长度适中。背景技术里的缺陷转折（「然而」以及对现有技术的批评）不写入本段。

## 从属权利要求的实施例写法

独立权利要求之外，**每一条从属权利要求也要各自撰写对应的实施例**，同样遵循"复述+展开"的两段结构，但展开部分的重点不同：

1. **第一段**：写成"**进一步地，**"+该从权特征部分原文；**删除**"根据权利要求X所述的（主题名称），"以及"其特征在于"，除此之外不得改动技术特征文字。
2. **第二段"具体而言，"**：**只展开该从权相对于其引用的基础权利要求新增或进一步限定的技术特征**，不要把基础权利要求里已经详细说明过的共同特征重新展开一遍；确需带到基础特征时，用"如前所述""如上所述"一句带过即可。改变水或汽路径的关键结构，在同一段内写清介质接着怎么走；个数、对称和单纯尺寸比较只写直接对应。效果不另起段。不要用「本实施例的有益效果在于：」。
3. 若从权限定的是**数值范围、比例、数量关系、角度**等参数，展开时应说明该范围与相关结构或工况的对应关系，以及在该范围内取得的技术效果。取值依据用正面关系写清。不要写「低于下限会怎样」「高于上限会怎样」「若超出该范围则……」。
4. 组织方式：通常以"实施例1对应独立权利要求"为主线，各从属权利要求可逐条对应追加段落；每条从权实施例第一段各自用"进一步地，"起句即可，不必在实施例中重复权利要求编号依附关系。

## 附图引用与附图标记规范

具体实施方式要结合附图撰写，引用附图和附图标记时遵循以下写法：

- **何时写"如图所示"**：描述整体方案或某条实施例开头时，用"如图X所示"或"如图X至图Y所示"（独权放在第一段段首引导语中，如"在本实施例中，如图1至图3所示，……"；从权写成"进一步地，如图X所示，……"）；单独描述某个局部结构时，就近标注该结构所在的图，如"如图3所示，所述导流齿9设置于所述环形外沿4的外侧面"。
- **附图标记格式**：统一采用"**部件名称+标号**"的连写形式（如"环形外沿4""导流齿9"），**不要写成"4、环形外沿"这种附图标记说明里的列举格式**。附图标记只出现在第二段展开中；第一段是原样复述的权利要求文字，权利要求本身不带标号，故第一段不加附图标记。
- **一致性**：实施例中用到的每一个附图标记，其编号和名称都必须与 `说明书附图说明撰写` 里的"附图标记说明"完全一致，不得自创、错位或引用一个附图说明里不存在的标号。权利要求里有、图上可见、但附图说明未列标号的部件，展开段只写名称，不新编标号。

## 与"有益效果"的分工边界

发明内容和具体实施方式都要写有益效果，各写一次，作用不同：

- 发明内容：用「与现有技术相比，本实用新型的有益效果在于：」归纳独权方案的效果，见 `说明书有益效果撰写`。
- 具体实施方式：效果写在该条「具体而言」的同一段里，只写结构直接能够看出的路径或断面变化。从权不另起效果段。不补写推不出的液面、压力分布或排气量，不另起「本实施例的有益效果在于：」，也不整段照抄发明内容。
- 端到端工作原理仍放在 5E。5E 写怎么运行，实施例的有益效果段写运行之后得到什么。

## 参考示范一：方法类（用户提供的隧道施工案例）

> S2、当所述地下水状态满足预设的安全指标时，对所述主洞隧道的围岩进行帷幕注浆；开挖所述主洞隧道，并施作衬砌；并在所述主洞隧道内施作中心水沟；其中，所述主洞隧道沿所述泄水洞平行施作，且所述主洞隧道的底面标高高于所述泄水洞的底面标高；
>
> 具体而言，在所述泄水洞3持续进行泄排水与超前探测的过程中，需对主洞隧道1预掘进区段的地下水状态进行多维度客观评估，判断其是否已下降并稳定至预设的安全指标；只有在确认满足所述安全指标后，方可启动主洞隧道1的后续施工作业，从而避免在地下水压力仍处于高位时贸然施工而引发涌水、突泥等灾害性事故。
>
> 在确认满足所述安全指标后，首先针对主洞隧道1待开挖段的围岩实施帷幕注浆，通过预先注浆固结的方式在主洞隧道1开挖轮廓外围构建起加固阻水防线，避免在后续开挖过程中围岩因卸荷或渗水作用而发生失稳破坏。
>
> 待帷幕注浆固结完成后，沿所述泄水洞3的走向平行开挖施作主洞隧道1，且在施作过程中，通过测量放样控制使主洞隧道1的底面标高始终高于泄水洞3的底面标高，从而在两者之间构建起稳定的高差关系，为后续横向排水管网提供重力自流的高差基础，无需依赖机械抽排即可实现渗水的顺畅导排。
>
> 在主洞隧道1开挖成型后，随即在其内部施作衬砌，以对开挖揭示的围岩提供支护并阻隔残余渗水，保障主洞隧道1的结构安全与长期运营稳定。最后，在主洞隧道1底部的纵向中心线上施作中心水沟2，中心水沟2采用现浇混凝土结构沿主洞隧道1全线连续设置，用于收集汇聚经衬砌渗入主洞隧道1内部的残余渗漏水，构建起主洞隧道1内部渗漏水的初始汇流通道。

对照分析：第一段复述了S2步骤的四个技术特征（①判断地下水安全指标、②帷幕注浆、③平行开挖且底面标高高于泄水洞、④施作衬砌和中心水沟）；第二段严格按①②③④的顺序逐一展开，每一点都先写该步骤在方案中的作用，再说具体怎么做，且引入了复述部分没有点名的附图标记（1、2、3）和补充细节（现浇混凝土结构、全线连续设置），这些细节是对复述内容的具体化，不是引入新的技术特征。示范原文里的「避免……」只是在说明该步骤本身的作用，不得据此写成「若缺少该特征则会……」。

## 参考示范二：结构类（本项目喷雾降尘装置独权示例）

> 一种喷雾降尘装置，包括外罩、风叶和降尘组件；所述风叶安装在所述外罩的内壁，能够转动以产生轴向气流；所述降尘组件设置在所述风叶的一侧，所述降尘组件包括环管和多个喷雾管；所述环管同轴设置在所述风叶的出风侧；多个所述喷雾管呈放射状固定连通于所述环管，每个所述喷雾管的管壁上开设有多个喷孔；所述喷孔的开口方向与所述风叶所在平面之间形成有夹角。
>
> 具体而言，外罩1的内壁安装有风叶2，风叶2由电机驱动转动，转动过程中沿转轴方向产生轴向气流，用于将后续雾化水体向外罩1前方及外部推送。风叶2的一侧设有降尘组件，降尘组件包括环管3和多个喷雾管4：环管3同轴设置在风叶2的出风侧，用于承接外部输入的加压水源，并向各喷雾管4分配水流；多个喷雾管4呈放射状固定连通于环管3，每个喷雾管4的管壁上开设有多个喷孔5，用于将环管3内的水流雾化喷出。喷孔5的开口方向与风叶2所在平面之间形成有夹角，使喷孔5喷出的雾化水体能够获得风叶2产生的轴向气流的风压推动，在自身水压的基础上叠加获得额外的推进力，从而增大雾化水体的有效喷射距离，扩大对设备前方及周边粉尘扩散区域的覆盖能力。

对照分析：第一段直接复述权利要求原文；第二段把相邻部件写在同一段里，按"风叶→降尘组件（环管→喷雾管→喷孔）→喷孔夹角"的顺序往下讲。每个部件只写它和相邻件的配合（风叶产生轴向气流用于推送水雾、环管分配水流、喷雾管雾化喷出、夹角使雾化水体获得风压推动），并补上附图标记（1～5）。这是「相邻可合段、作用只写这一下」的结构类写法。

## 参考示范三：从属权利要求（删除引用套话）

权利要求原文：

> 根据权利要求1所述的喷雾降尘装置，其特征在于，所述喷孔的开口方向与所述风叶所在平面之间的夹角为30°至60°。

实施例第一段（复述）应写成：

> 进一步地，所述喷孔的开口方向与所述风叶所在平面之间的夹角为30°至60°。

**不要**写成："根据权利要求1所述的喷雾降尘装置，所述喷孔的开口方向与所述风叶所在平面之间的夹角为30°至60°。"（引用套话已删，只保留特征部分原文，前接"进一步地，"）。

## 检查清单

- [ ] 每一条权利要求的实施例，第一段是否原样复述了对应权利要求（或步骤）的技术方案，除允许删除的形式用语外没有改动、删减技术特征措辞，也没有遗漏任何技术特征？
- [ ] 第一段复述是否已删除"其特征在于"？从权是否已删除"根据权利要求X所述的……"引用套话，并改用"进一步地，"衔接特征部分（实施例中不得出现"根据权利要求X所述的……"）？
- [ ] 第二段"具体而言"之后的展开，是否按复述顺序覆盖了每一个技术特征？相邻特征是否合段叙述？
- [ ] 结构展开里，配合是否只写到与相邻部件的那一下？端到端时序是否留给 5E？
- [ ] 改变水或汽路径的关键结构，是否在同一段内写清了介质接着怎么走、速度或汽液在何处变化？个数、对称和单纯尺寸比较是否只写了直接对应，没有补写液面、压力场或排气量？效果有没有另起一段？
- [ ] 从属权利要求的实施例，第二段是否只展开了该从权新增/限定的特征，而没有把基础权利要求已详细说明过的共同特征重复展开？
- [ ] 数值范围、比例、数量、角度类从权，是否用该范围与结构或工况的正面对应关系说明了取值依据和范围内的技术效果？有没有写成「低于下限/高于上限/若超出该范围则会……」？
- [ ] 展开段有没有「若缺少/若不设置/若不这样/若只有……则会……」这类假设否定？
- [ ] 有没有在展开时夹带复述部分没有的新技术特征？未入权细节是否另起，且引导语为「在一个可选的实施方式中/作为一种改进/在另一实施例中」？「进一步地」是否只出现在从权复述段段首？
- [ ] 权1展开段末的装配总述是否至多一句，且没有写入复述段？
- [ ] 图上可见、附图说明未列标号的部件，展开段是否只写名称、没有新编标号？
- [ ] 是否在合适位置使用了"如图X所示"/"如图X至图Y所示"？附图标记是否统一为"部件名称+标号"（如"环形外沿4"）的连写格式，且编号、名称与附图标记说明完全一致？
- [ ] 过渡语是否规范：独权第一段段首用"在本实施例中，（如图X所示，）"，从权第一段用"进一步地，"起句（不得保留"根据权利要求X所述的……"），第二段展开固定用"具体而言，"，三者没有混用？
- [ ] 第二段是否按部件怎么接、介质或步骤怎么走来写，句子是否长度适中？背景技术的缺陷转折有没有写进本段？
- [ ] 实施例中的有益效果是否与结构写在同一段，并且只写直接能看出的那一步？有没有使用「本实施例的有益效果在于：」「显著」「有效」「大大」？

## 应用范围

本规则适用于撰写或审核任意类型专利说明书"具体实施方式"部分。撰写时直接遵循本 skill；正式质检时由 `说明书质检总控` 挂接本 skill，按其检查清单核对。与 `质检总控` → `权利要求质检总控` → `权利要求书质检` 配合：建议先确认权利要求书逐条定稿，再按本skill逐条撰写对应的具体实施方式，保证说明书和权利要求书的技术特征、措辞完全对应。

若某条权利要求涉及新定义名词，按 `具体实施方式名词先释义后展开` 把释义放在复述段之后、「具体而言」之前。本 skill 负责实施例怎么复述、怎么展开。
