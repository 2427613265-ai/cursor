# 方法独权成组下放

方法/算法案在第二版→第三版（及递交变劣）剔特征时的**下放编排**细则。由总控挂接。

## 规则

1. **按独权主步骤成组**：从独权删/概括掉的关联路径（工具、参数、细分支、实施例配套）按其所附属的 `S1…Sn`（见 `方法步骤编号规范`）分组，每组对应次级问题或效果，供从权与说明书。  
2. **一组一事**：同一从权（或从权簇）尽量只承接同一主步上的相关细化，避免把无关路径捆成一条。  
3. **禁止抽空骨架**：当前版本最小区别骨架（不变量）**不得**整组藏进从权；若误放，须回独权。  
4. **变劣回退**：递交独权相对定稿少掉的特征，同样按步成组写入从权（或「核心组 + 待写清单」）。  
5. **交付物**：至少给出「步骤号 → 下放特征摘要 → 建议从权主题」对照；完整从权文句可交 `从权撰写`。
