# 方法类·权利要求撰写

## 分工

| skill | 管什么 |
|-------|--------|
| `方法类独权撰写` | 两版策略与 plan（经 `独权撰写` 分流进入）：核心区别一句话+关键创新点→组成最小集→第一版→审定技术主题并重新核定→第二版；第1步细则见 `核心区别技术特征确定`；第2/3步细则见 `最小技术特征集与第一版独权`；第4步细则见 `审定技术主题与重新核定技术问题`；第5步细则见 `第二版独权校核` |
| **`方法类权利要求具体撰写规则总控`** | 独权**正文**横切入口：只挂通用横切 + 结构侧可复用；**不含**方法专有细则 |

写某一版独权正文前，经 **`方法类权利要求具体撰写规则总控`** 按特征 Read 触发的横切；不要在策略 skill 里展开横切全文。对象名命名经 `部件命名优化总控`（仅第二版，时机见 `方法类独权撰写`）。

原方法专有叶及具体规则（`方法类权利要求专有细则`、旧六叶等）**已删除**；点名曾用名时改走本总控横切 + `方法类独权撰写` 策略。

## 通用横切（示例）

- `条件判断语句规范`
- `预设值与参数来源检查`
- `权利要求主谓宾结构规范`
- `自定义名词就地定义`

**禁止**再把方法案套进 `结构类独权撰写` / `结构类权利要求撰写` 的「先总列后展开」。
