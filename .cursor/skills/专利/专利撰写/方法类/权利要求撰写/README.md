# 方法类·权利要求撰写

## 分工

| skill | 管什么 |
|-------|--------|
| `方法类独权撰写` | 三版策略与 plan（经 `独权撰写` 分流进入） |
| **`方法类权利要求具体撰写规则总控`** | 独权**正文**具体写法入口：挂接方法专有叶 + 通用横切 + 结构侧可复用 |

写某一版独权正文前，经 **`方法类权利要求具体撰写规则总控`** 按表 Read 细则；不要在策略 skill 里展开叶规则全文。

## 方法专有叶（由总控挂接；文件随后续分步补齐）

- `按产物拆步与I/O咬合`
- `方法步骤编号规范`
- `路径与不变量二分`
- `调控闭环最低链`
- `方法独权成组下放`
- `方法独权命名时机`

## 通用横切（示例）

- `条件判断语句规范`
- `预设值与参数来源检查`
- `权利要求主谓宾结构规范`
- `自定义名词就地定义`

**禁止**再把方法案套进 `结构类独权撰写` / `结构类权利要求撰写` 的「先总列后展开」。
