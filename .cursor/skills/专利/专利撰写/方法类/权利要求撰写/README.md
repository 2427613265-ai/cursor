# 方法类·权利要求撰写

本目录存放**方法类（含算法流程型）类型专属**权利要求规范，与结构类「先总列后展开」对称。

横切规则（条件判断、预设值来源、其中定义等）仍在 `专利/专利撰写/通用/`；本分支**只保留**方法铺陈与扩围硬规则，避免与通用平行空壳。

## 已有 skill

| skill | 用途 | 典型触发 |
|-------|------|----------|
| `方法类权利要求撰写` | 分步 I/O、步内用尽与步间咬合、路径/不变量三问与可实施下限、扩围；由 `独权撰写` 挂接 | 「写方法独权」「步骤衔接不紧」「中间算路径还是不变量」 |

## 与通用横切规范的分工

| 需求 | 归属 |
|------|------|
| 三版策略 / 重新界定问题 / 递交变劣 | `独权撰写`（策略层） |
| 条件判断句式 | `条件判断语句规范` |
| 预设值与参数来源 | `预设值与参数来源检查` |
| 自定义名词就地定义、主谓宾、指代、清楚性 | 通用·权利要求撰写下各规范 |
| 是否非必要特征 | `独立权利要求必要技术特征检查`（方法案并行本 skill） |

新增类型专属硬规则时按 `CONVENTIONS.md`，并在 `独权撰写` 挂接。
