# 方法类·权利要求撰写

本分支存放**方法类（含算法流程型）权利要求**的类型铺陈与扩围规范，与结构类「先总列部件、后展开」对称，但不适用结构铺陈规则。

## 已有 skill

| skill | 用途 | 典型触发 |
|-------|------|----------|
| `方法类权利要求撰写` | 方法独权 I/O 流水线、不变量/实现层分离、去钉死扩围；由 `独权撰写` 在方法类铺陈及第二/三版加码挂接 | 「写方法独权」「方法权扩围」「步骤是不是写太细」 |

## 与通用横切规范的分工

| 需求 | 归属 |
|------|------|
| 三版策略 / 重新界定问题 / 递交变劣 | `独权撰写`（策略层） |
| 条件判断句式 | `条件判断语句规范` |
| 预设值与参数来源 | `预设值与参数来源检查` |
| 自定义名词就地定义、主谓宾、指代、清楚性 | 通用·权利要求撰写下各规范 |
| 是否非必要特征 | `独立权利要求必要技术特征检查`（方法案并行本分支 skill） |

新增相关 skill 时更新本 README。
