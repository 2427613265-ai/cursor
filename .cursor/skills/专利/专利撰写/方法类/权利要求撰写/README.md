# 方法类·权利要求撰写

## 分工

| skill | 管什么 |
|-------|--------|
| `方法类独权撰写` | 两版策略与 plan（经 `独权撰写` 分流进入）：核心区别一句话+关键创新点→组成最小集→第一版→审定技术主题并重新核定→第二版；第1步细则见 `核心区别技术特征确定`；第2/3步细则见 `最小技术特征集与第一版独权`；第4步细则见 `审定技术主题与重新核定技术问题`；第5步细则见 `第二版独权校核` |
| **`方法类权利要求具体撰写规则总控`** | 独权**正文**具体写法入口：本页写方法专有规则（拆步与I/O、步骤编号、路径/不变量、闭环最低链、成组下放、命名时机）+ 通用横切 + 结构侧可复用 |

写某一版独权正文前，经 **`方法类权利要求具体撰写规则总控`** 必读该页「分节何时用」及触发的横切；不要在策略 skill 里展开专有细则全文。对象名命名经 `部件命名优化总控`（仅第二版）。

点名曾用名（`方法类权利要求专有细则`、`按产物拆步与IO咬合`、`方法步骤编号规范`、`路径与不变量二分`、`调控闭环最低链`、`方法独权成组下放`、`方法独权命名时机`）→ 直读 `方法类权利要求具体撰写规则总控` 对应节。

## 通用横切（示例）

- `条件判断语句规范`
- `预设值与参数来源检查`
- `权利要求主谓宾结构规范`
- `自定义名词就地定义`

**禁止**再把方法案套进 `结构类独权撰写` / `结构类权利要求撰写` 的「先总列后展开」。
