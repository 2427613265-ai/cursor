# 方法类·权利要求撰写

## 分工

| skill | 管什么 |
|-------|--------|
| `方法类独权撰写` | 两版策略与 plan（经 `独权撰写` 分流进入）：核心区别一句话+关键创新点→组成最小集（方案完整、不锚定先前问题）→据此写第一版→根据该独权重新核定→第二版；第1步细则见 `核心区别技术特征确定` |
| **`方法类权利要求具体撰写规则总控`** | 独权**正文**具体写法入口：挂接 `方法类权利要求专有细则` + 通用横切 + 结构侧可复用 |
| **`方法类权利要求专有细则`** | 方法专有规则全集：拆步与I/O、步骤编号、路径/不变量、闭环最低链、成组下放、命名时机（原六叶已收束） |

写某一版独权正文前，经 **`方法类权利要求具体撰写规则总控`** 必读 `方法类权利要求专有细则`（按该页「分节何时用」）及触发的横切；不要在策略 skill 里展开专有细则全文。对象名命名经 `部件命名优化总控`（仅第二版）。

点名旧叶名（`按产物拆步与IO咬合`、`方法步骤编号规范`、`路径与不变量二分`、`调控闭环最低链`、`方法独权成组下放`、`方法独权命名时机`）→ 直读 `方法类权利要求专有细则` 对应节。

## 通用横切（示例）

- `条件判断语句规范`
- `预设值与参数来源检查`
- `权利要求主谓宾结构规范`
- `自定义名词就地定义`

**禁止**再把方法案套进 `结构类独权撰写` / `结构类权利要求撰写` 的「先总列后展开」。
