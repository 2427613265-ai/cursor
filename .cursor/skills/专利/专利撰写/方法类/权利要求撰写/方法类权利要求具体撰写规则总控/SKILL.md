# 方法类权利要求具体撰写规则总控

方法/算法案**独权正文具体写法**的二级入口。只挂接、编排细则；**不**产出三版独权全文、**不**重新界定/再上位技术问题、**不**跑递交变劣。

三版策略与 plan 仍在 `方法类独权撰写`；写某一版**正文**时经本总控按需 Read 下表 skill。

## 适用与边界

- **入口：** `方法类独权撰写` 第2/4/6步（及变劣写递交稿时）写正文前；或用户点名本总控/某条方法细则。
- **禁止：** 充当 `独权撰写` / `方法类独权撰写`；套用 `结构类权利要求撰写`「先总列后展开」。
- **硬性：** 本页不粘贴叶 skill 全文；先 Read 再写。

## 一、方法专有细则（叶 skill）

| 具体 skill | 管什么 | 何时 |
|------------|--------|------|
| `按产物拆步与IO咬合` | 按产物切分、步间咬合、禁空挂 | 各版写正文 |
| `方法步骤编号规范` | 独权 S1…；从权 Sij；新增不挂靠 | 各版写正文；从权细化时 |
| `路径与不变量二分` | 三问判路径/不变量；非区别数据可用「获得××」精简独权 | 第二版去非必要；第三版去钉死 |
| `调控闭环最低链` | 感知→判定→中间调控量→执行 | 本案为调控闭环时 |
| `方法独权成组下放` | 按步成组供从权 | 二→三版剔特征后；变劣回退时 |
| `方法独权命名时机` | 仅第二版优化命名 | 第二版写正文前；再调命名总控 |

## 二、通用横切（已有，只挂）

| skill | 何时 |
|-------|------|
| `条件判断语句规范` | 出现条件分支 |
| `预设值与参数来源检查` | 出现阈值/预设/运行参数 |
| `权利要求主谓宾结构规范` | 各版写正文 |
| `权利要求指代与参照清晰性规范` | 出现该/其或参照不清 |
| `自定义名词就地定义` | 非公知概念 |
| `权利要求清楚性与逻辑一致性规范` | 自查假宽/孤岛等 |
| `独立权利要求必要技术特征检查` | 第二版主用；第三版再筛 |
| `部件命名优化总控` | **仅第二版**（经 `方法独权命名时机`） |

## 三、结构侧可复用（已有；边界）

| skill | 方法案边界 |
|-------|------------|
| `交底口语名改写为自明结构名规范` | 数据对象/模块等口语名 |
| `方位与场景限定上位规范` | 步骤或问题中的场景钉死语 |
| `功能性限定使用边界规范` | **少用**；默认步骤+I/O，不靠功能空话 |

## 四、明确不挂

- `结构类权利要求撰写`（先总列后展开）
- 结构独权「每版均开命名对照表」策略

## 与策略 skill 的调用关系

```text
方法类独权撰写（三版 plan）
  → 写第2/4/6步正文前 → 本总控（按表 Read）
       → 方法专有叶 / 通用横切 / 结构可复用
  → 正文仍交回方法类独权撰写该步交付
```

## 最低交付（本总控被点名时）

1. 本案将启用的细则清单（专有叶 + 触发的横切）；  
2. 一句：细则 Read 后回 `方法类独权撰写` 当前步写正文。  

禁止在本总控内输出独权全文或多版对照。
