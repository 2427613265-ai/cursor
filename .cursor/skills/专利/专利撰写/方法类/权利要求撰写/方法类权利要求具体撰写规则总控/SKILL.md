# 方法类权利要求具体撰写规则总控

方法/算法案**独权正文具体写法**的二级入口。只挂接、编排通用横切与结构侧可复用规范；**不**产出独权全文、**不**重新核定技术问题、**不**代替 `方法类独权撰写` 的 2.1～2.6 plan。

两版策略与 plan 仍在 `方法类独权撰写`；写某一版**正文**时经本总控按表 Read 触发的横切。**不含方法专有细则**——原 `方法类权利要求专有细则`、旧六叶及曾并入的具体规则（拆步/I/O、步骤编号、路径/不变量、闭环最低链、成组下放、命名时机）均已删除。

**曾用名（已删除，勿再查找）：** `方法类权利要求专有细则`、`按产物拆步与IO咬合`、`方法步骤编号规范`、`路径与不变量二分`、`调控闭环最低链`、`方法独权成组下放`、`方法独权命名时机`。用户点名时说明规则已删除，改走本页横切 + `方法类独权撰写` 策略。

**不适用：** 结构「先总列部件再展开」；纯装置构成罗列。

## 适用与边界

- **入口：** `方法类独权撰写` 第3/5步写正文前必经本总控；第5步写第二版前**先读** `第二版独权校核`（对齐新主题用语后再经本总控写正文）；第1/2/4步仍走 `核心区别技术特征确定` / `最小技术特征集与第一版独权` / `审定技术主题与重新核定技术问题` 等策略细则；或用户点名本总控。
- **禁止：** 充当 `独权撰写` / `方法类独权撰写`；套用 `结构类权利要求撰写`「先总列后展开」。
- **硬性：** 本页不维护方法专有正文规则；只挂表内横切。方法案命名时机（仅第二版）见 `方法类独权撰写`。

## 一、通用横切（只挂）

| skill | 何时 |
|-------|------|
| `条件判断语句规范` | 出现条件分支 |
| `预设值与参数来源检查` | 出现阈值/预设/运行参数 |
| `权利要求主谓宾结构规范` | 各版写正文 |
| `权利要求指代与参照清晰性规范` | 出现该/其或参照不清 |
| `自定义名词就地定义` | 非公知概念。**对象名**走命名总控第 4 闸；本行管方法参数等非对象名 |
| `权利要求清楚性与逻辑一致性规范` | 自查假宽/孤岛等 |
| `独立权利要求必要技术特征检查` | **不**用于第2步组集（组集不考虑先前技术问题）；第5步主用 |
| `部件命名优化总控` | **仅第二版**（时机见 `方法类独权撰写`）。对象名/中间量名的口语改写、方位定语、删定语、就地定义均经此总控分流，见 `部件命名/README.md` |

## 二、结构侧可复用（已有；边界）

| skill | 方法案边界 |
|-------|------------|
| `交底口语名改写为自明结构名规范` | **对象名**走命名总控第 1 闸。本行仅：步骤/关系里的布置口语（非对象名）可直读 |
| `方位与场景限定上位规范` | **名称定语**走命名总控第 2 闸。本行仅：步骤或问题句中的场景钉死语（不是对象名）可直读 |
| `功能性限定使用边界规范` | **少用**；默认写清楚步骤与输入输出，不靠功能空话 |

## 三、明确不挂

- `结构类权利要求撰写`（先总列后展开）
- 结构独权「每版均开命名对照表」策略
- 方法案第三版 / 再上位 / 递交变劣（方法案无这些步骤）
- 已删除的方法专有细则、旧六叶及上述具体规则正文

## 与策略 skill 的调用关系

```text
方法类独权撰写（2.1～2.6 plan）
  → 第5步先读 `第二版独权校核` → 写第3/5步正文前 → 本总控（按表 Read 横切）
  → 正文仍交回方法类独权撰写该步交付
```

## 最低交付（本总控被点名时）

1. 本案将触发的横切清单（上表按特征命中选用）；  
2. 一句：横切 Read 后回 `方法类独权撰写` 当前步写正文。  

禁止在本总控内输出独权全文或多版对照。

## 检查清单

- [ ] 未在本页写策略 plan / 重新核定 / 独权全文  
- [ ] 未套结构「总列后展开」  
- [ ] 已挂通用/结构可复用横切；命名仅第二版（见 `方法类独权撰写`）  
- [ ] 未尝试恢复已删除的方法专有细则  

## 能力边界

不管技术问题如何核定（见 `方法类独权撰写`）；不管拆步/I/O、步骤编号、路径/不变量、闭环链、成组下放等已删除的方法专有规则。
