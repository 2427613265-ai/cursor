# 方法类权利要求具体撰写规则总控

方法/算法案**独权正文具体写法**的二级入口。只挂接、编排细则；**不**产出独权全文、**不**重新核定技术问题、**不**代替 `方法类独权撰写` 的 2.1～2.6 plan。

两版策略与 plan 仍在 `方法类独权撰写`；写某一版**正文**时经本总控按表 Read。方法专有规则已收束为 **`方法类权利要求专有细则`**（原六叶不再单开）。

## 适用与边界

- **入口：** `方法类独权撰写` 第3/5步写正文前必经本总控；第1步定核心区别**先读** `核心区别技术特征确定`，并可挂本页所挂 `方法类权利要求专有细则` 第三节；第2步组成最小集时可挂该专有细则；从权细化步骤/承接下放组时亦可挂该专有细则；或用户点名本总控 / `方法类权利要求专有细则` / 旧六叶名。
- **禁止：** 充当 `独权撰写` / `方法类独权撰写`；套用 `结构类权利要求撰写`「先总列后展开」。
- **硬性：** 本页不粘贴专有细则全文；先 Read 再写。点名旧叶名（拆步I/O、步骤编号、路径与不变量、闭环最低链、成组下放、命名时机）→ 直读 `方法类权利要求专有细则` 对应节。

## 一、方法专有细则（只挂这一份）

| 具体 skill | 管什么 | 何时 |
|------------|--------|------|
| **`方法类权利要求专有细则`** | 拆步与I/O、步骤编号、路径/不变量、闭环最低链、成组下放、命名时机 | **写第3/5步正文前必读**（按该页「分节何时用」选用；闭环节仅闭环案启用）。第1/2步助判核心区别与最小集时读对应节。从权细化步骤/承接下放组时读编号与下放节。 |

## 二、通用横切（已有，只挂）

| skill | 何时 |
|-------|------|
| `条件判断语句规范` | 出现条件分支 |
| `预设值与参数来源检查` | 出现阈值/预设/运行参数 |
| `权利要求主谓宾结构规范` | 各版写正文 |
| `权利要求指代与参照清晰性规范` | 出现该/其或参照不清 |
| `自定义名词就地定义` | 非公知概念。**对象名**走命名总控第 4 闸；本行管方法参数等非对象名 |
| `权利要求清楚性与逻辑一致性规范` | 自查假宽/孤岛等 |
| `独立权利要求必要技术特征检查` | **不**用于第2步组集（组集不考虑先前技术问题）；第5步主用 |
| `部件命名优化总控` | **仅第二版**（经 `方法类权利要求专有细则` 第六节命名时机）。对象名/中间量名的口语改写、方位定语、删定语、就地定义均经此总控分流，见 `部件命名/README.md` |

## 三、结构侧可复用（已有；边界）

| skill | 方法案边界 |
|-------|------------|
| `交底口语名改写为自明结构名规范` | **对象名**走命名总控第 1 闸。本行仅：步骤/关系里的布置口语（非对象名）可直读 |
| `方位与场景限定上位规范` | **名称定语**走命名总控第 2 闸。本行仅：步骤或问题句中的场景钉死语（不是对象名）可直读 |
| `功能性限定使用边界规范` | **少用**；默认步骤+I/O，不靠功能空话 |

## 四、明确不挂

- `结构类权利要求撰写`（先总列后展开）
- 结构独权「每版均开命名对照表」策略
- 方法案第三版 / 再上位 / 递交变劣（方法案无这些步骤）
- 已删除的旧六叶目录（规则在 `方法类权利要求专有细则`）

## 与策略 skill 的调用关系

```text
方法类独权撰写（2.1～2.6 plan）
  → 写第3/5步正文前 → 本总控（按表 Read）
       → 方法类权利要求专有细则 / 通用横切 / 结构可复用
  → 正文仍交回方法类独权撰写该步交付
```

## 最低交付（本总控被点名时）

1. 本案将启用的细则清单（`方法类权利要求专有细则` 将用哪些节 + 触发的横切）；  
2. 一句：细则 Read 后回 `方法类独权撰写` 当前步写正文。  

禁止在本总控内输出独权全文或多版对照。
