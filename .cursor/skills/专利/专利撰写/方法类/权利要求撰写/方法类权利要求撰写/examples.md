# 方法类权利要求撰写 · 正反例

按需 Read；正文规则见同目录 `SKILL.md`。

## 1. 步内空挂输入（不合格）

```text
获取管网水力模型以及当前监测点集合；基于所述管网水力模型生成多漏损工况数据；
以所述多漏损工况数据训练全节点基准定位模型；提取…节点特征；
```

问题：本步写明获取「当前监测点集合」，但训练/抽特征未使用该集合 → **输入未用尽**。

处置：将该集合的获取挪到真正用于覆盖判断或增量起点的步骤；或改写本步输出使二者均为必要输入。

## 2. 路径堆进独权（过窄）

```text
提取全节点TCN最后一个卷积层输出的128维向量，采用余弦相似度构建矩阵并做谱聚类……
```

处置：独权写「根据节点特征之间的特征相似度进行聚类，得到特征簇」；TCN/层号/维数/余弦/谱聚类进从权。

## 3. I/O + 必要准则（宜留独权）

```text
基于管网水力模型，得到各管网节点的节点特征；
根据所述节点特征之间的特征相似度对管网节点进行聚类，得到特征簇；
……在信息盲区内按定位误差减少量选择监测点加入集合；每加入后重新训练漏损定位模型并更新定位误差减少量……
```

说明：步间「节点特征→聚类→盲区选点」咬合；「盲区内 + 误差减少量 + 重评」为不变量；中间造数/训练细节可从权展开。

## 4. 假宽（禁止）

```text
对管网数据进行智能分析并优化监测点布设。
```

无可核对的分步 I/O 与准则。
