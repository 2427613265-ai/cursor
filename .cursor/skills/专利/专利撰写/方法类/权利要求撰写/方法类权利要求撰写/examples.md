# 方法类权利要求撰写 · 正反例

按需 Read；正文规则见同目录 `SKILL.md`（含规则四：路径/不变量三问与可实施下限）。

## 1. 步内空挂输入（不合格）

```text
获取管网水力模型以及当前监测点集合；基于所述管网水力模型生成多漏损工况数据；
以所述多漏损工况数据训练全节点基准定位模型；提取…节点特征；
```

问题：本步写明获取「当前监测点集合」，但训练/抽特征未使用该集合 → **操作数空挂**。

处置：将该集合的获取挪到覆盖判断或增量选点步；**禁止**为通过用尽检查而虚构「本步输出初始方案评估」——除非交底确实有该产出。

## 1b. 拆步过碎（不合格 · 规则一）

```text
S1 生成多漏损工况数据；
S2 训练全节点基准定位模型；
S3 提取节点特征；
S4 计算相似度矩阵；
S5 谱聚类得到特征簇；
…
```

问题：按实现路径拆碎，独权主步骤过多，易把路径抬进独权。

处置：按产物合并，例如「得到节点特征」一步（内含仿真/训练概括层）→「得到特征簇与候选监测点集合」→「增量选点得到优化集合」→「验证并输出方案」；相似度/谱聚类细节进从权。

## 1c. 循环按轮次拆步（不合格 · 规则一）

```text
Sn 加入贡献度最高的节点286；
Sn+1 加入节点304；
Sn+2 加入节点638；
```

处置：合并为一步「盲区约束的增量选点」，用预设切换/终止条件控制循环。

## 2. 路径堆进独权（过窄 · 判问①）

```text
提取全节点TCN最后一个卷积层输出的128维向量，采用余弦相似度构建矩阵并做谱聚类……
```

三问：换成其他能出节点特征的模型/其他相似度与聚类，本步「节点特征→特征簇」I/O 仍成立 → **路径**。

处置：独权写「根据节点特征之间的特征相似度进行聚类，得到特征簇」；TCN/层号/维数/余弦/谱聚类进从权。

## 3. 误把不变量当路径删（不合格 · 判问③）

```text
在候选监测点集合内选择监测点加入布设集合，直至满足终止条件。
```

问题：删掉「在信息盲区内选」「按定位误差减少量选」「加点后重评」后，与交底区别及所解技术问题落空 → 这些是**不变量**，不得当路径下放。

处置：独权必须保留盲区约束、误差减少量选点及加入后更新评价等准则。

## 4. 概括层过薄、跌破可实施下限（不合格 · 判问②）

```text
基于管网水力模型，得到各管网节点的节点特征。
```

若说明书/交底情境下，本领域无法仅凭该句知道特征从何而来，则独权过空。

处置（概括层可留独权）：例如「基于管网水力模型，通过多漏损工况仿真与定位模型训练，提取各管网节点的节点特征」——仍不钉死 EPANET/TCN/层号；仿真参数与网络结构进从权。

## 5. I/O + 不变量 + 必要概括（宜留独权）

```text
基于管网水力模型，通过多漏损工况仿真与定位模型训练，提取各管网节点的节点特征；
根据所述节点特征之间的特征相似度对管网节点进行聚类，得到特征簇；
……在信息盲区内按定位误差减少量选择监测点加入集合；每加入后重新训练漏损定位模型并更新定位误差减少量……
```

说明：造数/训练的**具体路径**可从权展开；独权保留概括层 +「盲区内 + 误差减少量 + 重评」不变量；步间 I/O 咬合。

## 6. 假宽（禁止）

```text
对管网数据进行智能分析并优化监测点布设。
```

无可核对的分步 I/O 与准则。

## 7. 非 ML 工法类 · I/O 拆步示意（合格方向）

主题：一种隧道初期支护喷射混凝土的施工方法（示意，非完整独权）。

| 步骤 | 输入 | 输出 | 不变量（若有） | 拟下放路径 |
|------|------|------|----------------|------------|
| S1 | 开挖轮廓与设计支护参数 | 喷射作业分区与喷层厚度控制目标 | 按分区顺序施工 | 具体分区尺寸、仪器型号 |
| S2 | 分区与厚度控制目标、拌合料 | 已喷射成型的喷层 | 分层喷射且层间间歇满足预设条件 | 配比、风压、喷嘴型号 |
| S3 | 已成型喷层 | 质量检测结果与是否进入下一循环的判定 | 检测不合格则返工至满足预设指标 | 检测点数量、具体仪器 |

独权宜写「获取…→得到…；判断是否满足预设条件，若否，则…」；配比与仪器进从权。勿把「风压 0.X MPa」等路径写进独权主步骤。

## 8. 调控闭环 · 跳过中间调控量（不合格 · 规则八）

```text
获取冰厚与水温剖面；确定暖水层；根据暖水层调整出水口距离或功率。
```

问题：未产出「冰–水热通量 / 目标热通量 / 偏差」等**中间调控量**，执行步缺少可核对的控制依据，因果断链。

处置：插入调控量步，例如「计算实际热通量与目标热通量，得到热通量偏差」→「根据所述热通量偏差调整…」。

## 9. 调控闭环 · I/O 对照表示意（合格方向 · 规则八/九）

主题：水体热分层下的冰层生消调控方法（示意，非完整独权）。

| 步骤 | 输入 | 输出 | 不变量（若有） | 拟下放路径（按步） |
|------|------|------|----------------|--------------------|
| S1 感知 | 监测数据 | 初始冰厚、水温剖面 | — | 测点布置、温度链、传感器型号 |
| S2 作用/判定 | 水温剖面、泵/出口参数 | 暖水层判定 + **定向扰动水流**（作用场） | 先判定暖水层并驱动输送以建立扰动（作用可先于精细通量观测） | 驱动方式、ADCP、流速阈值 |
| S3 调控量 | 冰厚、暖水层、作用场工况 | **实际/目标热通量及偏差**（控制量中置） | 先算通量再比偏差 | 热通量公式、系数、回归 |
| S4 执行 | 热通量偏差 | 调整后的出水口距离和/或功率 | **根据偏差调节**；多旋钮「和/或」 | 各旋钮公式、优先顺序、高程数值 |
| （从权）闭环 | — | 返回重测/补偿/终止 | 闭环不变量已在独权 | 气象补偿、返回 S3、终止条件 |

从权示例映射（逐步显微镜）：权2–3←S1；权4←S2；权5–7←S3；权8–9←S4/补偿闭环。

独权步内「以…」示例：S2「…以产生定向扰动水流」；S4「…以控制热交换速率」——接的是本步直接效果，不是「提高调控智能化水平」类空话。
## 10. 多执行器只钉死一种（过窄 · 规则八.2）

```text
根据所述热通量偏差，调整水泵出水口与水面的距离。
```

若交底同时支持调功率（或二者联合），且换任一种仍完成「按偏差调节」，独权宜写「调整…距离**和/或**…功率」；专条细节进从权。若只有距离才是区别不变量，则不得用「和/或」冲掉。
