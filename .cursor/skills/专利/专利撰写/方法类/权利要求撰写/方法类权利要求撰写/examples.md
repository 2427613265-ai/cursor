# 方法类权利要求撰写 · 正反例

按需 Read；正文规则见同目录 `SKILL.md`（含规则四：路径/不变量三问与可实施下限）。

## 1. 步内空挂输入（不合格）

```text
获取管网水力模型以及当前监测点集合；基于所述管网水力模型生成多漏损工况数据；
以所述多漏损工况数据训练全节点基准定位模型；提取…节点特征；
```

问题：本步写明获取「当前监测点集合」，但训练/抽特征未使用该集合 → **输入未用尽**。

处置：将该集合的获取挪到真正用于覆盖判断或增量起点的步骤；或改写本步输出使二者均为必要输入。

## 2. 路径堆进独权（过窄 · 判问①）

```text
提取全节点TCN最后一个卷积层输出的128维向量，采用余弦相似度构建矩阵并做谱聚类……
```

三问：换成其他能出节点特征的模型/其他相似度与聚类，本步「节点特征→特征簇」I/O 仍成立 → **路径**。

处置：独权写「根据节点特征之间的特征相似度进行聚类，得到特征簇」；TCN/层号/维数/余弦/谱聚类进从权。

## 3. 误把不变量当路径删（不合格 · 判问③）

```text
在候选监测点集合内选择监测点加入布设集合，直至满足终止条件。
```

问题：删掉「在信息盲区内选」「按定位误差减少量选」「加点后重评」后，与交底区别及所解技术问题落空 → 这些是**不变量**，不得当路径下放。

处置：独权必须保留盲区约束、误差减少量选点及加入后更新评价等准则。

## 4. 概括层过薄、跌破可实施下限（不合格 · 判问②）

```text
基于管网水力模型，得到各管网节点的节点特征。
```

若说明书/交底情境下，本领域无法仅凭该句知道特征从何而来，则独权过空。

处置（概括层可留独权）：例如「基于管网水力模型，通过多漏损工况仿真与定位模型训练，提取各管网节点的节点特征」——仍不钉死 EPANET/TCN/层号；仿真参数与网络结构进从权。

## 5. I/O + 不变量 + 必要概括（宜留独权）

```text
基于管网水力模型，通过多漏损工况仿真与定位模型训练，提取各管网节点的节点特征；
根据所述节点特征之间的特征相似度对管网节点进行聚类，得到特征簇；
……在信息盲区内按定位误差减少量选择监测点加入集合；每加入后重新训练漏损定位模型并更新定位误差减少量……
```

说明：造数/训练的**具体路径**可从权展开；独权保留概括层 +「盲区内 + 误差减少量 + 重评」不变量；步间 I/O 咬合。

## 6. 假宽（禁止）

```text
对管网数据进行智能分析并优化监测点布设。
```

无可核对的分步 I/O 与准则。
