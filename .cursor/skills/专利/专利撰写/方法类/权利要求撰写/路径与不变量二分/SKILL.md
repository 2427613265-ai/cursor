# 路径与不变量二分

方法/算法独权去钉死、去非必要时的**轻量判定**。由总控在第3/4步助判核心区别与最小集、第7步去非必要/去钉死时挂接。  
**不**恢复轨A/B正式择轨，**不**要求各版提交 I/O 对照表硬门禁。

## 术语（白话）

| 用语 | 含义 |
|------|------|
| **路径** | 一种实现外壳（工具/软件名、具体算法名、层数维数、数值范围等）；换成等价实现后，本步 I/O 关系往往仍成立 → 宜删/概括/下放 |
| **不变量** | 换等价实现后仍必须留下的**区别骨架**（关键变换准则、控制逻辑）；删了则发明不成立或被抽空 → **独权必留** |

二者都不是数学「invariant」；本页只用于权要取舍。

## 三问（对每一拟删/拟概括限定依次问）

1. **换等价实现后，本步 I/O 关系是否仍成立？**  
   → 是：多为**路径** → 宜删/概括/下放从权。  
2. **是否恰为本案区别准则或控制逻辑骨架？**  
   → 是：**不变量** → 独权必留；不得为扩围抽空。  
3. **去掉后是否只剩假宽空词、无法实施？**  
   → 是：不得假宽；回调保留可实施下限（可与不变量重叠）。

## 非区别数据的「获得」表述（精简独权）

对**不是发明点、无区别贡献**的数据/输入（常规工况量、公知接口可读量、仅作背景的配置表等）：

| 独权 | 从权 |
|------|------|
| 可用 **「获得××」/「获取××」** 概括，**不写**具体采集、解算、传感器、通信接口、文件格式等准备过程 | 将上述具体获得步骤/方式成组下放（见 `方法独权成组下放`） |

**判据（先问再省）：**

1. 该数据的**来源/采集/准备方式**是否恰为本案区别点？  
   - **否** → 独权「获得××」即可；细节进从权（属**路径**）。  
   - **是**（特殊采样、特殊标注、区别性预处理等）→ 独权须保留能体现区别的获得/生成步骤（属**不变量**），不得收成光秃「获得」。  
2. 后续独权步骤是否**实际使用**该××？  
   - **必须使用**；否则是空挂，见 `按产物拆步与IO咬合`（与本条精简无关）。  
3. 省掉具体获得过程后，本领域能否理解××从何处可合理得到？  
   - **不能** → 不得假宽；至少保留可实施的获得下限，或把必要下限留在独权。

**目的：** 精简独权，避免非区别的数据准备链拖胖权1；**不是**把区别性数据处理藏进从权。
