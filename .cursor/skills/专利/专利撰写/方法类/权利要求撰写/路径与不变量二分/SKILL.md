# 路径与不变量二分

方法/算法独权去钉死、去非必要时的**轻量判定**。由总控在第二版去非必要、第三版去钉死时挂接。  
**不**恢复轨A/B正式择轨，**不**要求各版提交 I/O 对照表硬门禁。

## 术语（白话）

| 用语 | 含义 |
|------|------|
| **路径** | 一种实现外壳（工具/软件名、具体算法名、层数维数、数值范围等）；换成等价实现后，本步 I/O 关系往往仍成立 → 宜删/概括/下放 |
| **不变量** | 换等价实现后仍必须留下的**区别骨架**（关键变换准则、控制逻辑）；删了则发明不成立或被抽空 → **独权必留** |

二者都不是数学「invariant」；本页只用于权要取舍。

## 三问（对每一拟删/拟概括限定依次问）

1. **换等价实现后，本步 I/O 关系是否仍成立？**  
   → 是：多为**路径** → 宜删/概括/下放从权。  
2. **是否恰为本案区别准则或控制逻辑骨架？**  
   → 是：**不变量** → 独权必留；不得为扩围抽空。  
3. **去掉后是否只剩假宽空词、无法实施？**  
   → 是：不得假宽；回调保留可实施下限（可与不变量重叠）。

## 操作落点

| 版本 | 用法 |
|------|------|
| 第二版 | 清非必要实现路径；保留最小区别骨架 |
| 第三版 | 在无非必要之上继续去工具/参数钉死；表述上位不得违反问3 |
| 变劣 | 可变劣点优先来自仍属路径的限定 |
