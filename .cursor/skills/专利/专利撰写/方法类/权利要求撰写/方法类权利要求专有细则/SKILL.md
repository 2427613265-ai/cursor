# 方法类权利要求专有细则

方法/算法案**专有撰写规则全集**（原六叶已收束于此）。由 `方法类权利要求具体撰写规则总控` 挂接；不替代 `方法类独权撰写` 的两版策略与 2.1～2.8 plan。

**曾用名（点名即读本页对应节）：** `按产物拆步与IO咬合`、`方法步骤编号规范`、`路径与不变量二分`、`调控闭环最低链`、`方法独权成组下放`、`方法独权命名时机`。

**不适用：** 结构「先总列部件再展开」；纯装置构成罗列。条件句句式、预设值来源、主谓宾、指代、就地定义、清楚性、必要特征检查等横切仍走总控所挂通用 skill。

| 第4步组成最小集 | 一、拆步与I/O；三、路径与不变量 | 五、成组下放（未入集候选） |

## 一、按产物拆步与 I/O 咬合

### 按产物拆步

1. 主步骤一般约 **3～7** 步；以本步**得到什么**（中间量、状态、方案、指令等）为切分点。  
2. **禁止**按代码行、仿真次数、训练 epoch、日志打印点等实现粒度拆碎。  
3. 循环、迭代、增量更新过程默认写成**一步**，在该步内用控制流写明切换与终止条件（条件句走 `方法步骤条件与参数规范`）。  
4. 一步内可含多个紧密咬合的子操作，但对外仍是一个「产物」节点；需要从权细化时用第二节的 `Sij`。

### 每步 I/O 可核对

读者须能从权要文字看出：

| 核对项 | 要求 |
|--------|------|
| **基于什么** | 本步输入来自交底已引入的数据、上一步产物，或本步内先获取/算得 |
| **得到什么** | 本步产物有名称或可指代的结果，供后续步骤或权利要求结尾使用 |
| **步间咬合** | 上一步输出能被下一步合法使用；禁止「上步产出 A、下步却依赖从未出现的 B」 |

### 禁止空挂操作数

- **禁止**写「获取/采集/读取××」却在本步及后续独权步骤中**从不使用**该××。  
- 若某量仅在更后步骤才用：获取动作应写在**真正首次使用**的步骤，或写明获取后立即得到供后续使用的命名产物。  
- 空挂常见于：为凑「数据采集感」前置一堆无关读取；或把说明书实施例操作未加筛选写入独权。

空挂 ≠ 第三节允许的「获得××」精简：空挂是写了获取却**不消费**；精简是后续**要用**××，独权只不展开具体获得过程。当××为非发明点输入时，「获得××」视为合法的按产物一步（本步产物即××），须与下一步咬合；**不得**据此把区别性预处理也收成光秃「获得」。

## 二、步骤编号

| 场景 | 编号 | 说明 |
|------|------|------|
| 独权主步骤 | `S1、S2、S3…` | 与权要正文步骤顺序一致；交付时可附「步骤编号对照」 |
| 从权对某主步细化 | `Sij` | 如细化 S2 → `S21、S22…`；不得跳号混乱挂靠 |
| 整案新增、不挂靠已有步 | **不加**挂靠号 | 另起独立主步号或写清「新增步」，禁止硬挂成 S2x 假装从属于 S2 |

1. 独权主步骤用连续 `S1…Sn`；中途插入须重排并在对照中说明。  
2. `Sij` 仅用于**从权**（或布局说明）对已有 `Si` 的细化，不在独权里用 S21 冒充主步。  
3. 与交底实施例步骤号无关；不得把交底「步骤3.2」直接当权要编号。  
4. 权要正文**可不出现**「S1」字样：可用交付说明中的编号对照表；若正文列举「步骤一、步骤二」，对照表须一一映射到 `S1、S2`。

成组下放按哪一步分组：用本表编号指称。

## 三、路径与不变量二分

去钉死、去非必要时的轻量判定。**不**恢复轨A/B正式择轨，**不**要求各版提交 I/O 对照表硬门禁。二者都不是数学「invariant」，只用于权要取舍。

| 用语 | 含义 |
|------|------|
| **路径** | 一种实现外壳（工具/软件名、具体算法名、层数维数、数值范围等）；换成等价实现后，本步 I/O 关系往往仍成立 → 宜删/概括/下放 |
| **不变量** | 换等价实现后仍必须留下的**区别骨架**（关键变换准则、控制逻辑）；删了则发明不成立或被抽空 → **独权必留** |

### 三问（对每一拟删/拟概括限定依次问）

1. **换等价实现后，本步 I/O 关系是否仍成立？** → 是：多为**路径** → 宜删/概括/下放从权。  
2. **是否恰为本案区别准则或控制逻辑骨架？** → 是：**不变量** → 独权必留；不得为扩围抽空。  
3. **去掉后是否只剩假宽空词、无法实施？** → 是：不得假宽；回调保留可实施下限（可与不变量重叠）。

第3步只用三问定「哪些是核心区别」，不写独权、不组成最小集。第4步：路径不宜进最小集；不变量为完整方案支撑。第7步：清非必要实现路径；非区别输入改为「获得××」；保留最小区别骨架。

### 非区别数据的「获得」表述

对**不是发明点、无区别贡献**的数据/输入（常规工况量、公知接口可读量、仅作背景的配置表等）：

| 独权 | 从权 |
|------|------|
| 可用 **「获得××」/「获取××」** 概括，**不写**具体采集、解算、传感器、通信接口、文件格式等准备过程 | 将上述具体获得步骤/方式按第五节成组下放 |

**判据（先问再省）：**

1. 该数据的**来源/采集/准备方式**是否恰为本案区别点？否 → 独权「获得××」即可（路径）；是（特殊采样、特殊标注、区别性预处理等）→ 独权须保留能体现区别的获得/生成步骤（不变量），不得收成光秃「获得」。  
2. 后续独权步骤是否**实际使用**该××？必须使用；否则是第一节的空挂，与本条精简无关。  
3. 省掉具体获得过程后，本领域能否理解××从何处可合理得到？不能 → 不得假宽；至少保留可实施的获得下限。

目的：精简独权，避免非区别的数据准备链拖胖权1；**不是**把区别性数据处理藏进从权。

## 四、调控闭环最低链（仅闭环案）

**仅当本案为调控/闭环型**时启用。本节约是拆步/I/O 在闭环案上的特化，**不是**全部方法独权的第一质量规则。非闭环的方法/纯数据处理案**不要**强制套本链。

```text
感知 →（可选）判定 → 中间调控量 → 按准则/偏差执行
```

| 环 | 含义 | 独权常见写法 |
|----|------|--------------|
| **感知** | 取得与调控相关的状态/偏差输入 | 获取压力、流量、误差、工况量等 |
| **判定（可选）** | 要不要调、往哪边调 | 「判断是否…若是…若否…」（`方法步骤条件与参数规范`） |
| **中间调控量** | 感知（与判定）之后、执行之前的调控依据 | 目标开度、修正量、设定增量、分配权重等 |
| **执行** | 按该量或准则改对象 | 调节执行器、更新设定、下发指令等 |

1. **缺环要交代**：交底是闭环，独权却少中间调控量或少执行 → 须补步，或写明合并/下放理由（不得 silently 省略）。  
2. **中间调控量须有来源**：不能凭空「根据优化结果调节」；须能从前文感知/计算/判定推出（与 `方法步骤条件与参数规范` 同精神）。  
3. **判定可选**：无分支可感知后直接形成调控量再执行；有分支必须用规范条件句。  
4. **公式/具体算法默认从权**：独权保留「形成何种中间量 + 按何类准则执行」；PID 公式、寻优式等进从权，除非恰为区别点（不变量）。  
5. 四环是结构下限（骨架）；具体传感器型号、求解器名等多属路径（见第三节）。

## 五、成组下放

方法/算法案在第4步组最小集及第7步第一版→第二版剔特征时的下放编排。不代替从权引用合规、形式编号（见 `从权撰写` / 形式类 skill）。

1. **按独权主步骤成组**：未纳入/删/概括掉的关联路径（工具、参数、细分支、实施例配套）按其所附属的 `S1…Sn` 分组，每组对应次级问题或效果，供从权与说明书。  
2. **一组一事**：同一从权（或从权簇）尽量只承接同一主步上的相关细化，避免把无关路径捆成一条。  
3. **禁止抽空骨架**：当前版本最小区别骨架（不变量）**不得**整组藏进从权；若误放，须回独权。  
4. **「获得××」省掉的具体获得步骤**：独权对非区别输入仅写「获得/获取××」时，被省略的采集/解算/接口/格式等准备过程，挂靠该「获得」主步，成组写入从权（判据见第三节）。  
5. **两处来源均要收**：第2步清单中未进入第4步最小集的特征，以及第7步相对第一版剔出的特征，都按步成组。  
6. **交付物**：至少给出「步骤号 → 下放特征摘要 → 建议从权主题」对照；完整从权文句交 `从权撰写`。

## 六、命名时机（仅第二版优化）

具体改名手法仍走 `权利要求命名细则`。本节约管**何时**优化。

| 版本 | 命名动作 | 说明 |
|------|----------|------|
| **第一版**（第5步） | **不优化** | 一律沿用交底原名（口语/缩略/工具名可暂留）；可不交命名对照表 |
| **第二版**（第7步） | **唯一一次优化** | 必须触发 `权利要求命名细则` → 对照表（关键名至少两档 + 推荐采用名 + 范围影响）→ **用户确认前不得写第二版正文** |

1. 方法案**禁止**套用结构独权「每一版都开命名表」。  
2. 第二版确认名即全书基准；从权/说明书术语与之对齐。方法案无第三版、无再上位独权。  
3. 口语名改写、方位/场景上位等，在第二版优化时按 `权利要求命名细则` 分型处理。  
4. 数据对象、中间量、模块名与步骤产物名一并纳入第二版对照，避免只改半套。

## 最低自检（写完一版独权正文后）

- [ ] 主步骤按产物切分（约 3～7 步），非按代码；每步能指出输入来源与产物  
- [ ] 无空挂获取；无「产出未用、所用未产」；非区别「获得××」后续有消费  
- [ ] 主步为 S1…Sn 连续；从权细化才用 Sij；新增步未假挂旧号  
- [ ] 拟删项已经三问；路径与不变量未混；区别准则/控制逻辑仍在独权  
- [ ] 闭环案：感知与执行能读出，中间调控量有着落；非闭环未强套四环  
- [ ] 下放项能挂到具体 Si；区别骨架未整组进从权；未入最小集与第一→第二版剔出均已收口  
- [ ] 第一版未擅自改名；第二版有对照表且经确认后才写正文
