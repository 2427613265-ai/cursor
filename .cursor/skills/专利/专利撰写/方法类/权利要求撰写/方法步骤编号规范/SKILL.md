# 方法步骤编号规范

方法/算法权利要求的**步骤编号体例**。由 `方法类权利要求具体撰写规则总控` 挂接；切步与 I/O 见 `按产物拆步与I/O咬合`。

## 编号表

| 场景 | 编号 | 说明 |
|------|------|------|
| 独权主步骤 | `S1、S2、S3…` | 与权要正文步骤顺序一致；交付时可附「步骤编号对照」 |
| 从权对某主步细化 | `Sij` | 如细化 S2 → `S21、S22…`；不得跳号混乱挂靠 |
| 整案新增、不挂靠已有步 | **不加**挂靠号 | 另起独立主步号或在说明中写清「新增步」，禁止硬挂成 S2x 假装从属于 S2 |

## 硬性规则

1. 独权主步骤用连续 `S1…Sn`；中途插入须重排并在对照中说明。  
2. `Sij` 仅用于**从权**（或布局说明）对已有 `Si` 的细化，不在独权里用 S21 冒充主步。  
3. 与交底实施例步骤号无关；不得把交底「步骤3.2」直接当权要编号。  
4. 权要正文**可不出现**「S1」字样：可用交付说明中的编号对照表；若正文列举「步骤一、步骤二」，对照表须一一映射到 `S1、S2`。
