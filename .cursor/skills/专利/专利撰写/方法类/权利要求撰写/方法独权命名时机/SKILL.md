# 方法独权命名时机

方法/算法案**何时做命名优化**的硬性规则。由总控挂接；具体改名手法仍走 `部件命名优化总控` 及其下游。

## 时机表（硬性）

| 版本 | 命名动作 | 说明 |
|------|----------|------|
| **第一版**（第4步） | **不优化** | 一律沿用交底原名（口语/缩略/工具名可暂留）；可不交命名对照表 |
| **第二版**（第6步） | **唯一一次优化** | 必须经本规则触发 `部件命名优化总控` → 对照表（关键名至少两档 + 推荐采用名 + 范围影响）→ **用户确认前不得写第二版正文** |

方法案无第三版、无再上位独权；第二版确认名即全书基准。

## 硬性规则

1. 方法案**禁止**套用结构独权「每一版都开命名表」。  
2. 第二版确认名即全书基准；从权/说明书术语与之对齐。  
3. 口语名改写、方位/场景上位等，在第二版优化时按命名总控分流（可挂 `交底口语名改写为自明结构名规范` 等）。  
4. 数据对象、中间量、模块名与步骤产物名一并纳入第二版对照，避免只改半套。
