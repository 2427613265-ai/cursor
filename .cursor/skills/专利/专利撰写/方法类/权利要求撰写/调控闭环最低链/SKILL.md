# 调控闭环最低链

**仅当本案为调控/闭环型**时由总控挂接。本页是拆步/I/O 在闭环案上的特化，**不是**全部方法独权的第一质量规则（问题锚定与必要特征仍优先）。

## 最低链

```text
感知 →（可选）判定 → 中间调控量 → 按准则/偏差执行
```

| 环 | 含义 | 独权常见写法 |
|----|------|--------------|
| **感知** | 取得与调控相关的状态/偏差输入 | 获取压力、流量、误差、工况量等 |
| **判定（可选）** | 要不要调、往哪边调 | 「判断是否…若是…若否…」（`条件判断语句规范`） |
| **中间调控量** | 感知（与判定）之后、执行之前的调控依据 | 目标开度、修正量、设定增量、分配权重等 |
| **执行** | 按该量或准则改对象 | 调节执行器、更新设定、下发指令等 |

## 硬性规则

1. **缺环要交代**：交底是闭环，独权却少中间调控量或少执行 → 须补步，或写明合并/下放理由（不得 silently 省略）。  
2. **中间调控量须有来源**：不能凭空「根据优化结果调节」；须能从前文感知/计算/判定推出（与 `预设值与参数来源检查` 同精神）。  
3. **判定可选**：无分支可感知后直接形成调控量再执行；有分支必须用规范条件句。  
4. **公式/具体算法默认从权**：独权保留「形成何种中间量 + 按何类准则执行」；PID 公式、寻优式等进从权，除非恰为区别点（不变量）。  
5. **与路径/不变量**：四环是结构下限（骨架）；具体传感器型号、求解器名等多属路径。

## 最低自检

- [ ] 感知与执行能读出；中间调控量有着落  
- [ ] 有分支则条件句合规  
- [ ] 未用功能空话代替中间量  

## 能力边界

非闭环的方法/纯数据处理案**不要**强制套本链。
