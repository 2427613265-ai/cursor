# 专利撰写总控（顶层：只挂阶段入口）

## 适用场景

- 用户说「写案子」「写专利」「从交底开始」「帮我做这份申请」且**未点名**具体阶段；
- 需要与 `质检总控` 对称的撰写侧总入口，避免误触质检叶节点或创造性旧名。

**硬性规则：** 本 skill **只分流**，不产出权要/说明书/答复正文。已点名阶段（如「写从权」「写独权第三版」「答复创造性」）可直接进对应阶段 skill；若误进本 skill，立刻改分流。

**不适用：** 「质检/审核/检查」→ `质检总控`；仅讨论单条规范细节且用户已点名规范名时，可直读该规范。

---

## 分流表

| 类型 | 典型说法 | 下一步 |
|------|----------|--------|
| A. 交底理解（默认起点） | 「拿到交底书」「先梳方案」「能不能写」 | `交底书技术方案理解` |
| B. 独权 | 「写独权」「三版独权」「重新界定技术问题」 | `独权撰写` |
| C. 创造性补强（可选） | 「评估创造性」「独权补强」 | `创造性评估与独权补强` |
| D. 从权 | 「写从权」「九条从权」「从权布局」 | `从权撰写` |
| E. 说明书 | 「写说明书」「写具体实施方式」「写背景/摘要」 | `权利要求定稿后说明书撰写`（再挂各说明书子 skill） |
| F. 创造性答复 | 「答复创造性」「写意见陈述」「一通/二通答复」 | `创造性答复总控` |
| G. 对象不明 | 只说「写专利」且无交底/无阶段 | 询问是否已有交底；有则 A，否则请用户补充材料 |

## 推荐全案链路

```text
专利撰写总控
  → 交底书技术方案理解（术语词典 → 外行总故事 → 构成/过程 → 懂后再体检 → 问题候选）
  → 独权撰写（自建三版递进 plan；方法案各版内 a策略→b方法优化→c择轨→d正文；含可选创造性评估与独权补强）
  → 从权撰写
  → 权利要求定稿后说明书撰写
  →（授权前 OA）创造性答复总控
  →（定稿后）质检总控
```

## 与质检总控的关系

| | 撰写 | 质检 |
|--|------|------|
| 顶层 | **本 skill** | `质检总控` |
| 权要二级 | `独权撰写` / `从权撰写` 等 | `权利要求质检总控` |
| 说明书二级 | `权利要求定稿后说明书撰写` | `说明书质检总控` |
| 创造性 OA | `创造性答复总控` | （论证在答复链路，不走质检总控） |

## 最低交付

分流时输出：当前判定类型（A～G）+ 将调用的阶段 skill 名 + 一句前置条件（如「须已有定稿权1」）。禁止在本 skill 内展开该阶段全文步骤。
