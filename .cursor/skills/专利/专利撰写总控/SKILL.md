# 专利撰写总控（顶层：只挂阶段入口）

## 适用场景

- 用户说「写案子」「写专利」「从交底开始」「帮我做这份申请」且**未点名**具体阶段；
- 需要与 `质检总控` 对称的撰写侧总入口，避免误触质检叶节点或创造性旧名。

**硬性规则：** 本 skill **只分流**，不产出权要/说明书/答复正文。已点名阶段（如「写从权」「写独权第三版」「答复创造性」）可直接进对应阶段 skill；若误进本 skill，立刻改分流。

**不适用：** 「质检/审核/检查」→ `质检总控`；仅讨论单条规范细节且用户已点名规范名时，可直读该规范。

---

## 分流表

| 类型 | 典型说法 | 下一步 |
|------|----------|--------|
| A. 独权（默认起点） | 「拿到交底书」「写案子」「写独权」「三版独权」「重新核定技术问题」 | `独权撰写`（再分流至 `结构类独权撰写` 等） |
| B. 从权 | 「写从权」「九条从权」「从权布局」「次要权利要求组」「产业链原则」「五件套」 | `从权撰写` |
| C. 说明书 | 「写说明书」「写具体实施方式」「写背景/摘要」 | `权利要求定稿后说明书撰写`（再挂各说明书子 skill） |
| D. 创造性答复 | 「答复创造性」「写意见陈述」「一通/二通答复」 | `创造性答复总控` |
| E. 对象不明 | 只说「写专利」且无交底/无阶段 | 询问是否已有交底；有则 A，否则请用户补充材料 |

## 现行口径（入口勿回退）

细则仍在下游 skill；本表只防入口套旧说法。

| 项 | 现行 | 勿用 |
|----|------|------|
| 机制 | 第1步机制三栏（问题–机制–效果）；填不满停步或 `[推定]` | 只交一句话、不交机制 |
| 删一法 | 没有 F，三栏效果还在不在 | 只问「能不能跑通」 |
| 步数 | 方法 7 步（第3步骨架核验不写正文）；结构 9 步。共用细则写「结构案第X / 方法案第Y」 | 方法旧 6 步直接写第一版；把结构第一版改成全局第4步 |
| 结构正文 | 关系、作用面；产品权禁止使用过程；动词独权取宽 | 把使用过程写进产品独权 |
| 方法正文 | 得到 X 骨架、单侧、步骤间约束；发明点只一侧用「在……的情况下」 | 只一侧仍写若是/若否 |
| 从权 | 树状；10 项费用预算非硬封顶；软件五件套不默认 | 默认长链；只写 10 条；默认五件套 |
| 校核 | 第二版交付前三句闸各一句 | 六道检验报告；12 节计划当独权步；三稿并行叠在分版上 |

## 推荐全案链路

```text
专利撰写总控
  → 独权撰写（分流）
       → 结构案：`结构类独权撰写`（第1步经 `核心区别技术特征确定`；第2/3步经 `最小技术特征集与第一版独权`；第4步经 `审定技术主题与重新核定技术问题`；第5步经 `第二版独权校核`；至第二版后保留再上位→第三版→可选变劣）
            → 写正文时：`结构类权利要求撰写`（先总列后展开；列名未展不得交付）+ 按需 `功能性限定使用边界规范`
       → 方法/算法案：`方法类独权撰写`（第1～2步与结构案同；第3步步骤骨架核验；第4步第一版；第5步审主题；第6步第二版；第7步收束）
            → 写正文时：`方法类权利要求具体撰写规则总控`（`方法类权利要求专有细则`；点名完整版再读 `方法类权利要求撰写`）
  → 从权撰写（核心组树状布局；10项为费用预算；完成后按产业链/对应/单边判定次要组，软件五件套不默认，见 `从权分层次布置` / `次要权利要求组撰写`）
  → 权利要求定稿后说明书撰写
  →（授权前 OA）创造性答复总控
  →（定稿后）质检总控
```

## 与质检总控的关系

| | 撰写 | 质检 |
|--|------|------|
| 顶层 | **本 skill** | `质检总控` |
| 权要二级 | `独权撰写`（入口）/ `结构类独权撰写` / `方法类独权撰写` / `核心区别技术特征确定`（第1步细则）/ `最小技术特征集与第一版独权`（结构案第2/3步、方法案第2/4步）/ `审定技术主题与重新核定技术问题`（结构案第4步、方法案第5步）/ `第二版独权校核`（结构案第5步、方法案第6步）/ `结构类权利要求撰写` / `功能性限定使用边界规范` / `方法类权利要求具体撰写规则总控`（挂 `方法类权利要求专有细则`；点名时挂 `方法类权利要求撰写`）/ `从权撰写` / `从权分层次布置` / `次要权利要求组撰写` 等 | `权利要求质检总控` |
| 说明书二级 | `权利要求定稿后说明书撰写` | `说明书质检总控` |
| 创造性 OA | `创造性答复总控` | （论证在答复链路，不走质检总控） |

## 最低交付

分流时输出：当前判定类型（A～E）+ 将调用的阶段 skill 名 + 一句前置条件（如「须已有定稿权1」）。禁止在本 skill 内展开该阶段全文步骤。
