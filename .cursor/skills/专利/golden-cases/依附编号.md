# Golden · 权利要求依附编号与术语出处

规范：`权利要求依附编号与术语出处规范`

## Case 1 — 覆盖失败（应改引用或本条引入）

**输入（节选）：**
```
权1：一种装置，包括壳体和电机。
权3：根据权利要求1所述的装置，其特征在于，所述减速器与所述电机连接。
```
（布局中权3仅引用权1；「减速器」从未在引用链出现）

**期望：** 覆盖=否。处置三选一：A 改引用至首次引入「减速器」的权号；B 本条改为「还包括减速器，所述减速器与…」首次引入；C 调整布局。禁止带病交付。

## Case 2 — 覆盖成功

**输入：**
```
权1：…包括壳体和电机。
权2：根据权利要求1所述的装置，其特征在于，还包括减速器，所述减速器与所述电机连接。
```

**期望：** 「所述减速器」「所述电机」「所述装置」覆盖=是。

## Case 3 — 所述A的B 中子件

**输入：** 权2 引用权1；权1 仅有「箱体」；权2 写「所述箱体的加强筋」但加强筋未在链上引入。

**期望：** 「加强筋」覆盖失败 → 本条先「所述箱体上设有加强筋」或改引用/布局。
