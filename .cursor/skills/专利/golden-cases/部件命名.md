# Golden · 部件命名

规范：`部件命名优化总控` / `部件命名具体优化`

## Case 1 — 非必要性能定语

**输入拟名：** 高强螺栓  
**期望：** 对照表至少给出「螺栓」档；除非高强度本身解决独权技术问题，否则推荐去掉「高强」。

## Case 2 — 同名多物

**输入：** 权1 已有「加劲板」（锚固箱内）；权3 拟再引入另一处也叫「加劲板」（拉杆端）。  
**期望：** 命中同名多物 → 按规则五加归属前缀消歧（如「箱内加劲板」「杆端加劲板」），不得两处裸名并存。

## Case 3 — 交底口语名

**输入：** 交底称「小板」连接两块腹板。  
**期望：** 经口语改写 skill 优先改为自明结构名（如「连接板」）；改不动再用「其中」定义，不直接把「小板」写入独权定稿。
