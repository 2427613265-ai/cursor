# Golden · 部件命名

规范：`部件命名优化总控` / `部件命名具体优化`

## Case 1 — 非必要性能定语

**输入拟名：** 高强螺栓  
**期望：** 对照表至少给出「螺栓」档；除非高强度本身解决独权技术问题，否则推荐去掉「高强」。

## Case 2 — 同名多物

**输入：** 权1 已有「加劲板」（锚固箱内）；权3 拟再引入另一处也叫「加劲板」（拉杆端）。  
**期望：** 命中同名多物 → 按规则五加归属前缀消歧（如「箱内加劲板」「杆端加劲板」），不得两处裸名并存。

## Case 3 — 交底口语名

**输入：** 交底称「小板」连接两块腹板。  
**期望：** 总控 B 型打开口语改写，优先改为自明结构名（如「连接板」），再由总控打开具体优化做两档；改不动标 D 型走就地定义（先前置白话），不直接把「小板」写入独权定稿。

## Case 4 — 名称 vs 句中方位

**输入：** 名称「左侧板」；另有句中「设置在左侧」。  
**期望：** 「左侧板」走命名总控 C 型再开方位规范；「设置在左侧」不进命名总控，直挂方位规范。
