# 创造性答复显著技术进步撰写

本 skill 撰写 2.3/3.3 前须同时 Read `创造性答复共用硬性规则`（语言分轨、效果协同、因果单元以此为准）。

适用：一通 2.3（及 3.3）；二通对应步。有益效果不得在 2.2 逐条中收束。本节禁止出现「技术启示」「结合动机」「非显而易见」「不是显而易见地得到」。

**充分论述（硬性；以因果单元计量，禁止两段作业故事收工）：** 2.3 不是 2.2 之后的短收束。禁止只写「作业过程 1～2 段 + 对比 1 段 + 因此句」。主尺是因果单元，不是段数：

1. 运行单元：写到中间状态（物料/力/位姿/信号走到哪），点到区别特征（N）；本单元不把效果写完。
2. 问题要素单元：2.1 有几个问题要素，此处就有几处可独立指出的「区别特征（N）→中间过程→该要素直接效果」；穿插对比只写**运行停点与直接效果差**，禁止重写 2.2 的启示/动机链。
3. 效果协同单元：少任一区别特征会停在现有技术哪一停点（见共用硬性规则「两种协同」）；禁止写「评价上不能拆开评」。

段数是结果：通常 4～7 段（不含标题与两句收束）；问题要素仅 1 个时不得注水凑段。二通 2.3 同样按因果单元写满，不得因「收束」缩成两段，也不得把第一部分的启示论证改写成效果对比。

## 独权创造性三节中的 2.3 模板与行文规范

**2.3 显著的技术进步（单独成节；有益效果统一写在这里；必须深入）**

> 2.3 修改后的权利要求1的技术方案具有显著的技术进步
>
> 【开篇 1 段：按说明书实施例写清方案如何运行及中间状态，点到区别特征（N）；本段不把效果写完】
> 【随后：每个 2.1 问题要素至少一处可独立指出的因果，写清特征→中间过程→直接效果；穿插对比只写运行停点/效果差，不写有无启示】
> 【再一处：效果协同——缺一停在现有技术哪一停点；需要时再嵌入相对审查员组合方案的效果差】
> 【每一个效果须能追溯到区别特征（N）；不要用“机制/直接效果/逐点对比”等标签把段落切成填表腔】
>
> 因此，修改后的权利要求1相对于现有技术具有显著的技术进步。
>
> 综上所述，修改后的权利要求1具有突出的实质性特点和显著的进步，具备创造性，符合专利法第二十二条第三款的规定。

**深入论述须覆盖的实质层次（层次 1～5 必写可见；写法可灵活，不得缺层）：**

1. **区别特征到运行机制（必写可见）**：按权利要求的数据流、控制流或结构配合顺序，说明方案实际如何工作，写到中间状态（物料/力/位姿/信号走到哪），不得只复述权利要求原文，也不得只写一篇作业故事就停笔。
2. **运行机制到直接效果（必写可见）**：每个 2.1 问题要素都须写清「区别特征（N）→中间状态/过程→该要素下的直接效果」；禁止从特征直接跳到“提高准确性/效率/可靠性”等空泛形容词。问题要素 ≥2 时，**每个要素至少有一段或一段内可独立指出的因果文句**，不得合并成一段把全部要素一笔带过。
3. **特征协同到整体效果（必写可见；此处=效果协同）**：说明各区别特征如何配合，缺少任一特征会退化到现有技术的哪一**停点**；整体效果不是各已知手段的简单叠加。仅有一项区别特征时，本层改为写该特征内部限定如何互相提供前提。禁止写「不能拆成常规手段逐项评价」（那是 2.2 评价协同）。
4. **与 2.1 技术问题呼应（必写可见）**：2.1 各问题要素在本节均须有对应效果回应（可自然融入叙述，**不必**再列“①②③镜像表”或“以下三个方面”式提纲）；缺一即补。
5. **相对现有技术的进步（必写可见）**：结合对比文件1及审查员组合方案，分别说明本申请多实现了什么、避免了什么（运行停点/直接效果差）；对比写入行文，不套“D1如何、D2如何、D3如何”的固定排比，但也不得只写本申请作业、把对比压缩成一句。禁止把 2.2 已写的「无启示/无动机」改写为本节对比。
6. **显著性表述审慎**：有说明书/实施例支持时方可使用较强措辞；无依据不用“预料不到”“唯一”“质变”等营销化或 AI 常用强化词。
7. **证据与支持**：优先引用说明书实施例、附图关系或已记载机理；无数据不编造定量幅度。

**充分论述的最低要求（写完须能逐条勾）：**

1. **运行写到中间状态**：读者能看出方案怎么跑、中间量如何变化，而不是权要换一种说法。
2. **问题要素全覆盖**：2.1 有几个问题要素，2.3 就有几处对应的因果+效果；缺一即补。
3. **因果不跳步**：每处效果都能回溯到区别特征（N）及其中间过程，不能特征直接跳到形容词。
4. **协同/缺一退化**：写明少任一区别特征会回到对比文件已停住的哪一步。
5. **相对现有写具体**：对比文件1自身方案、审查员主张的组合方案各至少有一处嵌入对比，说明其运行停在哪、得不到本申请哪一直接效果；不得改写为启示否定。
6. **只挂独权特征**：从权才能实现的效果不写入 2.3（除非标明进一步限定且与独权效果分开）。
7. **有据**：效果能指向说明书实施例/附图/已记载机理；不编造百分比、倍数或未记载的实验数据。
8. **用语不越权**：本节无「技术启示」「结合动机」「非显而易见」；第1步指定的 I 类比喻不得在本节再用。

**2.3 行文风格（反 AI 腔；硬性）：**

交付正文须读起来像代理人撰写的意见陈述书，而不是自动生成的结构化报告。具体要求：

1. **禁止填表式标签**：不得出现“机制：”“直接效果：”“逐点对比：”“场景价值：”“第一、……（效果命名）”下再套完全同构的四段式。效果用连贯段落叙述即可。
2. **禁止套路起句**：慎用或不用“与对比文件相比，本申请至少在以下 N 个方面产生了……所不能实现的技术效果”“本申请实现了从……到……的质变”等明显的生成式套话。
3. **禁止过度对称**：不要强行拆成三点、五点且每点字数、句式、结构完全一致。结构服从案情，但**不得**用「叙述式」当借口写成 1～2 段长文把全部问题要素一笔带过。
4. **叙述优先于命名**：少用自造效果小标题（如“零改装测试”“分区梯级送风效果”等口号式命名）；直接写技术事实与因果，效果从事实中自然得出。
5. **对比文件穿插写法**：需要对比时，用“相较对比文件1……，本申请……”“对比文件2虽……，但未……”等嵌入句，避免每条效果末尾都机械追加“对比文件1……对比文件2……对比文件3……”三连排比。
6. **场景价值从简**：工程场景一句带过即可（如“适用于连续进料的生物质燃烧炉运行”），不写商业策划式铺陈；无说明书依据不拓展市场、产业链表述。
7. **正文内星号标加粗**：同加粗星号标记规则；禁止填表标签与套路起句。
8. **收束句保留**：节末“因此……具有显著的技术进步”及法22.3符合性收束可保留，这是实务惯例，不算 AI 腔。

**推荐写法（叙述式；优先采用）：**

```text
2.3 修改后的权利要求1的技术方案具有显著的技术进步

【1段：运行机制——按说明书实施例工作流程，写到中间状态，点到区别特征（N）；不得只复述权要，也不得把效果提前堆进本段收完】

【每 2.1 问题要素至少 1 处因果：该要素下，区别特征如何改变中间过程、得到什么直接效果；穿插对比文件1及审查员组合方案的运行停点/效果差。不单独开“对比小节”，不写有无启示】

【1处效果协同——缺任一区别特征会退化到现有技术的哪一停点；整体效果不是已知手段叠加。不写「不能拆开评价」】

【视需要 0～1 段：相对审查员组合方案的整体进步，仍用嵌入句】

因此，修改后的权利要求1相对于现有技术具有显著的技术进步。
综上所述，……（法22.3收束）
```

**禁止浅表写法：**

- 仅把区别特征换一种说法复述后直接写“因此效果更好”；
- 只列“提高精度、降低成本、提升效率”三个结果而不解释技术因果；
- **作业故事两段收工**：只写如何作业 + 一句对比 + 因此句，不展开各问题要素的中间过程→直接效果；
- 两项独权共用一段效果文字、不区分方法执行机制与系统结构协同；
- 把针对性答复中尚未由独权特征支撑的效果搬入 2.3；
- 使用填表式标签（机制/直接效果/逐点对比/场景价值）或高度对称的“第一/第二/第三”四点式；
- 每条效果末尾机械堆砌 D1、D2、D3 三连对比。

**三点式表达骨架（已降级为备选；默认不采用）：**

仅当用户明确要求“分点列效果”或案情效果要素多、叙述式易遗漏时，方可酌情用分点写法——且**不得**使用“机制/直接效果/逐点对比/场景价值”标签，每点用**一整段自然段落**完成，各段句式须有变化。默认优先用上文「叙述式」写法。

若采用分点，须满足：
1. **镜像自检**：效果覆盖 ≥ 2.1 问题要素数，缺一即补。
2. **场景一句即可**：不展开商业策划式铺陈。
3. **两独权分别写效果**：方法独权不得机械复制装置独权效果。

### 二通·第7步 / 一通·第(5+N)步：2.3 显著的技术进步（有益效果统一在此；**单独一步**）

本节必须**单独成节并充分论述**，严格按上文「2.3 模板」「充分论述」「实质层次」「充分论述的最低要求」及「行文风格（反 AI 腔）」输出。标题用：

> 2.3 修改后的权利要求1的技术方案具有显著的技术进步

- 效果挂在区别特征（N）上，与 2.1 技术问题呼应（每个问题要素须有可见因果；**不强制列镜像提纲**）。
- 写入 2.2 各子步针对性答复时**刻意留到本步**的全部有益效果要点。
- 按上文「推荐写法」展开：**以因果单元为准**（运行 + 每问题要素一处因果 + 效果协同）；通常 4～7 段，问题要素仅 1 个时不得注水；**默认不用**填表式三点四段式，也**禁止**改回「1～3 段作业故事」。
- 不用“机制/直接效果/逐点对比/场景价值”等标签；核心效果/法22.3收束句用 `**……**` 标出；只交一份；禁止「建议手动加粗」段。
- 二通不得因骨架写「2.3 收束」而少写因果单元；第一部分已论的是启示/动机，效果因果仍在本步写满，且不得把启示链改写为本步对比。
- 以创造性符合法22.3的收束句结束本节。

**写完自检（缺一则补写后再交）：** 运行写到中间状态；2.1 各问题要素均有中间过程→直接效果；有效果协同/缺一停点；对比文件1与审查员组合方案各有嵌入**效果差**（无启示用语）；无填表标签、无编造数据、无第1步已用比喻。

### 第二项独立权利要求（3.3）

行文风格与因果单元同 2.3。**增量边界见 `创造性答复共用硬性规则`**：共同效果回引 2.3；本步只写第二独权模块/连接/数据流/独有结构带来的中间状态与直接效果，不得机械复制方法独权效果，也不得整节克隆 2.3。不存在第二项独权时，plan 标「不适用」，不得虚构。3.1 / 3.2 分见对应撰写 skill。
