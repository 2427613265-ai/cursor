# 创造性答复总控

创造性答复**唯一入口**。负责一通/二通判定、plan 驱动、按步挂接；**禁止同一次回复写出全文或整节 2.2**。

细则（加粗/硬规则、手法、修改策略、修改说明、2.1/2.2/2.3）已外置到挂接 skill；本总控只保留调度、骨架、其他权利要求节、组装契约与检查清单。

## 挂接总表（每步先 Read 再写）

| 步骤 | 必读 skill |
|------|------------|
| 任一答复正文步 | `创造性答复共用硬性规则` |
| 第1步选法 | `创造性答复反驳手法工具箱` + 共用硬性规则（选法条款） |
| 第2步 修改策略+plan | `创造性答复修改策略` |
| 第3步 修改说明/坚持原权 | `创造性答复修改说明撰写` + 共用硬性规则 |
| 2.1 / 3.1 | `创造性答复区别特征与技术问题撰写` + 共用硬性规则 |
| 2.2 / 3.2 / 二通第一部分 / 2.2收束 | `创造性答复非显而易见性撰写` + 共用硬性规则（手法回查工具箱） |
| 2.3 / 3.3 | `创造性答复显著技术进步撰写` + 共用硬性规则 |
| 其他权利要求 / 组装 | 本总控下文 + 共用硬性规则 |

**硬禁令（摘要；全文见共用硬性规则）：** 第1步不得夹带修改分层与完整 plan；2.2 须「逐条每步一条 + 归纳单独一步」；有益效果归 2.3；只交一份正文并用 `**…**` 标加粗。

## 一通 / 二通分支（第1步先判明）

### 一通｜三段论为主

```text
一、修改说明 / 坚持原权
二、权利要求1具备创造性
   2.1 区别特征 → 实际技术问题 → 与审查员概括对比
   2.2 非显而易见性（审查员结论性观点嵌入；以2.1问题为锚否定启示）
   2.3 显著技术进步（镜像2.1）
三、第二项独权 3.1/3.2/3.3（若有）
四、其他权利要求
```

骨架不可改；引述嵌入 2.2，不另设并列大节。

### 二通及以后｜观点作答为主

```text
一、针对第N次审查意见核心观点逐条作答（主战场）
二、权利要求1具备创造性
   2.1 仍须完整
   2.2/2.3 收束：回引第一部分，补漏启示否定与技术进步镜像
三、第二项独权（若有）
四、其他权利要求
```

禁止二通再写一通同构长文；新争点必须在第一部分正面拆解。

### 逻辑递进（共用，硬性）

可选进阶层级（按事实取舍，非必须写满）：

```text
纠错问题上位 → 客观教导与真实差异 → 针对2.1问题有无启示/动机
  →（事实支持时）思想到方案的鸿沟 →（事实支持时）结合冲突/失败预期
  →（特征间有前提关系时）整体协同
```

每层须能回答「删去本层，上层是否仍缺关键论证」；删上则下失前提才算递进，否则是并列堆砌。

## 分步流程

**一通：** 第1步材料+选法 → 第2步修改策略+plan（同批）→ 第3步修改说明 → 第4步2.1 → 第5步起2.2逐条（每条一步）→ 2.2末归纳 → 2.3 → 第二独权（若有）→ 其他权利要求→组装。

**二通：** 第1步 → 第2步策略+plan → 第3步修改说明（若有）→ 第4步起第一部分逐条 → 2.1 → 2.2收束 → 2.3 → 第二独权 → 其他→组装。

### 各步交付契约（细则在挂接 skill）

| 步 | 交付要点 | 禁止 |
|----|----------|------|
| 1 | 材料表；一通/二通；结论清单；手法组合+递进序+事实支点；独权清点；篇幅倾向一句 | 修改分层表；完整 plan |
| 2 | 修改策略/分层清单 + plan（含2.2子步拆分）同批 | 并回第1步；拆成两步 |
| 3 | 修改说明或坚持原权（四拍体例等见修改说明 skill） | — |
| 2.1 | 编号区别特征+原文；问题要素为主；与审查员概括对比 | 手段写入问题句 |
| 2.2 | 一通：每步仅一条「针对审查意见」；末步仅归纳 | 一次整节2.2 |
| 2.3 | 显著技术进步，镜像2.1；叙述式 | 效果写在逐条答复收束 |

第二项独权：3.1/3.2/3.3 见对应三 skill；无则 plan 标不适用。

## 其他权利要求（本总控保留）

两层：**全体从权**一句依附概括；**仅精选 1～2 项**作「退一步·独立防线」。禁止对每项从权按小独权展开。

**精选优先级：** ①审查员点名 → ②与对比文件差异最立体 → ③补强独权且2.2未充分展开；纯参数/数量/角度默认不选。修改策略步须写明精选权号及理由。

**第一层（必写）：**  
> 新的权利要求【2】至【N】直接或间接引用权利要求1。在权利要求1具备创造性的前提下，上述从属权利要求亦具备创造性，符合专利法第22条第3款。

**第二层（≤2项）：** 统一起句后，每项一段：附加特征含义 → 对比文件未公开/未教导 → 落回该从权具备创造性。不重复2.2/2.3已论内容；须有事实支点。

## 组装

各步确认后再拼接。开场/结尾套话与一通/二通全文骨架见下（未修改则去掉修改说明，用语改「本申请权利要求1」）。

开场：已收到【发文日】第【N】次审查意见通知书（申请号【…】）…答复如下。  
结尾：综上所述…恳请再次给予答复机会…此致。

### 一通骨架（已修改）

```text
开场 → 一、修改说明 → 二、权1创造性（2.1/2.2/2.3）
→ 三、第二独权（若有）→ 四、其他权利要求（依附概括+精选1～2项）→ 结尾
```

### 二通骨架（已修改）

```text
开场 → 一、核心观点逐条作答 → 二、修改说明（可前移）
→ 三、权1创造性（2.1完整；2.2/2.3收束）→ 四、第二独权 → 五、其他权利要求 → 结尾
```

## 检查清单

- [ ] 已判明一通/二通并选用正确骨架  
- [ ] 第1步有手法递进序+事实支点+独权清点；未输出分层/完整plan  
- [ ] 第2步策略与plan同批；并入够立住且保护范围未过窄  
- [ ] 分步完成；2.2已逐条拆步+归纳单独一步  
- [ ] 每项独权均有2.1类区别/问题、非显而易见（含启示否定）、2.3技术进步；未用「同理」带过第二独权  
- [ ] 有益效果只在2.3/3.3；正文只交一份且关键句已`**加粗**`  
- [ ] 其他权利要求仅精选≤2项深入，其余一句依附概括  
- [ ] 细则自检：修改说明体例、2.1/2.2/2.3写法以各挂接 skill + 共用硬性规则为准  

不适用：仅新颖性、超范围、不清楚、得不到说明书支持等且不夹带创造性评述。
