# 创造性答复（拆分建设中）

本目录存放针对专利法第22条第3款（创造性）意见陈述书相关的 skill。

## 阶段 0｜已冻结约定

### 命名（文件夹名 = `name`）

| skill | 角色 |
|-------|------|
| `创造性答复总控` | 入口：一通/二通、plan、按步挂接 |
| `创造性答复共用硬性规则` | 跨步硬规则（加粗、只交一份、问题锚点等） |
| `创造性答复修改策略` | 第2步：修改分层 + 与 plan 同批 |
| `创造性答复修改说明撰写` | 第3步：修改说明 / 坚持原权 |
| `创造性答复区别特征与技术问题撰写` | 2.1 / 3.1 |
| `创造性答复非显而易见性撰写` | 2.2 / 3.2；二通第一部分主战场暂并入本 skill |
| `创造性答复显著技术进步撰写` | 2.3 / 3.3 |
| `创造性答复反驳手法工具箱` | 第1步选法：A–I 手法库 |

### 挂接契约

- 总控与各 skill 之间**只按中文 `name` 挂接**，不写死仓库相对路径。
- 用户要写创造性答复时，**先触发总控**；具体 skill 由总控在对应步骤要求 Read。
- 二通「针对审查员核心观点」主战场与一通 2.2 逐条模板同构，**先不另立 skill**；若后续仍臃肿再拆。

### 过渡期策略

- 旧单体 `意见陈述书撰写`（`name`: `创造性答复意见陈述书撰写`）在阶段 3～5 **仍为跑案入口**；已迁出的横切规则以新 skill 为权威，旧文件仅留跳转指针。
- **阶段 2 已完成**：`创造性答复共用硬性规则`、`创造性答复反驳手法工具箱` 已迁入正文（原文未删减）。
- **阶段 3 已完成**：`创造性答复修改策略`、`创造性答复修改说明撰写` 已迁入正文（原文未删减）。
- 旧单体对应节改为跳转指针；**细则全文以新 skill 为权威副本，迁入时不压缩、不省略条目。**
- 阶段 6：旧文件改为跳转说明或删除；以总控为唯一入口。
