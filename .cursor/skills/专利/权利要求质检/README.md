# 权利要求质检

本分支存放**权利要求质检二级总控**与**具体质检** skill。顶层入口为同级目录下的 **`质检总控`**。

## 层级

```
质检总控（顶层）
  └─ 权利要求质检总控（本分支二级总控）
        ├─ 权利要求书质检
        ├─ 单条权利要求审查
        └─ 权利要求引用结构检查
```

## 已有 skill

| skill | 角色 | 用途 | 典型触发 |
|-------|------|------|----------|
| `质检总控`（`专利/质检总控`） | **顶层总控** | 大类分流至权要/说明书二级总控 | 「质检」「审核」「检查」 |
| `权利要求质检总控` | **二级总控** | 整份/单条判型、编排与收口 | 由顶层分流；权要质检场景 |
| `权利要求书质检` | 具体质检 | **整份**权要实质与布局 | 由权利要求质检总控调用 |
| `单条权利要求审查` | 具体质检 | **单条**六维审查 | 由权利要求质检总控调用 |
| `权利要求引用结构检查` | 具体质检 | 引用结构（平行/串联） | 由权利要求质检总控在整份链路必读调用 |

## 推荐调用关系

```
用户说「质检/审核/检查」
  → 质检总控（大类判型）
      → 权利要求质检总控
            ├─ 整份：形式合规 → 引用结构检查 → 权利要求书质检
            └─ 单条：单条权利要求审查
```

新增相关 skill 时，请在本目录下按照 `.cursor/skills/专利/权利要求质检/<中文名称>/SKILL.md` 添加，并在 `权利要求质检总控` 挂接清单中登记。
