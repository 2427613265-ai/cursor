# 权利要求质检

本分支存放**权利要求书具体质检**相关 skill，与「专利撰写」「说明书质检」并列；质检总入口为同级目录下的 **`质检总控`**。

## 已有 skill

| skill | 角色 | 用途 | 典型触发 |
|-------|------|------|----------|
| `质检总控`（`专利/质检总控`） | **总控入口** | 判型、分流、编排顺序与输出收口 | 「质检」「审核」「检查」 |
| `权利要求书质检` | 具体质检 | **整份**权要实质与布局 | 由总控在整份/全案链路调用 |
| `单条权利要求审查` | 具体质检 | **单条**六维审查 | 由总控在单条链路调用；或「检查权2」等 |
| `权利要求引用结构检查` | 具体质检 | 引用结构（平行/串联） | 由总控在整份链路、形式合规之后必读调用 |

## 推荐调用关系

```
用户说「质检/审核/检查」
  → 质检总控（判型）
      ├─ 整份权要：
      │     权利要求形式合规性规范（必读）
      │  → 权利要求引用结构检查（必读）
      │  → 权利要求书质检（实质四维度 + 按需规范）
      ├─ 单条权要：
      │     单条权利要求审查
      └─ 说明书 / 全案说明书阶段：
            说明书具体实施方式清楚性与逻辑一致性规范
```

新增相关 skill 时，请在本目录下按照 `.cursor/skills/专利/权利要求质检/<中文名称>/SKILL.md` 的结构添加，并在 `质检总控` 挂接清单中登记。
