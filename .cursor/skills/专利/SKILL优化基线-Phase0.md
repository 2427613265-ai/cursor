### 路由效果核查（人工）

对 28 个压缩项逐条判定：**FIX 3 / WATCH 5 / OK 20**。

- 结论：多数不会因瘦身选错入口；正文规则未动，执行效果不取决于 description 长度。
- 真风险已回补：从权节奏词、说明书总控角色、`依附编号` 检索键、若干「撰写或审核」双用触发。
- 误报：启发式把正文控步用语（「禁止一次倾倒」「必须先补参数」）当成入口防护丢失——不影响路由。

优化后同场景少读约 **750+ 行**示例型正文；规则改为摘要五勾，疑点再读规则卡（~100 行）或 `examples.md`。
