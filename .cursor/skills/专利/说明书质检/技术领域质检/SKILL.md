# 技术领域质检（具体质检 skill）

## 适用场景

由 `说明书其他部分质检总控` 在质检技术领域或其他部分全套时调用。

**调用关系：** `质检总控` → `说明书质检总控` → `说明书其他部分质检总控` → 本 skill。细则以 `说明书技术领域部分撰写` 为准。

## 检查清单

- [ ] 是否使用固定句式：「本发明/实用新型涉及XXX技术领域，具体涉及（专利名称）。」
- [ ] 「（专利名称）」是否与权利要求书标题（独权前序主题名称）逐字一致
- [ ] 上位技术领域措辞是否与全篇术语统一（无同义词混用）
- [ ] 上位技术领域范围是否合适（不过窄排除独权覆盖方案，不过宽脱离本案）

## 输出

位置 → 问题 → 修改建议；未发现问题则明确写「技术领域：未发现问题」。
