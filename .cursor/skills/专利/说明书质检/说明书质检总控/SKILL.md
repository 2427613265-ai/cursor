# 说明书质检总控（二级：直接挂接检查 skill）

## 适用场景

- 由顶层 `质检总控` 判定为说明书质检或全案中的说明书阶段后调用；
- 用户明确质检说明书某一段或全文时，经顶层分流至此。

**硬性规则：** 说明书质检二级入口。**直接**按大类挂接撰写规范 / 清楚性专项做核对；顶层入口仍是 `质检总控`。旧名「具体实施例质检总控」「说明书其他部分质检总控」已收束为本 skill（见同目录跳转页）。

**说明：** 撰写过程边写边自查可直接对照各撰写 skill；正式「质检/审核说明书」应经 `质检总控` → 本 skill。

---

## 本 skill 管什么

1. 识别说明书质检范围（其他部分单段 / 实施例专项 / 说明书全文）；
2. 分流并 Read 对应挂接 skill，按其检查清单核对；
3. 全文时收口：其他部分问题 + 实施例问题。

---

## 一、挂接清单（直接挂）

### A. 说明书其他部分（撰写规范兼质检）

| 挂接 skill | 何时 |
|------------|------|
| `说明书技术领域部分撰写` | 质检技术领域；其他部分全套必含 |
| `说明书背景技术部分撰写` | 质检背景技术；全套必含 |
| `说明书技术问题陈述撰写` | 质检技术问题/目的陈述；全套必含 |
| `说明书有益效果撰写` | 质检有益效果；全套必含 |
| `说明书附图说明撰写` | 质检附图说明；全套必含 |
| `说明书摘要撰写` | 质检摘要；全套必含 |

### B. 具体实施例（撰写规范兼质检 + 清楚性专项）

| 挂接 skill | 何时 |
|------------|------|
| `说明书具体实施方式撰写` | 实施例写法；实施例全套**必含** |
| `具体实施方式名词先释义后展开` | 含新定义名词时；全套按需 |
| `具体实施方式补充整体装配方式` | 涉及装配/安装类标记时；全套按需 |
| `未写入权利要求的技术方案在说明书中的编排` | 存在未入权方案时；全套按需 |
| `具体实施方式工作流程与原理撰写` | 交底有主流程/端到端运行时；全套按需 |
| `说明书具体实施方式清楚性与逻辑一致性规范`（须先 Read `清楚性与逻辑一致性共用内核`） | 清楚性专项；实施例全套**必含** |

不另建与撰写规范平行的「××质检」副本。

## 二、先识别大类

| 类型 | 典型说法 | 下一步 |
|------|----------|--------|
| A. 仅其他部分单段 | 「质检技术领域/背景/摘要…」 | 只跑 A 组对应 1 个 skill |
| B. 仅其他部分全套 | 「质检说明书其他部分」 | A 组 1→6 顺序 |
| C. 仅具体实施例 | 「质检具体实施方式」「审核实施例」 | B 组：写法必含 → 按需项 → 清楚性必含 |
| D. 说明书全文 | 「质检说明书」 | 先 B（其他部分全套）→ 再 C（实施例全套）→ 本 skill 汇总 |
| E. 对象不明 | 已进入本总控未点名 | 默认按 D |

建议权要经 `权利要求质检总控` 稳定后再跑；用户只要一段则只跑对应挂接。

## 三、调用顺序

### 其他部分全套

```text
说明书质检总控
  → 技术领域 → 背景技术 → 技术问题 → 有益效果 → 附图说明 → 摘要
  → 按各 skill 检查清单汇总
```

### 实施例全套

```text
说明书质检总控
  → 1. 说明书具体实施方式撰写（必含）
  → 2～5. 名词释义 / 装配 / 未入权 / 工作流程（按需）
  → 6. 说明书具体实施方式清楚性与逻辑一致性规范（必含）
  → 汇总（未命中按需项注明「本轮未检」）
```

### 说明书全文

```text
说明书质检总控
  → 其他部分全套
  → 实施例全套
  → 汇总：其他部分问题 | 实施例问题
```

---

## 四、最低交付要求

- 每条问题：位置 → 问题 → 修改建议。
- **必须** Read 命中的挂接 skill；禁止只凭记忆空审。
- 清楚性专项发现孤岛等勿擅自删除，交用户决定。
- 全文须做两段汇总收口。
