# 说明书质检总控（二级：只挂三级总控）

## 适用场景

- 由顶层 `质检总控` 判定为说明书质检或全案中的说明书阶段后调用；
- 用户明确只要质检/审核说明书时，经顶层总控分流至此。

**硬性规则：本 skill 是说明书质检的二级入口。只分流至三级总控，不直接调用具体质检 skill。顶层入口仍是 `质检总控`。**

**说明：** 撰写过程中的边写边自查，仍可直接对照各撰写/具体质检 skill；正式「质检/审核说明书」应经 `质检总控` → 本 skill → 对应三级总控。

---

## 本 skill 管什么

1. **识别说明书质检大类**（具体实施例 / 其他部分 / 说明书全文）；
2. **分流至三级总控**（`具体实施例质检总控` / `说明书其他部分质检总控`）；
3. **说明书全文时收口**：实施例问题 + 其他部分问题。

---

## 一、挂接清单（仅三级总控）

| 三级总控 | 管什么 | 何时分流 |
|----------|--------|----------|
| `具体实施例质检总控` | 具体实施方式/实施例相关质检的判型、编排与收口；其下再挂具体实施例质检 skill | 「质检具体实施方式」「审核实施例」；说明书全文中的实施例阶段 |
| `说明书其他部分质检总控` | 技术领域、背景技术、发明内容、附图说明、摘要等质检的判型与编排；其下再挂各部分具体质检 skill | 「质检技术领域/背景/摘要…」；说明书全文中的其他部分阶段 |

本 skill **不** 直接挂接：`说明书具体实施方式清楚性与逻辑一致性规范`、各说明书撰写规范 skill 等；具体挂接由对应三级总控负责。

---

## 二、先识别说明书质检大类

| 类型 | 典型用户说法 | 下一步调用 |
|------|--------------|------------|
| A. 具体实施例/具体实施方式 | 「质检具体实施方式」「检查实施例」「审核实施方式」 | **必须** `具体实施例质检总控` |
| B. 说明书其他部分 | 「质检技术领域」「审核背景技术」「检查摘要/附图说明」 | **必须** `说明书其他部分质检总控` |
| C. 说明书全文 | 「质检说明书」「审核整份说明书」 | 先 `说明书其他部分质检总控`，再 `具体实施例质检总控`，最后由本 skill 汇总 |
| D. 对象不明（已进入本总控） | 只说「质检说明书」且未点名段落 | 默认按 C |

建议在权利要求书经 `权利要求质检总控` 稳定后再跑本链路；若用户只要说明书某一段，只跑对应三级总控。

---

## 三、调用顺序

### 链路 A：仅具体实施例

```text
说明书质检总控（本 skill）
  → 具体实施例质检总控
       →（由其再挂具体实施例质检 skill）
```

### 链路 B：仅其他部分

```text
说明书质检总控（本 skill）
  → 说明书其他部分质检总控
       →（由其再挂各部分具体质检 skill）
```

### 链路 C：说明书全文

```text
说明书质检总控（本 skill）
  → 说明书其他部分质检总控
  → 具体实施例质检总控
  → 汇总：其他部分问题 | 实施例问题
```

推荐顺序与说明书撰写顺序一致：先其他部分（技术领域→…→摘要相关），再具体实施方式。

---

## 四、最低交付要求

- **仅 A / 仅 B**：以对应三级总控收口为准。
- **全文 C**：两段三级总控结果之后，由本 skill 做一节汇总收口。

## 五、与上下级 skill 的关系（收口）

| 角色 | skill |
|------|--------|
