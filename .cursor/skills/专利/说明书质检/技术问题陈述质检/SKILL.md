# 技术问题陈述质检（具体质检 skill）

## 适用场景

由 `说明书其他部分质检总控` 在质检发明内容·技术问题或其他部分全套时调用。

**调用关系：** `质检总控` → `说明书质检总控` → `说明书其他部分质检总控` → 本 skill。细则以 `说明书技术问题陈述撰写` 为准。

## 检查清单

- [ ] 是否使用固定句式：「本发明/实用新型的目的在于提供一种（专利名称），以解决现有技术中的XXXX的问题。」
- [ ] 专利名称是否与技术领域、权利要求书标题三处一致
- [ ] XXXX 是否对准独立权利要求实际解决的技术问题
- [ ] 是否未把背景技术中由从权解决的问题一并堆进目的陈述

## 输出

位置 → 问题 → 修改建议；未发现问题则明确写「技术问题陈述：未发现问题」。
