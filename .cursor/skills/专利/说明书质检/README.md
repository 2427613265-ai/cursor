# 说明书质检

本分支存放说明书质检的**二级总控、三级总控与具体质检** skill。顶层入口为同级目录下的 **`质检总控`**。

## 层级

```
质检总控（顶层）
  └─ 说明书质检总控（二级）
        ├─ 具体实施例质检总控（三级）
        │     └─ 说明书具体实施方式清楚性与逻辑一致性规范
        └─ 说明书其他部分质检总控（三级）
              ├─ 技术领域质检
              ├─ 背景技术质检
              ├─ 技术问题陈述质检
              ├─ 有益效果质检
              ├─ 附图说明质检
              └─ 摘要质检
```

## 已有 skill

| skill | 角色 | 用途 |
|-------|------|------|
| `质检总控` | 顶层总控 | 大类分流至权要/说明书 |
| `说明书质检总控` | 二级总控 | 分流至具体实施例 / 其他部分三级总控 |
| `具体实施例质检总控` | 三级总控 | 挂接并编排实施例具体质检 skill |
| `说明书其他部分质检总控` | 三级总控 | 挂接并编排其他部分具体质检 skill |
| `说明书具体实施方式清楚性与逻辑一致性规范` | 具体质检 | 实施例清楚性与逻辑一致性 |
| `技术领域质检` 等 6 个 | 具体质检 | 说明书其他各段质检（细则对照对应撰写规范） |

## 推荐调用关系

```
质检总控
  → 说明书质检总控
      ├─ 具体实施例质检总控
      │     → 说明书具体实施方式清楚性与逻辑一致性规范
      └─ 说明书其他部分质检总控
            → 技术领域质检 → … → 摘要质检
```

说明书全文质检推荐顺序：先其他部分，再具体实施例。

新增相关 skill 时：具体 skill 挂在对应三级总控挂接清单中登记；三级总控挂在 `说明书质检总控` 登记。
