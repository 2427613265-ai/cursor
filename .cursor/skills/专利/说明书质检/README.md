# 说明书质检

本分支存放说明书质检的**二级总控、三级总控**，以及具体实施例侧**不与撰写规范重复**的专用质检 skill。顶层入口为同级目录下的 **`质检总控`**。

质检时优先挂接 `专利撰写/通用/说明书撰写` 下既有撰写规范 skill，按其检查清单核对；仅当存在撰写规范未覆盖的专项（如实施例清楚性与逻辑一致性）时，才保留本分支专用质检 skill。

## 层级

```
质检总控（顶层）
  └─ 说明书质检总控（二级）
        ├─ 具体实施例质检总控（三级）
        │     ├─ 说明书具体实施方式撰写（撰写，兼质检）
        │     ├─ 具体实施方式名词先释义后展开
        │     ├─ 具体实施方式补充整体装配方式
        │     ├─ 未写入权利要求的技术方案在说明书中的编排
        │     ├─ 具体实施方式工作流程与原理撰写
        │     └─ 说明书具体实施方式清楚性与逻辑一致性规范（专用质检，不重复故保留）
        └─ 说明书其他部分质检总控（三级）
              ├─ 说明书技术领域部分撰写
              ├─ 说明书背景技术部分撰写
              ├─ 说明书技术问题陈述撰写
              ├─ 说明书有益效果撰写
              ├─ 说明书附图说明撰写
              └─ 说明书摘要撰写
```

## 已有 skill（本分支）

| skill | 角色 | 用途 |
|-------|------|------|
| `说明书质检总控` | 二级总控 | 分流至具体实施例 / 其他部分三级总控 |
| `具体实施例质检总控` | 三级总控 | 挂接实施例撰写 skill + 清楚性专用质检 |
| `说明书其他部分质检总控` | 三级总控 | 挂接既有撰写规范 skill 做检查 |
| `说明书具体实施方式清楚性与逻辑一致性规范` | 专用质检 | 孤岛/歧义/反例等（撰写 skill 未覆盖） |

## 推荐调用关系

```
质检总控
  → 说明书质检总控
      ├─ 具体实施例质检总控
      │     → 撰写规范 skill（写法/编排）→ 清楚性专用质检
      └─ 说明书其他部分质检总控
            → 对应撰写规范 skill
```

说明书全文质检推荐顺序：先其他部分，再具体实施例。
