# 说明书质检

本分支存放**说明书质检二级总控**与**具体质检** skill。顶层入口为同级目录下的 **`质检总控`**。

## 层级

```
质检总控（顶层）
  └─ 说明书质检总控（本分支二级总控）
        └─ 说明书具体实施方式清楚性与逻辑一致性规范
```

## 已有 skill

| skill | 角色 | 用途 | 典型触发 |
|-------|------|------|----------|
| `质检总控`（`专利/质检总控`） | **顶层总控** | 大类分流至权要/说明书二级总控 | 「质检说明书」等 |
| `说明书质检总控` | **二级总控** | 挂接并编排说明书具体质检 skill | 由顶层分流 |
| `说明书具体实施方式清楚性与逻辑一致性规范` | 具体质检 | 孤岛、自定义术语、模糊语、歧义反例、常识/矛盾 | 由说明书质检总控调用；或撰写时自查 |

## 推荐调用关系

```
质检总控
  → 说明书质检总控
      → 说明书具体实施方式清楚性与逻辑一致性规范
```

建议先完成权利要求书质检（经 `质检总控` → `权利要求质检总控`），再质检说明书具体实施方式。

新增相关 skill 时，请在本目录下按 `<中文名称>/SKILL.md` 添加，并在 `说明书质检总控` 挂接清单中登记。
