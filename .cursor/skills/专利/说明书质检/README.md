# 说明书质检

本分支存放说明书质检的**二级总控**，以及实施例侧**不与撰写规范重复**的专用质检 skill。顶层入口为 **`质检总控`**。

质检时由 `说明书质检总控` **直接**挂接 `专利撰写/通用/说明书撰写` 下既有撰写规范 skill；仅清楚性专项保留本分支专用 skill。旧「三级总控」已收束为跳转页。

## 层级（扁平后）

```
质检总控（顶层）
  └─ 说明书质检总控（二级，直接挂接）
        ├─ 【其他部分】技术领域 / 背景 / 技术问题 / 有益效果 / 附图说明 / 摘要（撰写兼质检）
        └─ 【实施例】具体实施方式撰写… + 说明书具体实施方式清楚性与逻辑一致性规范
```

## 本分支 skill

| skill | 角色 |
|-------|------|
| `说明书质检总控` | 二级总控（唯一编排入口） |
| `具体实施例质检总控` | 旧名跳转 → 说明书质检总控 |
| `说明书其他部分质检总控` | 旧名跳转 → 说明书质检总控 |
| `说明书具体实施方式清楚性与逻辑一致性规范` | 专用质检（须先读共用内核） |

说明书全文推荐顺序：先其他部分，再具体实施例。
