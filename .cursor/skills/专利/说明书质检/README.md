# 说明书质检

本分支存放**说明书具体质检**相关 skill。质检总入口为同级目录下的 **`质检总控`**；本目录 skill 由总控在「说明书 / 全案」链路中调用，撰写过程中也可就地自查。

## 已有 skill

| skill | 角色 | 用途 | 典型触发 |
|-------|------|------|----------|
| `质检总控`（`专利/质检总控`） | **总控入口** | 判型后分流至本目录具体 skill | 「质检说明书」「审核具体实施方式」 |
| `说明书具体实施方式清楚性与逻辑一致性规范` | 具体质检 | 孤岛、自定义术语、模糊语、歧义反例、常识/矛盾 | 由总控调用；或撰写时自查 |

## 推荐调用关系

```
质检总控
  →（说明书 / 全案说明书阶段）
      说明书具体实施方式清楚性与逻辑一致性规范
```

建议先完成权利要求书质检（经 `质检总控` 整份权要链路），再质检说明书具体实施方式。

新增相关 skill 时，请在本目录下按 `<中文名称>/SKILL.md` 添加，并在 `质检总控` 挂接清单中登记。
