# 附图说明质检（具体质检 skill）

## 适用场景

由 `说明书其他部分质检总控` 在质检附图说明或其他部分全套时调用。

**调用关系：** `质检总控` → `说明书质检总控` → `说明书其他部分质检总控` → 本 skill。细则以 `说明书附图说明撰写` 为准。

## 检查清单

- [ ] 是否仅依据交底/已有附图撰写，未凭空编造新图
- [ ] 图的数量、顺序、内容是否与已有附图一致
- [ ] 标点排版是否符合模版（图与图之间「；」、最后一张「。」；附图标记说明另段以「附图标记说明：」开头）
- [ ] 附图标记是否统一、不重号；同对象跨图尽量同号
- [ ] 标记名称是否优先与当前权利要求术语一致
- [ ] 方法类发明第一张附图是否为方法流程图（若适用）
- [ ] 核心发明点若无对应附图，是否已提醒需向发明人补充（而非自行编图）

## 输出

位置 → 问题 → 修改建议；未发现问题则明确写「附图说明：未发现问题」。
