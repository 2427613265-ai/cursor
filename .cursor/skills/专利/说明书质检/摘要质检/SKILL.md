# 摘要质检（具体质检 skill）

## 适用场景

由 `说明书其他部分质检总控` 在质检摘要或其他部分全套时调用。

**调用关系：** `质检总控` → `说明书质检总控` → `说明书其他部分质检总控` → 本 skill。细则以 `说明书摘要撰写` 为准。

## 检查清单

- [ ] 说明书摘要全文（含标点）是否不超过 300 字
- [ ] 摘要中的技术领域表述是否与说明书「技术领域」部分用词一致
- [ ] 是否概括了独立权利要求的核心技术方案
- [ ] 是否点出主要技术效果，且与独权实际解决的技术问题相对应
- [ ] 专利名称/主题名称是否与权利要求书标题一致

## 输出

位置 → 问题 → 修改建议；未发现问题则明确写「摘要：未发现问题」。
