# 具体实施例质检总控（三级总控：挂撰写 skill + 保留不重复的专用质检）

## 适用场景

- 由 `说明书质检总控` 判定为具体实施例/具体实施方式质检，或说明书全文中的实施例阶段后调用；
- 用户明确「质检具体实施方式 / 审核实施例」时，经 `质检总控` → `说明书质检总控` 分流至此。

**硬性规则：本 skill 是具体实施例质检的三级入口。质检时优先 Read 并遵循下属挂接的撰写规范 skill（按其检查清单核对）；清楚性/逻辑一致性等撰写 skill 未覆盖的专项，再调用保留的专用质检 skill。不另建与撰写规范平行重复的「××质检」副本。不越级充当顶层或说明书二级总入口。**

**说明：** 撰写过程中的边写边自查，仍可直接对照各撰写/专用质检 skill；正式质检应经上级总控进入本 skill。

---

## 本 skill 管什么

1. **识别实施例质检范围**（结构写法 / 名词释义 / 装配 / 未入权 / 工作流程 / 清楚性逻辑 / 全套）；
2. **分流并编排**下属挂接 skill；
3. **收口输出**：按命中 skill 的检查清单汇总；发现孤岛等勿擅自删除，交用户决定。

---

## 一、挂接清单

### A. 既有撰写规范 skill（主挂接；兼作质检核对）

位于 `专利/专利撰写/通用/说明书撰写/具体实施例/`：

| 挂接 skill | 管什么 | 何时分流 |
|------------|--------|----------|
| `说明书具体实施方式撰写` | 复述权利要求 →「具体而言」展开、从权写法、附图标记引用等 | 实施例结构/写法质检；全套必含 |
| `具体实施方式名词先释义后展开` | 新名词是否在复述后、展开前先释义 | 含新定义名词时；全套按需 |
| `具体实施方式补充整体装配方式` | 权要未写装配关系时是否补充整体装配、安装类标记是否有呼应 | 涉及装配/安装类附图标记时；全套按需 |
| `未写入权利要求的技术方案在说明书中的编排` | 未入权方案是否就近或文末编排、有无遗漏询问 | 存在未入权补充方案时；全套按需 |
| `具体实施方式工作流程与原理撰写` | 工作流程/原理段是否单独成段、术语是否对齐权要 | 交底有主流程/多通道/端到端运行时；全套按需 |

### B. 专用质检 skill（保留：与撰写规范不重复）

| 具体 skill | 管什么 | 何时分流 |
|------------|--------|----------|
| `说明书具体实施方式清楚性与逻辑一致性规范` | 孤岛特征、人为定义术语、模糊用语、歧义与反例、清楚简洁、常识/前后矛盾 | 实施例清楚性/逻辑质检；**全套必含**（撰写 skill 不覆盖此专项） |

**为何保留 B：** 各撰写 skill 管「怎么写结构/顺序/编排」；清楚性规范管「写完后逻辑是否自洽、有无孤岛/歧义/反例」。二者不重复；撰写 skill 内亦多处交叉引用该清楚性规范，故保留为专用挂接，不删、不另造平行副本。

## 二、先识别对象

| 类型 | 典型用户说法 | 下一步调用 |
|------|--------------|------------|
| A. 实施例写法/结构 | 「检查实施例复述展开」「质检具体实施方式写法」 | `说明书具体实施方式撰写` |
| B. 名词释义顺序 | 「检查名词释义」 | `具体实施方式名词先释义后展开` |
| C. 整体装配 | 「检查装配补充」 | `具体实施方式补充整体装配方式` |
| D. 未入权编排 | 「检查未入权方案」 | `未写入权利要求的技术方案在说明书中的编排` |
| E. 工作流程与原理 | 「检查工作流程段」 | `具体实施方式工作流程与原理撰写` |
| F. 清楚性与逻辑 | 「检查孤岛/歧义」「实施例清楚性」 | `说明书具体实施方式清楚性与逻辑一致性规范` |
| G. 实施例全套 | 「质检具体实施方式」「审核实施例」 | 先 A（必含）→ 按需 B～E → 最后 F（必含） |
| H. 对象不明 | 已进入本总控未点名 | 默认按 G |

建议在权要经 `权利要求质检总控` 稳定、且说明书其他部分已基本定稿后再跑本链路；用户只要实施例，仍可只跑本总控。

## 三、调用顺序

### 单段/单主题链路

```text
具体实施例质检总控（本 skill）
  → 命中的某一个挂接 skill（按其检查清单核对）
```

### 全套链路（推荐）

```text
具体实施例质检总控（本 skill）
  → 1. 说明书具体实施方式撰写              （必含：复述+展开结构）
  → 2. 具体实施方式名词先释义后展开        （按需）
  → 3. 具体实施方式补充整体装配方式        （按需）
  → 4. 未写入权利要求的技术方案在说明书中的编排（按需）
  → 5. 具体实施方式工作流程与原理撰写      （按需）
  → 6. 说明书具体实施方式清楚性与逻辑一致性规范（必含：清楚性专项）
  → 按各 skill 检查清单汇总收口
```

## 四、最低交付要求

- 每条问题写清：位置 → 问题 → 修改建议。
- 全套时按上述顺序分节；未跑到的按需项注明「本轮未检（条件未命中）」。
- **必须**打开并遵循命中 skill；禁止只凭记忆空审。
- 清楚性规范下发现孤岛等勿擅自删除，说明疏漏或不必写入后交用户决定。
