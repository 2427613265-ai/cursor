# 具体实施例质检总控（三级总控：挂具体实施例质检 skill）

## 适用场景

- 由 `说明书质检总控` 判定为具体实施例/具体实施方式质检，或说明书全文中的实施例阶段后调用；
- 用户明确「质检具体实施方式 / 审核实施例」时，经 `质检总控` → `说明书质检总控` 分流至此。

**硬性规则：本 skill 是具体实施例质检的三级入口。具体检查由本 skill 分流调用下属具体质检 skill；不直接替代其细则。不越级充当顶层或说明书二级总入口。**

**说明：** 撰写过程中对具体实施方式的边写边自查，仍可直接对照下属具体 skill；正式质检应经上级总控进入本 skill。

---

## 本 skill 管什么

1. **确认实施例质检范围**（当前默认：具体实施方式清楚性与逻辑一致性；后续若增挂其他实施例质检具体 skill，由本 skill 判型分流）；
2. **分流并编排**下属具体质检 skill；
3. **收口输出**：按下属具体 skill 的检查清单汇总；发现孤岛等勿擅自删除，交用户决定。
