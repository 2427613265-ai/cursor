# 有益效果质检（具体质检 skill）

## 适用场景

由 `说明书其他部分质检总控` 在质检发明内容·有益效果或其他部分全套时调用。

**调用关系：** `质检总控` → `说明书质检总控` → `说明书其他部分质检总控` → 本 skill。细则以 `说明书有益效果撰写` 为准。

## 检查清单

- [ ] 是否主要使用「与现有技术相比，本发明/实用新型的有益效果在于：……」一类规范结构
- [ ] 是否只写独立权利要求核心技术特征直接带来的效果
- [ ] 是否与技术问题陈述中的问题一一镜像对应（不答非所问、不超纲）
- [ ] 是否未把从权才能实现的效果混入独权有益效果（若提及从权效果，是否已用「进一步地/优选」等明确隔离）

## 输出

位置 → 问题 → 修改建议；未发现问题则明确写「有益效果：未发现问题」。
