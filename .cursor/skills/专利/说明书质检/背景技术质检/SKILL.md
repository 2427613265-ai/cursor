# 背景技术质检（具体质检 skill）

## 适用场景

由 `说明书其他部分质检总控` 在质检背景技术或其他部分全套时调用。

**调用关系：** `质检总控` → `说明书质检总控` → `说明书其他部分质检总控` → 本 skill。细则以 `说明书背景技术部分撰写` 为准。

## 检查清单

- [ ] 是否按四段式展开：具体使用场景 → 现有技术客观描述 → 「然而」归纳问题 → 收尾句
- [ ] 第一段场景是否具体（非空泛「在XX领域中」）
- [ ] 第二段是否只客观描述现有技术、未提前夹带不足评价
- [ ] 现有技术抽象层级是否「粗一档」（未把本申请创新骨架写成现有技术）
- [ ] 是否未编造未经核实的专利文号/公告号
- [ ] 第三段是否用「然而」第一次归纳 2～3 个与权要实际问题对应的技术问题
- [ ] 收尾是否使用规范句式（「鉴于此，有必要提出（专利名称）以解决或至少缓解上述缺陷。」一类）
- [ ] 收尾中的专利名称是否与权要标题一致

## 输出

位置 → 问题 → 修改建议；未发现问题则明确写「背景技术：未发现问题」。
