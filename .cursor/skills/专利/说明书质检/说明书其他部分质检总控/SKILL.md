# 说明书其他部分质检总控（三级总控：挂既有撰写 skill 做检查）

## 适用场景

- 由 `说明书质检总控` 判定为说明书其他部分质检，或说明书全文中的「非具体实施例」阶段后调用；
- 用户明确质检技术领域、背景技术、发明内容、附图说明或摘要时，经上级总控分流至此。

**硬性规则：本 skill 是说明书其他部分质检的三级入口。质检时直接 Read 并遵循下属挂接的撰写规范 skill（其内已含固定句式与检查清单），按清单核对；不另建平行的「××质检」具体 skill，也不越级充当顶层或说明书二级总入口。**

**说明：** 具体实施方式/实施例不归本总控，改走 `具体实施例质检总控`。

---

## 本 skill 管什么

1. **识别要质检的说明书段落**（技术领域 / 背景技术 / 技术问题 / 有益效果 / 附图说明 / 摘要 / 其他部分全套）；
2. **分流并调用**对应撰写规范 skill，按其检查清单做质检；
3. **收口输出**：按命中 skill 的检查清单汇总问题。

---

## 一、挂接清单（既有撰写规范 skill）

| 挂接 skill（撰写规范，兼作质检核对） | 管什么 | 何时分流 |
|--------------------------------------|--------|----------|
| `说明书技术领域部分撰写` | 技术领域句式、专利名称与权要标题一致、术语与范围 | 质检技术领域；其他部分全套必含 |
| `说明书背景技术部分撰写` | 四段结构、现有技术客观描述、「然而」问题归纳、收尾句式等 | 质检背景技术；其他部分全套必含 |
| `说明书技术问题陈述撰写` | 目的陈述句式、XXXX 与独权问题对应（非背景问题堆砌） | 质检发明内容·技术问题；其他部分全套必含 |
| `说明书有益效果撰写` | 仅独权效果、与技术问题镜像对应、不混从权效果 | 质检发明内容·有益效果；其他部分全套必含 |
| `说明书附图说明撰写` | 依据已有附图、标点排版、标记与术语、缺图提醒等 | 质检附图说明；其他部分全套必含 |
| `说明书摘要撰写` | ≤300 字、技术领域一致、概括独权方案与主要效果 | 质检摘要；其他部分全套必含 |

以上 skill 位于 `专利/专利撰写/通用/说明书撰写/` 下；本总控只做分流与编排，检查细则以各撰写 skill 正文为准。

## 二、先识别对象

| 类型 | 典型用户说法 | 下一步调用 |
|------|--------------|------------|
| A. 技术领域 | 「质检技术领域」 | `说明书技术领域部分撰写` |
| B. 背景技术 | 「质检背景技术」 | `说明书背景技术部分撰写` |
| C. 技术问题陈述 | 「质检技术问题」「检查目的陈述」 | `说明书技术问题陈述撰写` |
| D. 有益效果 | 「质检有益效果」 | `说明书有益效果撰写` |
| E. 附图说明 | 「质检附图说明」 | `说明书附图说明撰写` |
| F. 摘要 | 「质检摘要」 | `说明书摘要撰写` |
| G. 其他部分全套 | 「质检说明书其他部分」；或说明书全文中的本阶段 | 按推荐顺序跑 A→F |
| H. 对象不明 | 已进入本总控未点名 | 默认按 G |

## 三、调用顺序

### 单段链路

```text
说明书其他部分质检总控（本 skill）
  → 命中的某一个撰写规范 skill（按其检查清单核对）
```

### 全套链路（推荐顺序，对齐撰写顺序）

```text
说明书其他部分质检总控（本 skill）
  → 1. 说明书技术领域部分撰写
  → 2. 说明书背景技术部分撰写
  → 3. 说明书技术问题陈述撰写
  → 4. 说明书有益效果撰写
  → 5. 说明书附图说明撰写
  → 6. 说明书摘要撰写
  → 按各 skill 检查清单汇总收口
```

## 四、最低交付要求

- 每条问题写清：位置（段落）→ 问题 → 修改建议。
- 全套时按上述 1～6 顺序分节输出；未跑到的段落注明「本轮未检」。
- **必须**打开并遵循对应撰写 skill，禁止只凭记忆空审。
