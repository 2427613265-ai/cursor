# 说明书其他部分质检总控（三级总控：挂各部分具体质检 skill）

## 适用场景

- 由 `说明书质检总控` 判定为说明书其他部分质检，或说明书全文中的「非具体实施例」阶段后调用；
- 用户明确质检技术领域、背景技术、发明内容、附图说明或摘要时，经上级总控分流至此。

**硬性规则：本 skill 是说明书其他部分质检的三级入口。具体检查由本 skill 分流调用下属具体质检 skill；不直接替代其细则。不越级充当顶层或说明书二级总入口。**

**说明：** 具体实施方式/实施例不归本总控，改走 `具体实施例质检总控`。

---

## 本 skill 管什么

1. **识别要质检的说明书段落**（技术领域 / 背景技术 / 技术问题 / 有益效果 / 附图说明 / 摘要 / 其他部分全套）；
2. **分流并编排**下属具体质检 skill；
3. **收口输出**：按命中具体 skill 的检查清单汇总。

---

## 一、挂接清单（具体质检 skill）

| 具体 skill | 管什么 | 何时分流 |
|------------|--------|----------|
| `技术领域质检` | 技术领域句式、专利名称与权要标题一致、术语与范围 | 质检技术领域；其他部分全套必含 |
| `背景技术质检` | 四段结构、现有技术客观描述、「然而」问题归纳、收尾句式等 | 质检背景技术；其他部分全套必含 |
| `技术问题陈述质检` | 目的陈述句式、XXXX 与独权问题对应（非背景问题堆砌） | 质检发明内容·技术问题；其他部分全套必含 |
| `有益效果质检` | 仅独权效果、与技术问题镜像对应、不混从权效果 | 质检发明内容·有益效果；其他部分全套必含 |
| `附图说明质检` | 依据已有附图、标点排版、标记与术语、缺图提醒等 | 质检附图说明；其他部分全套必含 |
| `摘要质检` | ≤300 字、技术领域一致、概括独权方案与主要效果 | 质检摘要；其他部分全套必含 |

细则核对时，各具体质检 skill 应对照同名撰写规范 skill（如 `说明书技术领域部分撰写`）执行；本总控只做分流与编排。

## 二、先识别对象

| 类型 | 典型用户说法 | 下一步调用 |
|------|--------------|------------|
| A. 技术领域 | 「质检技术领域」 | `技术领域质检` |
| B. 背景技术 | 「质检背景技术」 | `背景技术质检` |
| C. 技术问题陈述 | 「质检技术问题」「检查目的陈述」 | `技术问题陈述质检` |
| D. 有益效果 | 「质检有益效果」 | `有益效果质检` |
| E. 附图说明 | 「质检附图说明」 | `附图说明质检` |
| F. 摘要 | 「质检摘要」 | `摘要质检` |
| G. 其他部分全套 | 「质检说明书其他部分」；或说明书全文中的本阶段 | 按推荐顺序跑 A→F |
| H. 对象不明 | 已进入本总控未点名 | 默认按 G |

## 三、调用顺序

### 单段链路

```text
说明书其他部分质检总控（本 skill）
  → 命中的某一个具体质检 skill
```

### 全套链路（推荐顺序，对齐撰写顺序）

```text
说明书其他部分质检总控（本 skill）
  → 1. 技术领域质检
  → 2. 背景技术质检
  → 3. 技术问题陈述质检
  → 4. 有益效果质检
  → 5. 附图说明质检
  → 6. 摘要质检
  → 按各具体 skill 清单汇总收口
```

---

## 四、最低交付要求

- 每条问题写清：位置（段落）→ 问题 → 修改建议。
- 全套时按上述 1～6 顺序分节输出；未跑到的段落注明「本轮未检」。
- 细则以各具体质检 skill 及其对照的撰写规范为准。
