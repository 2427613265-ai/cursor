## 对准新问题的拟保留特征骨架（第二版）

| 保留（必要取向） | 理由（相对新问题） |
|------------------|--------------------|
| 全节点基准定位模型 + 节点特征向量 | 从模型感知视角看节点，才能谈「与感知需求匹配」 |
| 按相似度划分特征簇 | 识别冗余/互补感知结构的基础 |
| 信息盲区（高贡献且缺覆盖）→ 候选监测点集合 | 把布点对准感知缺口，并收缩搜索空间（匹配+可实施） |
| 在信息盲区约束下按定位误差减少量增量选点，并加点后重评 | 动态匹配定位效果，避免全网盲目试探 |
| 停止条件（数量上限或精度阈值）→ 得到优化后监测点集合 | 形成完整可实施闭环 |
| 输出布设方案（位置、数量） | 方法产物；验证环节可概括或下从权 |

| 拟删/下放（相对第一版） | 去向 |
|--------------------------|------|
| S1中过细的「采集…绑定」工序叙事 | 概括进「得到全节点基准定位模型」或从权S11 |
| 初评「若不达标才优化」的完整分支 | 可保留为可选入口；非匹配问题之唯一必要，第二版可简化为「在初始集合基础上优化」或保留简判 |
| S4「更新仿真并验证」的独立重训验收 | 对「匹配+可实施」非独有必要；可并入输出步一句或下从权S41 |
| 布设优先级 | 从权 |
| 冗余检测、EPANET、谱聚类、维数等 | 从权（第一版已未入主文的维持） |
