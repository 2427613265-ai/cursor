# 用户稿补全 · 当前独权工作稿

按用户给出的 S1～S5 骨架补全；不另起一套步骤。补的是：S2 输出口径、S3 关键监测区引入、S4 节点贡献度含义、S5 寻优动作与终止判断、S1 终止条件来源。

---

## 补全后的独立权利要求

1. 一种面向漏损定位的管网压力监测点布设方法，其特征在于，包括以下步骤：

S1：获取目标管网、所述目标管网的初始压力监测点的布设方案，并预先设定终止条件；

S2：获取漏损定位模型，所述漏损定位模型以所述目标管网中各节点的压力数据为输入、漏损坐标为输出；

S3：基于所述漏损定位模型对所述各节点划分特征簇，并基于所述漏损定位模型确定各特征簇对漏损定位的特征簇贡献度，基于所述特征簇贡献度确定所述目标管网的关键监测区；

S4：根据所述关键监测区以及所述初始压力监测点的布设方案，确定候选监测节点，并基于所述漏损定位模型确定各候选监测节点的节点贡献度；

S5：以所述初始压力监测点的布设方案为当前布设方案，基于所述特征簇贡献度以及所述节点贡献度对所述目标管网进行监测点动态增量寻优；判断是否满足所述终止条件，若否，则根据所述特征簇贡献度确定当前优先的关键监测区，在所述当前优先的关键监测区内按照所述节点贡献度从所述候选监测节点中选取节点加入所述当前布设方案，再次进行本步骤所述判断；若是，则将所述当前布设方案作为优化后的压力监测点布设方案。

## 相对你原句补了什么、为什么

| 位置 | 你原来的写法 | 补全 | 原因 |
|------|----------------|------|------|
| S1 | 只获取管网和初始布设 | 增加「预先设定终止条件」 | S5 要用终止条件，权要里必须先有来源 |
| S2 | 「对应节点的漏损坐标」 | 改为「漏损坐标」 | 模型输出的是漏损点坐标，不是每个节点各有一个漏损坐标 |
| S2 | 模型 I/O 写在「获取」里一长串 | 先获取模型，再用一句写清输入输出 | 读起来更清楚，含义不变 |
| S3 | 已有：分簇 → 特征簇贡献度 → 关键监测区 | 基本保持；「确定关键监测区」即用贡献度高的簇作为关键监测区 | 关键监测区＝贡献高、对定位重要的区域，不是「没装表」 |
| S4 | 候选节点 + 节点贡献度 | 保持你的两句；节点贡献度在寻优里用 | 具体「加入后误差减少量」可放从权，以免独权过长 |
| S5 | 写到「当满足预设的终止条件时」断开 | 禁止「当…时」；改成「判断是否满足…若否…若是…」；补上寻优动作和最终产物 | 循环必须写进同一步；独权要有输出 |

S5 里「动态增量寻优」不再是空话，拆成可执行的两层：先按**特征簇贡献度**定当前优先的关键监测区，再在该区内按**节点贡献度**选点加入当前布设，直到终止。

## 接下来怎么写（建议顺序）

**独权到此可以收住。** S5「若是，则将当前布设方案作为优化后的压力监测点布设方案」就是全文结束，不必再接验证、出施工清单。

**从权按步补细节（一组一事）：**

| 挂靠 | 从权写什么 |
|------|------------|
| S1 | 终止条件＝达到监测点数量上限，或定位精度达到预设要求；初始布设可为空（从零布设） |
| S2 | 漏损定位模型为全节点模型；压力数据为时序；模型种类（TCN 等）；如何训练/加载 |
| S3 | 如何从模型得到节点特征再聚类；特征簇贡献度如何算（只用该簇定位的误差，或拿掉该簇后误差升高） |
| S4 | 如何结合初始布设筛候选（例如关键监测区内尚未布置监测点的节点）；节点贡献度＝加入当前布设后漏损定位误差的减少量 |
| S5 | 每加入一点后是否重算节点贡献度；关键监测区何时切换到下一个（交底的盲区级—节点级排程） |

说明书里用一句对照即可：交底所称信息盲区，即本权利要求的关键监测区。

若要把节点贡献度的定义写进独权 S4（更清楚、稍窄一点），可用：

所述节点贡献度为将所述候选监测节点加入当前布设方案后漏损定位误差的减少量。
