## 核心区别（一小撮 · 不变量）

相对上述惯常、真正做功且撑住声称问题的，收成 **三条骨架**（不是十五条全中）：

### 区别一：用定位模型的节点级内部特征作为布点依据

| 项 | 内容 |
|----|------|
| 对应第2步 | **A5（仅「全节点基准模型作为特征来源」这一角色）+ B1** |
| 相对现有 | 静态水力指标 / 管网物理聚类不读模型内部表征；已有 TCN 定位也不倒过来指导布点 |
| 支撑声称问题 | **脱节/适配**：布点对准的是模型眼里的非线性时空响应，而不是管段重要性或水力敏感度 |
| 三问 | 换成 LSTM/Transformer 等「能输出节点级高维特征的端到端定位模型」后，I/O 仍成立 → **TCN / 末层卷积 / 128维是路径**；必须留下的是「从全节点定位基准模型取出节点级内部特征」 |
| 口径 | **核心区别**。A5 里「用 TCN 做漏损坐标回归」本身是惯常，不单独当区别 |

### 区别二：按内部特征划分特征簇，识别高贡献且未覆盖的信息盲区，并把后续候选限制在盲区内

| 项 | 内容 |
|----|------|
| 对应第2步 | **B3 + B6（B4/B5 为度量）+ B7** |
| 相对现有 | 无「面向模型内部表征的盲区诊断」；全局增量在全网节点上遍历 |
| 支撑声称问题 | **脱节/适配**（补模型真正缺的信息）+ **计算量**（搜索空间从全网压到盲区）+ 背景「盲区/冗余」 |
| 三问 | 谱聚类、余弦矩阵、簇数 7、196→32 是路径。不变量是：同簇≈对模型贡献冗余；用簇对端到端定位的贡献（或混淆）**并且**当前缺乏压力表覆盖，标出信息盲区；后续只在盲区内选点 |
| B4 口径取舍 | **不把「仅以该簇节点训练 TCN 的平均误差」钉成唯一核心公式。** 不变量写「按簇对定位的贡献/混淆程度识别高贡献簇」。B4「只拿该簇来训」、实施例「拿掉该簇传感器后误差更高」、背景「定位混淆程度」视为**度量路径**，第4步用概括准则，具体公式进从权。B6「当前无表覆盖」与贡献高**同时**构成盲区，属不变量（否则已覆盖的高贡献簇会被重复当盲区，压缩搜索的逻辑被抽空） |

### 区别三：在盲区约束下，以定位误差减少量为节点贡献度，做盲区级—节点级动态增量选点

| 项 | 内容 |
|----|------|
| 对应第2步 | **C1 + C3 + C5**（C2 是这三项的总称） |
| 相对现有 | SFFS 等全局增量也用「加一点看误差降多少」，但无特征簇/盲区约束，也不先按盲区排序再在簇内定向选点 |
| 支撑声称问题 | **脱节/适配**（选点目标仍是端到端定位误差）+ **计算量 / 冗余**（外循环换盲区、内循环在盲区内选，避免同簇堆点） |
| 三问 | 「至少一个表覆盖即降优先级」、边际贡献衰减率、感知充分系数、K 次冗余回溯，均为切换/控表**路径**。不变量是：外循环按盲区整体贡献度排优先级并切换；内循环在当前盲区内按节点贡献度选点；优先补尚未覆盖的盲区 |
| 口径 | C1 单独对 SFFS **不够成区别**，必须与区别二的盲区约束绑在一起才是本案增量。第4步不得只写「按误差减少量增量加表」而丢掉盲区级—节点级 |

## 拟确认的核心区别清单（第4步最小集必须包含）

1. **从全节点端到端漏损定位基准模型提取节点级内部特征**（表征各节点对漏损的非线性时空响应）；定位模型具体种类、取自哪一层、维数不钉死。  
2. **按所述内部特征的相似性将节点划分为特征簇**（同簇对定位模型的信息贡献存在冗余）。  
3. **将定位贡献高且当前缺乏压力表覆盖的特征簇作为信息盲区，后续候选节点取自信息盲区内部**（贡献/混淆的具体计算公式不钉死）。  
4. **在信息盲区约束下动态增量选点：** 节点贡献度＝加入当前布设后全网定位误差的减少量；外循环按盲区整体贡献度确定优先补哪一盲区，内循环在该盲区内按节点贡献度选点；优先覆盖尚未被压力表覆盖的信息盲区。

第4步另需补的是使方案可实施的**必要支撑**（例如获得管网与初始布设、获得全节点漏损—压力样本、得到所述基准模型、增量循环的起止），**不得**把 A3 工具链、C8、C4、谱聚类等灌进第一版。
