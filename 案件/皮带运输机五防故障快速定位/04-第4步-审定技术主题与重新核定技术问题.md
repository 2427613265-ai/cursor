# 【第 4 步 / 共 9 步】审定技术主题并重新核定技术问题

阶段：结构类独权撰写。反推对象仅为已交付的第一版独权全文。本步不写第二版。申请类型：**实用新型**。

## 1. 反推对象（第一版独权）

1. 一种皮带运输机五防故障定位系统，其特征在于，包括多只保护装置和采集单元；
各所述保护装置具有信号输出端；
所述采集单元具有多条相互独立的输入通道；
各所述保护装置的信号输出端分别连接至不同的所述输入通道；
以用于区分各所述保护装置安装点的标识为点位标识，所述采集单元配置有各所述输入通道与皮带标识、所述点位标识及故障类型的对应关系；
所述采集单元被配置为根据状态发生变化的所述输入通道及所述对应关系，给出包含皮带标识、点位标识及故障类型的定位信息。

全部特征：多只保护装置、信号输出端、采集单元、相互独立的输入通道、一对一接入、皮带标识 / 点位标识 / 故障类型的对应关系、据此给出定位信息。不含隔离生产主控、远程 IO、环网、消抖、HMI、五种保护名称、分级联锁、预警。

## 2. 原技术主题 → 审定后的技术主题

| | 表述 |
|--|------|
| 交底标题 | 一种应用于皮带运输机五防故障快速定位 |
| 第一版前序 | 一种皮带运输机五防故障定位系统 |
| **审定后的技术主题** | **一种带式输送机保护装置故障定位系统** |

处理：过窄处放宽一层，过宽处收住。

- **去掉「快速」：** 效果词，第一版已删，主题不再带回。
- **去掉「五防」：** 第一版正文只有保护装置、故障类型，没有把跑偏 / 打滑 / 撕裂 / 堵料 / 拉绳五种都写成必要构成。主题钉死「五防」会把只有部分保护回路、或同类保护开关的实施方式排除。五防分列进从权。
- **皮带运输机 → 带式输送机：** 同一客体的规范称谓；交底应用领域已写冶金、矿山、港口、电力等带式输送机。特征不依赖烧结、炼铁、360㎡ 产线。
- **补「保护装置」：** 第一版实际定位的是保护装置动作点，不是任意工艺故障。
- **不放到「输送设备 / 工业监测系统」：** 第一版对应关系里写有皮带标识，特征能合理读出的是带式输送机上的保护装置，不是任意设备诊断。再宽一层要把皮带标识改成设备标识，已接近另一概括，实用新型对比领域较窄，本步不跨。

特征依据：一对一接入与通道—身份对应关系不依赖烧结工况；身份三项中的皮带标识把主题锚在带式输送机；保护装置 + 故障类型撑住「保护装置故障定位」，撑不住「任意故障诊断」。

## 3. 申请类型对宽窄的影响

本案是**实用新型**。创造性评价可考虑的对比技术领域较窄，主题过宽（如「一种故障定位系统」）容易落到特征撑不住的领域。故去掉场景钉死语「五防」「快速」「烧结」，停在带式输送机保护装置，不再升到全部输送设备或工业监测。

## 4. 重新核定后的技术问题

多只保护装置中发生保护动作后，无法确定是哪一只装置、位于哪一安装点、属于哪类保护，只能沿线逐点排查。

## 5. 核定考虑

反推对象 = 第一版全文，不是交底发明目的清单。第一版实际稳定消除的是「动作有了、点位身份没有」这一层，不是全域停机、也不是隐患预警。问题只写后果，不写入独立通道、对应关系、采集单元等手段。假定第二版只保留第一版这些必要特征，仍能指向具体保护装置、不必沿线盲查，故问题与特征匹配。结构案问题须被现有手段撑住，不把未入权的分级联锁、预警写成独权问题。
