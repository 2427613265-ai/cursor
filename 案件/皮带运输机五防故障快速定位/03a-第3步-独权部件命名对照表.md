# 【第 3 步 / 共 9 步 · 3a】独权部件命名对照表

阶段：结构类独权撰写第 3 步。最小集已确认。本步先过 `部件命名优化总控`，**确认前不写第一版独权全文**。

实用新型：主题必须是产品。交底标题「一种应用于皮带运输机五防故障快速定位」不是产品名，「快速」是效果词。

## 分流（总控）

| 拟入权名称 | 分型 | 已读叶子 |
|------------|------|----------|
| 交底标题 / 技术主题 | B（非产品名）+ A（「快速」效果；「五防」「皮带运输机」场景） | 口语改写；具体优化；方位与场景（场景钉死语） |
| 保护装置 | 功能结构名，略 H；多只同类 → F | 具体优化；指代（用「各 / 多只」，不必第一/第二） |
| 采集单元 | B（相对 PLC / 远程 IO / CPU） | 口语改写；具体优化 |
| 输入通道 | A（交底「数字量输入通道」） | 具体优化 |
| 对应关系 | D（本案配置对象，须说清内容） | 就地定义（前置白话，不用「其中」） |
| 皮带标识 | B（交底「皮带编号」） | 口语改写 |
| 点位标识 | B（交底「传感器位号」）+ D | 口语改写；就地定义（前置白话） |
| 故障类型 | 公知词 | 具体优化（两档） |
| 定位信息 | D | 就地定义（前置白话） |
| 信号输出端 | 关系部位，非独立部件 | 具体优化 |

未命中：名称无左/右、上游/下游。规则五：本版拟用名互不撞车。

母子件：输入通道是采集单元的内部构成，总列只列保护装置、采集单元；通道在展开采集单元时写。对应关系 / 标识 / 定位信息不是另列同级部件。

## 已入权名表（本版拟用，供规则五）

保护装置；采集单元；输入通道；信号输出端；对应关系；皮带标识；点位标识；故障类型；定位信息。

同名多物：无。禁止再把 PLC、远程 IO、传感器、位号、对照表与上表混用指同一物。

| 部件原名（交底 / 最小集） | 分型 | 第一档优化 | 第二档优化 | 推荐采用名 | 对保护范围的影响（一句话） | 用户选择 |
|---------------------------|------|------------|------------|------------|----------------------------|----------|
| 一种应用于皮带运输机五防故障快速定位 | B+A | 一种皮带运输机五防故障定位系统 | 一种带式输送机故障定位系统 | **一种皮带运输机五防故障定位系统** | 改成产品主题并去掉「快速」；保留皮带运输机与五防，第一版清楚、未放到最宽 | 待确认 |
| 五防保护装置 / 传感器 / 开关 | H | 保护装置 | 检测装置 | **保护装置** | 覆盖开关量保护及撕裂检测等，不钉死某一种开关；「检测装置」更宽但弱化保护属性 | 待确认 |
| PLC / 远程 IO / CPU / 采集单元 | B | 采集单元 | 采集装置 | **采集单元** | 不钉死 PLC 或远程 IO，一体或分设均可；「装置」稍宽、层次略糊 | 待确认 |
| 数字量输入通道 / 输入通道 | A | 输入通道 | 输入接口 | **输入通道** | 去掉「数字量」变宽；「通道」比「接口」更贴一对一接入 | 待确认 |
| 保护装置的信号输出端 | — | 信号输出端 | 输出端 | **信号输出端** | 「输出端」过宽（可被理解成机械出料口）；信号输出端仍清楚 | 待确认 |
| 对照表 / 组态 / 预先绑定 / 对应关系 | D | 对应关系 | 通道身份对应关系 | **对应关系** | 不钉死表或组态；正文前置写清「各输入通道与皮带标识、点位标识及故障类型相对应」，不用「其中」 | 待确认 |

| 传感器位号 | B+D | 点位标识 | 位置标识 | **点位标识** | 去掉「传感器」；「位置标识」易被理解成仅坐标、不含「哪一只装置」，第一版停在点位标识 | 待确认 |
| 故障类型 | — | 故障类型 | 保护类别 | **故障类型** | 第一版沿用交底；「保护类别」稍抽象，可留第二版 | 待确认 |
| 报警画面 / 定位信息 | D | 定位信息 | 故障定位信息 | **定位信息** | 不钉死 HMI；正文写明其包含三项身份。加「故障」略窄 | 待确认 |

## 正文落地约定（确认采用名之后才写权 1）

- 总列同级部件：**保护装置、采集单元**。输入通道不与二者并列。
- 多只保护装置、多条输入通道：用「多只」「各」，不用第一 / 第二。
- 点位标识、对应关系、定位信息：名称出现前用白话写清含义，不堆「其中」。
- 不采用：PLC、CPU、远程 IO、TBEN、传感器、位号、对照表、HMI、快速。
