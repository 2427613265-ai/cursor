# 独权创造性预评（盲判 + 公开文献对照）

评价对象：用户改写独权（微控制器 / 输入采样电路 / 存储映射 / 按电平跳变显示）。润色稿把微控制器改为控制器、前序去掉五防和快速，**不改变创造性结论**。申请类型：**实用新型**。未做全库检索，不能当授权保证。

本案第 1 步已写明：未检索，独权宽窄为盲判。本预评补充同领域已公开线索，供权 1 定稿时知情。不是审查意见答复，不套意见陈述书体例。

---

## 1. 总评

相对交底里的**串联接入生产 PLC**，权 1 有区别：一对一独立通道 + 通道与点位 / 类型映射 + 跳变后显示。实用新型创造性门槛低于发明，若审查员只拿「串联五防」当最接近技术，仍有过关空间。

权 1 一旦被概括成「每只开关独占一个输入通道，存储器里放对照表，控制器查表后在显示模块上显示点位和类型」，创造性就偏弱：

- 发明标准（突出的实质性特点、显著进步）：很难过。
- 实用新型标准（实质性特点、进步）：碰上行标、分压定位专利或「分点进 PLC + HMI」的公知常识后，风险高。

交底真正有辨识度的点（隔离加装、廊道远程 IO、环网、接线箱挂签）几乎都没写进这版独权，权 1 被抽成通用分点采集，创造性跟着被抽空。

---

## 2. 三步法（先对交底惯常）

最接近技术先按交底背景（串联保护信号进生产 PLC / 电气回路，HMI 只知道本机有保护动作）。这不是已核实的对比文件。

**区别（按权 1 原文要素）：**

1. 输入采样电路具有多个相互独立的输入通道，各保护装置信号输出端分别一对一电连接至不同输入通道。
2. 存储模块中预存各输入通道与安装点位及故障类型的映射关系。
3. 控制器（或微控制器）用于根据产生电平跳变的输入通道调取映射关系，并控制显示模块显示对应的安装点位及故障类型。

其余（沿机架分布、控制器 + 存储 + 显示的模块划分、电平跳变本身）是带式输送机保护和 PLC 采集的惯常配置，单独不能撑创造性。

**实际技术问题（只写问题，不写手段）：** 多只保护装置动作后，无法确定是哪一只、位于哪一安装点、属于哪类保护。

**是否显而易见：**

- 问题本身会直接把人推向「不要串在一路里、让每只开关有自己的身份」。一对一进不同输入通道，是本领域解决「串联抹掉点位」的最常规电路选择，不是迂回发明。
- 通道编号与点位、类型做成对照表，跳变后送到画面，是 PLC / HMI 组态的标准做法（输入点—报警文本）。权 1 末两句几乎是在描述这种组态，而不是一种新的电路构造。
- 因此：相对「串联」有进步；相对「本领域要定位就分点采集并在画面上显示」缺乏非显而易见的构造跳跃。实用新型仍可能凭「对比领域窄、只找到串联文献」授权，但不稳。

## 3. 同领域已公开、比「串联」更接近的线索

下列不是本案对比文件清单，说明权 1 当前抽象度一旦检索，容易撞车。

| 线索 | 公开了什么 | 对权 1 的压力 |
|------|------------|----------------|
| CN202208514U（2012，实用新型）带式输送机智能监控装置 | 同样要解决保护动作后难定位；跑偏 / 拉线 / 纵裂分接到 PLC 不同输入端，同类开关用分压电阻串联，按电压识别位置并报警 | 同一课题、同一产品领域。区别只是「一对一 DI」对「分压编码」。为定位而把开关接到 PLC 不同输入端已被公开；一对一比分压更常规，难说非显而易见 |
| JB/T 10938（2010 已有，2024 修订）带式输送机保护装置地址编码系统 | 专门规范保护装置状态采集和定位；编码控制器含人机接口、存储、显示、通讯；适用于不参与控制回路的采集定位 | 与交底「另做采集、定位到点」同一任务。控制器 + 存储 + 显示 + 点位信息，和权 1 模块划分高度同构。行标在实用新型里常被当公知常识或最接近技术 |
| 煤矿带式机实践 / 综合保护文献 | 沿线故障地址识别装置，显示跑偏、纵撕、闭锁等故障及地址 | 「要定位就上地址识别」已是现场常规选项 |
| 市售可寻址拉绳 / 跑偏开关、工程上「每只拉绳进一个 DI + HMI 点名」 | 串联进 PLC 是产品说明书里的常规接法；要中控看点位则改寻址或分点 DI | 权 1 的电路模块写法与这种工程改法同构 |

另：交底自己也把「每通道独占 DI + 组态绑定 + HMI 显示位号」写成实施方式，没有宣称这是对 PLC 输入方式本身的新电路。创造性若有，更应落在加装隔离、布线、挂签、分级等，而不是「有映射表的分点采集」。

## 4. 权 1 里几乎不贡献创造性的特征

- 沿机架分布：保护开关的惯常安装。
- 采集单元拆成控制器、输入采样电路、存储模块、显示模块：通用工控架构，CN 和行标里同类划分很多。
- 电平跳变：开关量输入的固有电现象。
- 「快速」「五防」若写回前序：效果词 / 场景词，不增加构造区别，还减范围。

真正还能跟「串联抹掉身份」咬上的，主要是**一对一独立通道**。但如上所述，这恰恰是最容易被评「常规选择」的那一步。

---

## 5. 交底里更有辨识度、当前权 1 没有的点

这些不能自动让现在的权 1 变强，只说明创造性的「肉」在独权之外：

- 采集系统与原生产主控隔离、不参与原启停联锁（不停产加装）
- 廊道就近远程 IO + 介质冗余环网
- 中继接线箱编号挂签（物理身份，不只是内存映射表）
- 通道消抖、分级联锁、趋势预警（另一改进，且交底与「不参与联锁」仍有张力）

实用新型若要把创造性立在权 1 上，通常需要把「相对串联且相对分压编码 / 地址编码行标仍能站住」的构造写进去，而不是只写 PLC 查表。隔离加装、挂签 + 独占通道的组合，比单独「映射关系」更像能答辩的实质性特点。是否并入独权是保护范围与授权稳定性的取舍，本预评不改权 1 正文。

## 6. 实务判断（给定稿用）

| 场景 | 判断 |
|------|------|
| 审查员只找到「保护开关串联进 PLC」 | 实用新型权 1 有授权可能；答复时把问题钉在「串联导致点位身份被抹掉」，强调一对一是针对该缺陷的电路改变 |
| 审查员找到 CN202208514U、地址编码行标或分点 DI + HMI 工程资料 | 权 1 创造性压力大；一对一相对分压编码难称非显而易见；映射 + 显示易被当公知常识 |
| 按发明来评 | 当前权 1 创造性不足的概率高 |
| 无效阶段 | 通用 PLC 分点采集 + 报警文本组态很容易被拿来拼，权 1 单独抗无效偏弱，要靠从权里的隔离、远程 IO、挂签等往回收 |

**一句话：** 这版独权解决的问题是真的，手段对交底也是对的，但写到现在的抽象度，创造性主要靠「审查员没找到更近的定位方案」；不是靠权 1 里那种电路模块划分本身。
