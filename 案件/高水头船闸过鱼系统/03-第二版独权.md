# 第二版独权（重新界定技术问题 · 无非必要特征）

**已确认锚定问题：** 如何在不对船闸主体进行大规模改造的条件下，解决高水头船闸过鱼时缺乏持续、可控溯游引导水流的问题。

**创造性骨架（用户选定）：** 既有检修门槽 + 底节门 + 可控输水管引水。

---

## 权利要求1（第二版工作稿）

一种利用防洪检修门引水的高水头船闸过鱼系统，其特征在于，包括上游防洪检修叠梁门、输水管、流量调节阀、消力池、上闸门和船闸闸室；

所述上游防洪检修叠梁门设置于上游水域与所述消力池之间，所述上游防洪检修叠梁门包括普通挡水叠梁门和底节专用叠梁门；所述普通挡水叠梁门与所述底节专用叠梁门共同设置于船闸既有门槽内，所述底节专用叠梁门位于所述上游防洪检修叠梁门的最下方；其中，所述底节专用叠梁门为外形尺寸与所述普通挡水叠梁门相适配、且集成有所述输水管的叠梁门节；

所述输水管贯穿所述底节专用叠梁门的门体，所述输水管的数量为至少一根，所述输水管的进水端与上游水域连通，所述输水管的出水端延伸至所述消力池；所述流量调节阀设置于所述输水管上，用于调节经所述输水管进入所述消力池的流量；

所述消力池与所述船闸闸室通过所述上闸门分隔，在所述上闸门开启时，所述消力池与所述船闸闸室连通，以使经所述输水管进入所述消力池的水流能够进入所述船闸闸室并形成溯游引导水流。

## 相对第一版：删除 / 概括 / 下放对照

| 处理 | 第一版特征 | 理由（相对已确认主问题） |
|---|---|---|
| 删除 | 上游引航道、下闸门、下游检修叠梁门、下游引航道 | 不回答「少改主体下的连续可控溯游水」 |
| 删除 | 输水廊道、左/右阀门、左侧出水口、左侧通道 | 属入口集流/伴生层 |
| 删除 | LED诱鱼灯组、饵料缓释装置、信息素释放装置 | 属辅层诱鱼，非本主问题必要 |
| 删除 | 四节/一节的具体节数、「五节全部落下」表述 | 节数非必要；保留「普通门+最下方底节门+既有门槽」即可 |
| 删除 | 迎水侧四段拆分称谓、拦污栅、进水口分列、加强肋与密封止水、配重环、电动球阀专名、加长管扩散整流等细部 | 具体实现/优选，去掉后主问题仍可解 |
| 概括 | 电动流量调节球阀 → 流量调节阀 | 阀型非必要 |
| 保留 | 既有门槽、底节专用叠梁门、至少一根输水管、阀控、通至消力池、经上闸门通闸室 | 最小创造性骨架 + 方案可实施闭环 |

## 成组下放从权建议

| 组 | 内容 | 对应次级问题/效果 |
|---|---|---|
| A | 普通挡水叠梁门为四节、底节为一节 | 实施例门组配置 |
| B | 拦污栅；加强肋与密封止水；背水侧加长延伸与平缓出流 | 拦污、止水、消能平顺 |

| E | 多根输水管并联 | 增大流量、均布出流 |
| F | 下游检修叠梁门缩窄过流断面 + 下闸门进鱼 | 下游入口集流 |
| G | 输水廊道左侧出水口 + 左侧通道进鱼 | 廊道口定向进鱼 |
| H | LED / 饵料 / 信息素 | 多场诱鱼 |
| I | 平压组件 | 仅实施例 |

## 必要性自检（压缩）

去掉阀 → 不能「可控」；去掉贯穿底节的管或既有门槽底节门 → 不能「少改主体地连续引水」；去掉消力池—上闸门—闸室连通关系 → 不能在闸室侧形成溯游引导水流。其余已删特征去掉后主问题仍成立。
