# 待确认：重新界定后的技术问题

## 重新界定后的技术问题（定稿候选）

如何在不对船闸主体进行大规模改造的条件下，解决高水头船闸过鱼时缺乏持续、可控溯游引导水流的问题。

---

## 界定考虑

### 点1：最核心的问题

交底场景里，若不解决就会导致过鱼整体失败的主矛盾是：**闸室侧缺少一路持续、可调节的溯游引导水流**（高水头下仅靠充泄水间歇流，鱼难进、易滞留）。  
「下游入口分散」「改造难」分别是入口效率与工程约束；入口分散在已有连续水的前提下仍重要，但单独构不成「没有连续水则全程失败」这一层。

（盘点）交底并列三条中：水流不连续 = 核心痛点；入口分散 = 伴生/入口层；改造难度大 = 约束条件与推广前提，不宜与核心痛点简单并列成同等「主问题」。

### 点2：最具创造性的技术方案所解决的问题（默认优先）

第一版独权中区分度最高的骨架是：**在既有检修门槽内设置底节专用叠梁门，以至少一根可控输水管将上游水引入消力池/闸室一侧**。  
该手段稳定解决的不良后果是：已建/高水头船闸**想补连续诱鱼水却往往只能大改主体或新建廊道**，以及由此导致的**溯游引导水流缺失或不连续**。  
故重新界定后的主问题落在「少改主体前提下的持续可控溯游引导水流」，使第二版能把这撮创造性骨架留在独权里。

（特征反推 / 区分度落点）问题若写太宽（泛「提高过鱼效率」）→ 难被该手段单独撑住；若写太窄（必须同时解决入口分散+光饵信息素）→ 会把廊道左出口、LED 等逼进第二版必要特征。当前落点宽度适中。

### 点3：好通过补强来增强创造性的方向

若第二版创造性仍边缘，可沿交底脉络补强且发明人易确认的方向包括：双进鱼通道切换、下游检修门缩窄集流、水流+光/饵/信息素协同等——对应「入口分散」「集鱼效率」次级问题，**不必升格为本轮主问题**，留作从权/可选创造性补强抓手。

### 综合取舍

- 点2 与点1 同层对齐（连续可控溯游水）；点1 中的「改造约束」写入问题的条件短语。  
- 点3 降为次级，不进主问题表述。  
- **手段不进问题**：未写入专用门、球阀、管径等手段名。

（可检验）假定第二版只保留：上游检修门位上的底节引水门 + 至少一根带阀输水管通至消力池侧 + 与闸室经上闸门可连通——仍能回答本主问题；廊道左通道、下游检修门、诱鱼三件删去后主问题仍成立 → 符合第二版去非必要方向。
