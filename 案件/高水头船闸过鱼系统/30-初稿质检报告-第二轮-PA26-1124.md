## 二、须优先修改（清楚性 / 一致性）

### 2.1 权10 配重环挂错主体（高优先）

**权利要求书：**「所述**输水管**还包括配重环，所述配重环设置于所述**输水管**迎水侧的顶部。」  
**实用新型内容：**仍为「所述**输水门节**还包括配重环…」  
**具体实施方式：**复述跟了「输水管」，展开却写「迎水侧是指**输水门节**…门节重心…」→ **权文、发明内容、实施例三者互斥**。

交底与技术逻辑：配重环服务于**输水门节**起吊平衡，不是输水管本身。

**建议改回：**

> 所述输水门节还包括配重环，所述配重环设置于所述输水门节迎水侧的顶部。

并同步改正权10实施例复述与展开主语。

### 2.2 权1「上游闸门」孤岛（高优先）

权1总列含「上游闸门」，但特征部分**未写**其与缓冲池／下游侧任何关系；「上游闸门分隔缓冲池与船闸闸室」直到权6才出现。独权中上游闸门成为**只列不用**的部件。

**建议（择一）：**

- A：权1补一句「所述上游闸门分隔所述缓冲池与下游侧水域／过鱼通道」等不依赖「船闸闸室」名的上位关系；或  
- B：上游闸门随船闸闸室一并下沉到权6再总列展开（权1删上游闸门）。

### 2.3 「船闸原有新建闸室」表述不清（高优先）

权8、发明内容、实施例多处使用「原有新建闸室」——「原有」与「新建」并列易被理解为矛盾。

**建议权文改为：**「所述船闸闸室为新建船闸闸室。」（或「工程中的新建船闸闸室」）  
说明书释义可保留「与老闸室相区分」的说明。

### 2.4 说明书与权利要求书不同步（高优先）

| 位置 | 与现行权利要求的偏差 |
|------|----------------------|
| **摘要** | 仍写系统「包括…**和船闸闸室**」「上游闸门分隔缓冲池与船闸闸室」→ 对应旧独权；现权1无船闸闸室 |
| **实用新型内容·权1复述** | 多了「其中，所述缓冲池为船闸原有老闸室」→ 该限定现仅在**权8** |
| **实用新型内容** | 仍单列「进一步地，所述叠梁门设置于船闸既有检修门槽内」→ 权利要求已无此独立条（并入权8） |
| **实用新型内容·下游条** | 「其中，船闸闸室为原有新建闸室」→ 应只在对应权8，不应挂在权6对应段 |
| **实用新型内容·廊道条** | 「其中，输水廊道为既有充泄水廊道」→ 应只在权8 |
| **实用新型内容·配重环** | 正确写输水门节，与**权利要求权10**不一致（以改权10为准） |
| **权6实施例复述** | 夹带「其中，船闸闸室为原有新建闸室」→ 超出权6权文 |
| **权7实施例复述** | 夹带「廊道为既有充泄水廊道」→ 超出权7权文（属权8） |
| **权6/权9展开** | 仍写「**权1所述**船闸闸室6」→ 闸室已不在权1，应改为「本实施例所述」或「权6所述」 |
| **权8展开** | 「仍可按**权7**所述缩窄下游过流断面」→ 缩窄是**权6**下游门体特征，应为权6 |

→ 发明内容各「进一步地」须与权利要求书**逐条逐字对齐**；实施例第一段只复述对应权文，不把权8限定提前塞进权6/权7。

### 2.5 权9「不同水深处」

实施例复述含「不同水深处」，权利要求权9仅「可拆装地设置于所述船闸闸室侧壁」。  
**建议：**权9补回「不同水深处」，或实施例复述删去该短语（细节改可选段）。
