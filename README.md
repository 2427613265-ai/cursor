# cursor

本仓库存放个人 Cursor Agent Skills，目前包含一套**中文专利撰写与质检 skill 体系**。

## 目录结构

skill 位于 `.cursor/skills/专利/` 下，克隆本仓库到用户主目录（`~`）即可让 Cursor 直接加载：

```
.cursor/skills/专利/
├── 专利撰写/
│   ├── 通用/
│   │   ├── 撰写策略/          # 交底理解、独权分流与结构/方法独权、从权、说明书总控
│   │   ├── 权利要求撰写/       # 形式合规、清楚性、必要特征、主谓宾、指代、条件句、预设值来源、自定义名词就地定义
│   │   └── 说明书撰写/         # 技术领域/背景技术/技术问题/有益效果/具体实施方式/附图说明/名词先释义后展开
│   ├── 结构类/               # 结构类权利要求撰写、功能性限定使用边界
│   ├── 方法类/               # 预留细则；方法独权策略见通用/撰写策略/方法类独权撰写
│   └── 算法类/               # 预留
├── 权利要求质检/              # 权利要求书质检（主控）、单条权利要求审查、引用结构检查
├── 说明书质检/                # 具体实施方式清楚性与逻辑一致性
└── 审查意见答复/
    └── 创造性答复/            # 创造性答复意见陈述书撰写
```

### 撰写策略主线（交底书 → 独权）

```
交底书评估（可写确认 → 体检）
  → 交底书技术方案理解（白话读懂：名片 → 场景问题 → 构成 → 流程 → 创新点剥离）
  → 交底书评估续（初版独权 → 主问题/待确认）
  → 独权撰写（分流）→ 结构类/方法类独权撰写
  → ……
```

**注意：** 体检之后、撰写初版独权之前，须先跑 `交底书技术方案理解`，避免未读懂方案就落独权。

## 使用方式

将本仓库克隆到 `~`（会生成 `~/.cursor/skills/专利`），Cursor 会自动发现这些 skill。

## 本地 / Cloud Agent 开发环境

本仓库是 Cursor Agent Skills 集合（非传统 Web/API 应用）。Cloud Agent 通过 `.cursor/environment.json` 安装依赖并启动 skill 目录页：

```bash
# 安装依赖并校验全部 SKILL.md
python3 -m pip install --user -q 'python-docx>=1.1.0'
python3 scripts/validate_skills.py

# 生成并打开本地 skill 目录（默认 http://127.0.0.1:8765/）
python3 scripts/serve_catalog.py
```
